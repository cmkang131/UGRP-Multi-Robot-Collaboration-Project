# R19 · 열린 이슈에서 독립 검토 근거 찾기

**열린 이슈 16개를 검토 근거에 연결한 탐색표다. 이슈 해결 판정이나 새 실행 승인이 아니다.** 공식 GitHub 검색을 2026-10-04 09:12 UTC에 확인했으며 16개 모두 open이다. R1의 이슈 검토 (Mac: `evidence/review-notes/issues-review.md`)와 제목·본문을 비교한 결과 모두 동일했고, #219의 댓글 2개와 #366의 댓글 1개만 추가됐다. ## R1의 과거 상태에서 바뀐 두 곳

- **#219:** [adapter 고정 댓글](https://github.com/cmkang131/UGRP-Multi-Robot-Collaboration-Project/issues/219#issuecomment-5971425132) 뒤 [작성자 v95 채점 보고](https://github.com/cmkang131/UGRP-Multi-Robot-Collaboration-Project/issues/219#issuecomment-5971577508)가 추가됐다. 따라서 R1의 “채점 전”은 당시 snapshot이며 현재 상태 설명으로 재사용하지 않는다. 보고는 원래 B의 전체 미판정과 회전 부록 판정을 분리하고, 후보의 `CANDIDATE_UNVALIDATED` 상태 및 PF 전체·학생제어·실제 성공·loaded 조건 제외를 명시한다. 이 표는 공개 보고의 존재와 범위만 반영한다. raw·점수 파일·TensorBoard를 열거나 수치/채점 재현을 검증하지 않았다.
- **#366:** [최신 사용자 결정 기록](https://github.com/cmkang131/UGRP-Multi-Robot-Collaboration-Project/issues/366#issuecomment-5970833614)은 실제 로봇 방향을 첫 LLM E2E 뒤 정하며, 간단 지도+자기 카메라 / 실제 위 카메라 / 로봇별 자기 지도 세 후보를 남긴다. 현재 이슈 작업은 계속 E2E 뒤로 미뤄져 있다.

R1의 이슈 본문과 과거 판단은 소급 수정하지 않는다. 발견 번호·검토 라운드 수를 이슈 진행률로 환산하지 않으며, “수정 확인”은 원래 반례가 해당 pin의 실제 caller에서 차단된 경우에만 사용했다. 사용자 결과 파일은 계속 제외했고 이 표를 위해 새 댓글·이슈·실험을 만들지 않았다.
