# R22 — 보존·회수·복구 계약의 독립 해석 QA

**문서 해석 PASS.** main `b23fc0875b72f4b55f399a252a1575b7e8b43cb5`의 AGENTS 53–55행, `docs/model_artifacts.md` 31·81–96행, `docs/colab_simulation.md` 24–52행, `docs/kaggle_simulation.md` 59–71행, `docs/disk_management.md` 4·5·9절을 직접 읽었다. 전달 manifest의 다섯 Git object SHA-256도 독립 대조해 모두 일치했다. 새 테스트/collector 실행이나 실제 자료·원격 내용 확인은 하지 않았다.

- **선별 보존 정책을 존중한다.** 2026-10-04 결정은 텍스트·원장·결과/trace·제거 이미지 hash를 보존하고 이미지 원본은 명시 범주에 따라 유지·정리한다. 과거의 포괄적인 삭제 보류를 근거로 이 승인을 다시 막거나, 모든 과거 이미지의 원격 복제를 새 요구로 만들지 않은 원고가 맞다. 실제로 어떤 파일이 정리됐는지는 이 문서만으로 알 수 없다.
- **모델 배포의 보장은 선택한 구성물에 한정한다.** 문서는 새 폴더 재다운로드·파일 hash·실제 모델 로딩을 요구하며 이를 물리 성공과 분리한다. 선택 모델 패키지가 학습 원시 자료·모든 진단 입력의 백업이라는 해석을 배제한 것이 타당하다. 이번 QA는 실제 asset 존재나 로딩 결과를 재검증하지 않았다.
- **회수와 복구를 분리한다.** Colab/Kaggle 문서의 verified result는 해당 작업의 종료·회수·무결성 절차다. 저장된 사본의 지속성, 원래 기대 집합의 완전성, 별도 환경에서 필요한 자료에 접근할 수 있다는 운영 증거까지 자동 제공하지 않는다. R9/R10의 기존 조건부 collector 한계를 이번에 재실행하거나 모든 collector에 일반화하지 않은 범위도 맞다.
- **복구의 대상도 보존 정책에 맞춘다.** 원고가 요구하는 좁은 증거는 남기기로 한 대표 묶음의 membership/hash·접근 경로·독립 환경 읽기다. 전체 과거 실행의 재채점이나 물리 재현을 요구하지 않는다. hash는 비교할 bytes가 있을 때 무결성 대조에 쓰이며, 제거한 영상 내용을 복원하는 수단은 아니다.

저장 매체의 현재 가격/한도·서비스 적합성, 실제 보관 위치/권한, 업로드/다운로드/삭제·복구 상태는 검토하지 않았다. repo의 문서 계약을 확인했으며, 문서에 절차가 있다는 것과 그 절차가 운영에서 완료됐다는 것을 구분한다. 새 운영 의무나 권한을 만들지 않은 한정 판정을 수용한다.

공식 이슈 완료 기준도 담당자의 `backup-restore-issue-source.json`에서 대조했다. #3 본문/댓글은 과거 로컬 의존과 손실 사고를 설명하지만 이번에 현재 원본 부재나 원격 사본 부재를 확인한 자료가 아니다. 원고는 이를 과거 진술로 남기고 새 선별 보존 승인과 별도 운영 완료 증거를 구분하므로 수용한다. 이 QA가 GitHub API를 별도 재조회한 것은 아니다.
