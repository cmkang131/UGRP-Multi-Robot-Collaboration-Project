# 14차 독립 검증과 부정 결과의 범위

| 대상 | 독립 확인 | 의미 |
|---|---|---|
| 현재 pair 판단 메모 | frontier가 direct predicate/currentness, geometry가 command/scan/quality source 경계를 교차 검토 | 연구 설계·판별 순서이며 새 raw 분석/현재 원인 확정 아님 |
| checkpoint guard | integration이14개 exact Git source hash,14 endpoint cases+4controller-only 대조, golden JSON 동일 확인 | endpoint pose guard와 controller timeout 순서를 분리. 실제 next carry GO/물리 파지/실제 fix 생성 미실행 |
| OpenCV 경계 | evaluation이 두 fixture 재실행·25개 공통/추가 source hash, JSON 동일 확인 |3pose×7pan와 grayscale4배열의 제한된 부정 대조. 전체 HSV/JPEG/OpenCV pipeline이나 실제 정보량 검증 아님 |
| pair approach | 실제 caller/factory/pursuit/final guard/arrival source 경로 읽기 | source-only이며 새 route/physics 반례를 실행한 것이 아님 |
| optional servo 식별가능성 | evaluation이2개 source AST와 모델 대수/optimizer·양성/음성 대조 재실행, JSON 동일 확인 | finite plan의 정확한 예측 동등성. 물리 rate/deadband 또는 confidence interval을 측정한 것 아님 |

Golden SHA256: checkpoint `51016b9d2a0ba37a9e06c808a83cdcdfdfe991dfc99cef1ca2dcfd067ec656d2`, ranker `fbe9a9eeb9f6ac2ecf5a3957da67ec645856c190d78d75fc1b7a3f4bc9c684aa`, band `9002903ba506e5e50efe0d7108cce806b9a209a988f6a609457b1f6d7a4be2bf`, servo `32aeeb066973f524fc44023e283a24646b4da933d154786a58231dea4c981063`다. 상세 메모와 source manifest는 Mac round14/evidence에 보존한다.

Checkpoint fixture는0.1초마다 endpoint를 호출한다. 실제 host의0.05초 호출과 before_control의 위치를 source로 구별해0.4초 stale abort 같은 수치를 보편적인 유예로 쓰지 않았다. 초기시각의 binary float 경계가 한 tick 통과 시각을 바꿀 수 있으며 새로운 물리 지연/별도 버그로 세지 않는다.

제안된 진단 필드는 기존 memory-only 값과 저장 필드를 구별하며 LLM input schema나 허용 정보 조건을 확장하지 않는다. 현재 공개 loaded 실패의 phase·sigma가 미공개면 unknown이다. detector 없음, numerical update, fresh receipt, 독립 정보, 물리 accuracy를 서로 바꿔 읽지 않는다.

배포는 Markdown-only Git과 additive Mac update다. 원래13개 manuscript, 이전1–13차 본문/source/result는 보존한다. 새 source QA와 재현 결과를 과거 snapshot에 소급 반영하지 않는다.

Checkpoint fixture의 `beam_grasp_confirmed=True`는 선언된 collaborator다. 실제 receipt/segment property, 전체 HIGH wrapper·PF·loaded geometry를 실행한 것으로 확대하지 않는다. 여기서 닫은 것은 해당 전제 아래 공통 pose guard와 controller timeout의 호출 순서다. 다른 grip/segment 계약은 별도 후속 검토로 남겼다.
