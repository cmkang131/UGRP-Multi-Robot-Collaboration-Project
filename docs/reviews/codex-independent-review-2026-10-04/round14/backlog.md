# 14차 이후 계속할 범위

| 범위 | 현재 상태 | 다음 근거 |
|---|---|---|
| r2 admission/r1 loaded uncertainty | 공개 보고+exact predicate/관측 경계까지 확인 | 같은 tick의 직접 failed predicate·gate history·report/fix 시각/phase가 있어야 분류. 미공개 값은 unknown |
| relook/worker current 결함 |12차 동결, 구현 변경 미수행 | 실제 수정 head가 생기면 narrow delta와 의미 있는 기존 대조만 재검증 |
| checkpoint·edge·carry 전제 | controller-only와 endpoint guard를 구별하는 합성 대조 완료 | 실제 phase가 확인되는 자료 없이 공개 failure에 원인 전이하지 않음 |
| predictor/observer/estimate | 제한된 current camera/geometry 부정 대조 완료 | local 민감도·모델 support를 actual detector covariance나 글로벌 ambiguity로 오인하지 않는 후속 |
| optional V2 보정 |13차 producer/consumer 결함,14차 finite-plan 동등성 | 정직한 effective 구성/평가 identity 수정과 의도한 사용 domain에서 필요한 예측 구별 |
| 최종 lower→release→done | 다음 caller coverage 대상 | HIGH final transition·barrier·release/retreat·evaluator success의 실제 연결을 source부터 확인 |
| planner/keepout 연속 pursuit | wall guard 존재 확인, 추가 keepout 증인 없음 | 현재 지원 지도/actual route에서 반례가 있을 때만 신규 finding 검토 |

연속 검토는 명확한 caller와 아직 구분하지 못한 계약을 중심으로 이어 간다. negative coverage를 새 버그 수로 바꾸거나 실제 실험·원본 raw 재분석을 수행한 것처럼 적지 않는다.
