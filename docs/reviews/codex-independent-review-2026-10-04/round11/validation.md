# 11차 독립 검증·출처

| 대상 | 별도 검토자의 확인 | 적용 범위 |
|---|---|---|
| Report latency | 실제 completer/fake HTTP·clock→원본 handler AST→실제 report를 재실행, JSON 완전 일치, source11개 Git hash 확인 | optional visual-team report. 이미지/planning/물리 미실행, 실제 latency benchmark 아님 |
| Ledger lifecycle | live runner/ledger fixture assertion 통과, 원래 run 보존·두 process cap·committed unknown charge 확인 | synthetic case/bundle/wire. full CLI·실제 provider·power-loss 보장 아님 |
| Repeat receipt | 새 temp에서144회 source fixture를 재실행, JSON 완전 일치; 별도 evaluation 검토도 동일 결과 | authored full-rank rows·particles·time-only prediction. 실제 상관/pose error 미측정 |
| Guard sample bound | 원본10개 파일 hash·closed-form derivative·margin계수·1-Lipschitz·beam sphere cover를 독립 source/수학 검토 | 고정-servo·세 predicted path·baseline guard true에 한정. 물리 안전 인증 아님 |
| Billing impact | evaluation 검토자가 exact cost source·산술 결과와 비교집합/validity/censor 제한 확인 | 고정 call 비용 재계산. 실제 발생률/수정 뒤 policy outcome 아님 |
| HIGH observer ownership | 원본12개 파일 hash·rid별 객체/closure/동기 호출·failure/close를 독립 읽기 | current default HIGH만. 외부 factory·async pool·실제 calibration 검증 아님 |

GitHub는 Markdown만 포함한다. Mac에는 script/작은 결과/source manifest와 일부 public cost source를 추가하며, 재현 준비는 `round11/evidence/reproduction-notes.md`를 따른다. 기존 결과를 덮어쓰지 않고 새 temp/출력 파일에서 실행한다. 정확한 Git source와 외부 Python dependency가 필요한 fixture를 구분했다.

원본13개, 1–10차 본문 및 과거 manifest/provenance는 바이트 그대로 보존한다. 탐색 README·checksum·압축본만 갱신한다. 실제 원자료·heldout score·영상·모델 weights·논문 전문을 패키지에 추가하지 않는다. 명시하지 않은 전체 pipeline/CI/실제 실패율을 검증했다고 쓰지 않는다.
