**교사 시연 분석**: approach → align(t≈9) → hover → descent → close(t≈14) → lift. 상자가 카메라 아래로 사라진 뒤에도 **약 5초간 조작 지속** → "안 보인 뒤 계속하기" 예시는 데이터에 존재.

**가설**: ① 조작 시작 상태에서 정책 출력이 0으로 붕괴(현재 프레임만 입력, 행동 크기 불균형), ② 긴 hold/lookback 구간의 0행동이 손실을 지배.

**해결 후보(싼 순)**
1. 추론 설정 스윕(무료, open-loop) — 가능성 낮음.
2. **말단 구간(align~close) 가중 fine-tune 1–5k step bf16** (~30–40분) — 먼저 시험.
3. **기억 입력 추가**: 과거 2–4프레임 + 마지막 목표 상대위치. 입력 계약 변경이므로 재학습 필요. 데모에 post-visibility 예시가 있어 가능성은 있으나 단독 보장 없음.
4. 라운드2 100k 재학습(8.5–9시간) — 데이터/설정 변경.
5. 교사 재녹화(카메라/가시성) — 사용자 승인 필요.

**"기억을 줘도?"에 대한 답**: 현재 모델은 current-frame-only라 기억을 주려면 재학습이 필요하고, 정지 원인이 표현 한계보다 행동 불균형(0행동 우세)이면 기억만으로 부족. 순서: 2번으로 확인 → 안 되면 3번.
