# 결정 모델 제어 (2026-10-13)

로봇 자기 판단을 결정 모델(Liquid d1 기본, Jev 비교)로 내리고 Gemma는 대화만 하는 구조의 설계 규칙이다. 근거 실험과 실패 사례를 함께 남긴다. AGENTS.md의 "결정 모델 역할과 실행 점검" 절이 요약이다.

## 1. 역할 분담

| 판단 | 담당 | 비고 |
|---|---|---|
| 몸 스킬 선택 | d1 (자기 RGB 이미지 + 범주 상태) | 코드가 수치 실행·안전 정지 |
| 프로토콜 행동 GO/ACK/WAIT/claim | d1 | 토글 `dialogue_decider=gemma_v0\|d1_v1` (구현 중, 브랜치 `claude/e2e18-llmmemory`; 2026-10-13 작성 시 미병합) |
| 파트너에게 보낼 문장 | Gemma | d1 행동을 바꿀 수 없음 |
| 받은 파트너 메시지 해석 | 없음 (원문을 d1 맥락에 그대로) | 오래된 메시지는 나이와 함께 표시 |

네 통신 조건에 같은 결정 경로를 쓴다. no_comm에서는 파트너 메시지 칸이 빈다.

## 2. 맥락 (매 호출)

- 고정: 과제·역할(어느 끝), 카메라 배치, 스킬별 효과, 짧은 우선순위 규칙.
- 현재: 단계, 집게 상태, 시각 범주(보임/왼/오/잘림/너무 가까움/안 보임), 자기 지도 추정(거리 + LEFT/RIGHT 단어, 나이·불확실성), 전방 초음파, 파트너가 화면에 있는지와 방향·거리 범주, 합의 상태.
- 기억: 최근 결정 8개와 결과 문장, 이 단계 사용 시간과 예산, 최근 20 s 진척, 놓침·재획득 횟수, 시도한 회복 전략, 같은 단계 실패 기억 한 줄씩.
- 방향은 부호 있는 숫자 대신 단어로 준다. 숫자 방위는 장기 과제에서 반대 방향 회전을 만들었다.

## 3. 선택 구조

1. 코드가 현재 가능한 스킬 후보만 남긴다. 안전 필터가 지운 뒤에도 진행 가능한 대안(좌/우 우회, 물러나 재계획)이 반드시 남아야 한다.
2. 후보마다 자기 추정으로 계산한 예상 결과 문장을 붙인다(미리 보기).
3. 최종 선택은 d1 확률 × 코드 점수다. 코드 점수는 막힘·충돌 위험이면 0이고, 진척에 비례한다(SayCan 방식).
4. d1 확신이 0.5 미만이면 코드 제안을 쓰고 기록에 표시한다.
5. 코드 제안은 필터 뒤 후보 안에서 계산한다. 변화 없는 같은 선택이 3회 연속이면 그 후보를 지운다.

## 4. 근거

아래 수치는 2026-10-13 조정자가 원본 파일을 직접 재집계한 값이다. 토이 자료는 저장소 밖(UGRP 규칙상 로컬 보존)에 있으며 경로를 함께 적는다. 저장소 실험 기록으로 옮기기 전까지 외부 재현은 미확인이다.

- 2D 토이 장기 과제(18 에피소드, Claude 세션 스크래치패드 `cmp/results_longhorizon*.json`): 미세 동작을 고르게 하면 d1 4–7/18, Jev 2–7/18, 규칙 14/18이었다. 스킬 단위로 바꾸면 d1 13/18, Jev 11/18, 간단 규칙 11/18이었다(진척 계산 일부에 정답 참조가 있던 초기 판이라 참고용).
- 2D 토이 840회(12종 × 10 seed, Codex 스크래치패드 `decision-v2/results_test.json`, 진척 계산의 정답 참조 제거판): d1 단독 80/120 → +미리 보기 108 → +확률 결합 112(충돌 0) → +실패 기억 111 → +낮은 확신 처리 117. 강한 규칙+예측은 120/120이다. 정보가 깔끔한 상황에서는 규칙이 천장이고, 결정 모델의 우위는 실제 영상과 자유 대화에서 재야 한다.
- 실제 실패 1 (2026-10-13 r70 v336, VM3 `~/ugrp-sim/runs/speed-gate-e2e18-ugrp-sim-azure3-r70-200fc07aa53e/speed-gate-e2e18-v336-s61006-r70/raw/body-decisions.jsonl.zst`): 파트너로 오인된 먼 주황 띠 때문에 경로 따라가기가 제거됐다. 남은 후보에 우회가 없어 r2가 30 SIM초 중 25초 동안 stop_and_look만 18번 골랐다. 코드 제안은 필터 전 값이 남아 있었다.
- 실제 실패 2 (r65, r69; VM3 `~/ugrp-sim/runs/e2e18-v32[4-9]-s61006-r69/`, 정지 기록 `outputs/e2e18-admin/stop-azure3-r69-r71-known-failures.json`, 재생 집계 `experiments/2026-10-13-e2e18-llmmemory/saved-replay-summary.json` — codex/e2e18 계열 브랜치): Gemma가 GO/ACK를 고르게 했더니 공동 파지 후 GO/ACK 15 s 창에서 실패했다. 저장 장면 재생에서 전체는 79/100이었지만 GO가 필요한 장면은 9/30이었다.
- 비용: Jev 응답에는 비용 칸이 없다(토큰 수만 있음). 공개 가격은 입력 $0.042/백만 토큰이다. "무료"는 집계 오류였다.
