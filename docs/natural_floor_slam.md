# 자연 바닥 특징점 기반 자기 지도·위치추정

이 경로는 **빈 지도에서 시작**한다. 첫 로봇 자세를 `(0, 0, 0)`으로 둔 로봇 전용 좌표계만 만들며,
시뮬레이션 맵이나 현실 경기장 도면을 입력으로 받지 않는다. AprilTag 같은 인공 마커도 쓰지 않는다.

## 런타임 입력

- 로봇 자체 RGB 카메라
- 고정된 카메라 내부 파라미터와 카메라-몸체 변환
- 실제로 발행한 바퀴 명령과 사전에 측정한 명령별 이동 평균·분산

상부 카메라, 시뮬레이터 pose, 접촉 정답, 사전 작성한 정적 맵은 평가·보정 때만 사용할 수 있고
실행 중 위치추정 입력에는 들어가지 않는다.

## 한 프레임의 처리

1. 카메라 자세를 고정하고 바닥과 로봇 몸체가 아닌 픽셀에서 ORB 특징을 뽑는다.
2. 기존 fisheye 보정과 바닥 평면 교차로 각 특징을 로봇 기준 미터 좌표로 바꾼다.
3. 직전 바퀴 명령의 보정 평균으로 현재 pose를 예측하고 공분산을 증가시킨다.
4. 현재 descriptor와 누적 랜드마크를 mutual ratio 방식으로 연결한다.
5. 연결된 점들이 하나의 2-D rigid transform을 지지하는지 RANSAC으로 확인한다.
6. 확인되면 영상 pose로 보정하고 새 특징을 지도에 추가한다. 실패하면 명령 예측을 유지하되
   `command_only`로 기록하며, **실패를 이동량 0으로 바꾸지 않는다.**

구현은 `harness/natural_floor_slam.py`의 `extract`와 `NaturalFloorSLAM`이다. 출력 지도는 자연
특징점의 미터 위치, 관측 횟수, keyframe, pose 궤적과 공분산이다.

## 현재 범위와 다음 결합점

이 모듈은 위치추정을 위한 **희소 특징점 지도**의 첫 단계다. 장애물 회피에 필요한 점유 격자는 별도다.
다음 단계에서는 이 모듈이 추정한 pose로 기존 자기 카메라 벽/바닥 관측을 `self_odom_grid`에 넣고,
그 점유 격자에서 frontier를 선택한다. 자연 무늬가 부족하거나 반복 무늬 때문에 기하 검증이 실패하면
로봇은 저속 탐색·카메라 재관측을 해야 하며, 그 구간의 지도 삽입은 보류한다.

실물 투입 전에는 바퀴 명령 `(방향, 속도, 시간, 하중, 배터리 상태)`별 실제 변위 분포와 카메라
바닥 투영 오차를 별도 주행으로 측정해야 한다. 이 값은 예측 평균·공분산일 뿐 위치 정답이 아니다.
