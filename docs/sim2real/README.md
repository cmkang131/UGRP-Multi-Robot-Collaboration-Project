# Sim2Real 병렬 과제 안내

MasterPi 실물에서 시뮬레이션의 관측·명령 계약을 재고, 접근·집기·놓기·이동을 각각 검증하기 위한 **문서 초안**이다. 기준일은 2026-11-13이다. 이 문서 묶음의 실물 시험은 **전부 확인 안 됨**이다. 과제 완료나 실물 성공을 선언하는 문서가 아니다.

## 바로 시작하기

- [환경과 색](01_environment.md): 경기장 외형과 사진 기반 임계 보정.
- [로봇 인터페이스](02_robot_interface.md): 입력·출력, 안전 범위, 측정할 값.
- [혼합 파이프라인](03_pipeline.md): 단계별 역할과 실물 위험.
- [13개 과제 목록](04_tasks.md): 무엇을 확인하고 어떤 근거로 통과시키는지, 담당·산출물·물리 통합 의존.
- [이슈 초안](tasks/ISSUES_DRAFT.md): 과제별 제목과 본문. 이슈로 만들 때 쓴다.

**가장 먼저 해야 하는 단일 과제는 없다.** 모든 과제의 설계, 사진 분석, 기록 형식, 모의 입출력, 시뮬 비교 준비를 동시에 맡을 수 있다. 번호는 식별자이지 순서가 아니다. 같은 로봇의 액추에이터는 동시에 여러 사람이 제어하지 않는다. 아래 순서는 팀 전체의 직렬 일정이 아니라 각 담당자가 실제 구동을 시작할 때 확인하는 안전 체크리스트다.

## 현재 기준과 한계

아래는 2026-11-13 연구 현황이다. 이전 [현황 기록](../current_status.md)의 다른 날짜·조건 성적과 합산하지 않는다.

| 흐름 | 시뮬에서 보고된 결과 | 해석 제한 |
|---|---|---|
| Solo 혼합 방식 | 접근을 고치며 본 12장면 중 11개 성공, 한 번도 안 쓴 새 12장면 중 6개 성공 | 새 12장면 실패 6개 모두 접근 단계. 두 집합 합산 금지 |
| ACT 단독 | 같은 새 12장면 중 0개 성공 | 혼합 방식과 구분 |
| Pair | 폐루프 함께 들기 아직 0 | 전체 시도 분모는 제공되지 않아 성공률 계산 불가. 두 로봇 통신 허용, 단계 분해 적용 계획 |
| 무하물 이동 | 초록 벽 색으로 문 통과 12개 중 11개, 구역 도착 6개 중 5개 | 지도 없음. 적재·Pair 운반 성적 아님 |
| 실물 | 전부 확인 안 됨 | 시뮬 성공·단위 시험·연결 성공을 실물 임무 성공으로 바꾸지 않음 |

최신 Solo hybrid 코드는 **main 미포함**이다. 새 clone의 기존 CLI가 이 구성을 제공한다고 가정하지 않는다. 이관 전 필요한 자산은 [파이프라인](03_pipeline.md)의 목록으로 확인한다.

## 구동 전 체크리스트

- [ ] 해당 카드의 준비·모의 시험과 물리 통합 조건을 구분했다.
- [ ] 기구 간섭·케이블·관절별 허용 범위를 현장에서 확인하고 로봇별로 기록했다.
- [ ] 독립적인 비상정지 수단과 현장 감시자를 확보했다. 연결 단절·프로세스 종료 때 정지 여부를 **무부하, 바퀴를 안전하게 띄운 상태부터** 검증한다.
- [ ] PWM 500–2500은 **시뮬 계약**이지 실물 전범위 스윕 허가가 아니다. 중앙 PWM도 모든 자세에서 안전하다고 가정하지 않는다.
- [ ] 10 Hz 발행과 최대 0.15 s 펄스의 중첩 정책을 확인했다. 덮어쓰기·큐잉·취소·STOP 우선순위는 **확인 안 됨**이며 결정 전 연속 실물 실행을 보류한다.
- [ ] 자기 RGB·자기 발행 명령 이력만 제어에 넣는다. 공용 TOP·지도·AprilTag는 이 작업 경로에서 사용하지 않는다. 외부 수기 측정은 오프라인 보정·평가에만 보존한다.
- [ ] 카메라 calibration board는 offline 보정 촬영에서만 쓰고 실행 전에 제거했다. 시작 지정상자 방위·거리 **1회 정보**를 자동 GT 공급이나 반복 갱신으로 확대하지 않는다.
- [ ] 하중 없이 시작하고, 낙하·끼임·과열·충돌 징후가 있으면 정지한다. 모터 STOP과 팔 전원 차단의 낙하 위험을 따로 확인한다.
- [ ] 로그와 실패 원장, 원본 해시, 새 버전 식별자를 준비했다. 결과 파일이 없으면 완료가 아니다.

## 기준의 등급

1. **프로젝트 계약·현황**: 이 묶음의 색, 해상도, 명령 범위, 단계 구성, 시뮬 성적. 실물 허용 범위나 일반화 보장이 아니다.
2. **기존 문서 기준**: 출처를 링크하고 당시 적용 범위를 적는다. 구형 물리의 허용오차를 최신 hybrid의 통과 기준으로 자동 승계하지 않는다.
3. **새 수치 기준**: 모든 카드의 제안은 **초안 제안·실물 미검증·담당자 합의 필요**다. 이유를 적었더라도 실기 사양·원본 분포·문헌 근거와 담당자 합의가 확보되기 전에는 수용 상수나 안전 한계로 코드에 넣지 않는다. 근거 없는 상수 금지는 [작업 지침](../../AGENTS.md)을 따른다.

## 결과와 기존 자료

카드마다 저장소 루트 기준 PR 결과 상대경로와 파일 형식을 지정한다. 공통 [결과 template](04_tasks.md#result-template)을 적용하고 카드의 CSV/JSON 필드를 추가한다. 미실행·실패·제외를 포함한 전체 분모와 측정 커버리지를 남긴다. 공개 기록에는 개인 절대경로, IP, 이메일, 클라우드 프로젝트 식별자, 비밀값을 넣지 않는다. raw 자료는 상대경로·sha256·접근 상태로 연결하며 해시만 있는 상태를 백업 완료라 하지 않는다.

기존 자료는 복사하지 않고 아래 원래 위치를 계속 링크한다. 과거 문서와 충돌하면 이 묶음의 제한 및 최신 프로젝트 결정를 적용한다.
