# 02 로봇 입력·출력 계약

[안내](README.md) · [과제 목록](04_tasks.md)

## 관측과 명령

다음은 사용자 제공 **시뮬 계약**이다. 실물 API가 이미 구현했다고 주장하지 않는다.

| 항목 | 계약 | 실물 확인할 것 |
|---|---|---|
| 제어 관측 | 자기 RGB와 자기 발행 명령 이력 | GT·측정 관절·접촉·성공 라벨이 입력·전환에 섞이지 않는지 |
| 카메라 | 자기 RGB 640×480, 모델 입력 320×240, 어안 | 촬영 시각·프레임 순서·색 채널·왜곡·전처리 동일성 |
| 발행 | 10 Hz, 주기 0.10 s | 실제 발행·수신·실행·정지 시각과 누락·지연 |
| 바퀴 | 4개 각각 0 또는 부호 있는 절댓값 0.31–0.40 | 채널 순서·부호·SDK 단위 환산·불감대 |
| 바퀴 펄스 | 각 0–0.15 s | 길이 0의 의미, 중첩·취소·종료 동작 |
| 서보 | 5개, ID 1,3,4,5,6, PWM 500–2500 | 관절별 기구 범위·방향·PWM–각도·집게 폭·정착 시간 |

**0.31–0.40을 m/s나 SDK 정수 속도로 해석하지 않는다.** 2026-11-13 정적 자산 감사에서 [기존 구동 CLI](../../scripts/masterpi_control.py)의 최소 유효값은 35, hybrid의 비영 휠 절댓값 하한은 0.31로 확인됐다. 단순 100배 변환으로 전 범위가 호환되지 않으며 31을 35로 몰래 클램프하지 않는다. 기존 CLI는 동기 14채널 스트리밍 계약도 직접 제공하지 않으므로 10 Hz 반복 호출만으로 연결을 완료했다고 하지 않는다. 발행 PWM은 실제 관절각이 아니고, 바퀴 명령은 실측 이동량이 아니다.

같은 감사에서 PR #385의 `scripts/real_robot_link.py`, `docs/real_robot_link_windows.md`, `tests/test_real_robot_link.py`는 조사 main(`3cd3897d5`)에 없었다. PR은 Windows 팔 연결의 draft이며 주행 변환·자율 임무 재생은 범위 밖이다. main에서 이미 사용 가능한 실물 backend나 실제 액추에이터 검증으로 간주하지 않는다.

## 중첩과 정지: 아직 결정되지 않은 계약

10 Hz는 0.10 s마다 새 명령인데 최대 펄스는 0.15 s다. 연속 발행하면 앞 펄스 종료 전에 다음 명령이 도착할 수 있다. 기존 실행기가 덮어쓰기, 큐잉, 연장, 취소 중 무엇을 하는지와 STOP 우선순위는 **확인 안 됨**이다. [T06](tasks/T06_command_contract.md)에서 시뮬 포트와 실물 어댑터의 타임라인을 비교해 명세를 고정한다. 임의로 직렬화하거나 길이를 잘라 같은 계약이라고 부르지 않는다. 합의 전에는 독립된 짧은 펄스 벤치 시험만 하고 연속 구동은 보류한다.

안전 확인은 기구 범위 점검, 비상정지 수단, 무부하·바퀴 띄움부터 한다. **PWM 500–2500은 실물 전범위 스윕 허가가 아니다.** 허용 범위 밖 요청은 기록 후 거부한다. 자동 clipping으로 조용히 다른 명령을 실행하지 않는다. 연결 단절·만료·예외·프로세스 종료 때 모터 정지를 검증하고 팔은 낙하 위험을 고려한 정지 방식을 현장에서 정한다. 구형 문서의 PWM 예시를 안전 인증으로 사용하지 않는다.

각 로봇·바닥·하중·전압 조건을 분리하고 반복 원자료·중앙값·분포를 남긴다. 합성 측정으로 빈칸을 채우지 않는다. 외부 측정은 평가 전용이며 제어기로 실시간 공급하지 않는다.

## 기록 연결

[기록기](../real_execution_recorder.md)와 [trace 구조](../real_trace_system.md)를 재사용한다. 어댑터 검증 sidecar에는 `command_id`, 로봇 익명 ID, monotonic 발행/수신/적용/정지 시각, 원래 요청, 실제 발행값, 거부 이유, `frame_id`를 기록한다. 이것은 새로 제안하는 감사 필드이지 기존 API 필드가 모두 있다는 뜻이 아니다. 서로 다른 기기의 monotonic 시각은 직접 빼지 말고 동일 기기의 왕복시간 또는 별도 동기화 오차와 함께 보고한다.

[실측 절차](../sim2real_measurement_protocol.md), [네트워크 런북](../masterpi_network_runbook.md), [실행 버전 관리](../execution_versioning.md)를 참조한다. 모든 실물 동작은 **확인 안 됨**이다.
