# T02 카메라 시야·왜곡·장착 보정

## 목적
로봇별 어안 내부 파라미터와 실제 장착 자세를 측정해 영상 입력의 차이를 분리한다. 실물 결과는 **확인 안 됨**.

## 준비물
자기 카메라, 실측 칸 크기를 아는 calibration board, 자·캘리퍼스·각도기, 촬영 조건 기록. 보드는 **offline 보정 촬영만** 사용하고 실행 전에 제거한다.

## 병렬 준비와 물리 통합
정적 촬영·적합 코드는 독립 준비 가능. 팔 자세를 바꿀 경우에만 T04의 기구 안전 범위가 필요하다. T01 완료를 기다리지 않는다.

## 실행절차
1. 카메라 모델·해상도·프레임 경로·장착 위치를 기록한다. 집게를 더 보이게 하려고 카메라를 옮기지 않는다.
2. [기존 실측 절차](../../sim2real_measurement_protocol.md)의 카메라 촬영 방법을 재사용해 화면 중심·가장자리와 여러 거리를 촬영한다. 적합/검증 목록을 먼저 고정한다.
3. fisheye 모델로 K/D를 적합하고 별도 사진의 재투영 오차를 **같은 어안 투영 모델**로 계산한다. pinhole solvePnP에 어안 D를 그대로 넣지 않는다.
4. 렌즈 위치·광축 방향·가로/세로 FOV를 독립 측정하고 640×480에서 320×240으로의 K 변환·crop/resize 순서를 검증한다.
5. 보드를 제거한 자기 RGB로 가장자리 상자 모습과 실제 장착 자세를 확인한다.

## 수치 통과기준
기존 프로토콜의 촬영 30–40장, 적합 2/3·검증 1/3 분리, 적합 RMS ≤1.0 px와 검증 평균 ≤적합 RMS의 2배를 **기존 문서 기준**으로 보고한다. 표본 수의 정수 분할을 명시한다. 이 값의 최신 실물 적합성은 확인 안 됨이며 담당자 재합의 전 자동 채택하지 않는다. 출력 크기 640×480/320×240과 보드 제거 후 실행 입력 보드 0개는 계약 확인 항목이다.

## 기준의 근거
재투영 오차와 사진 수는 링크한 프로토콜 3.2절에서 가져온 역사적 기준으로, 새 실측 근거가 아니다. 작은 RMS만으로 FOV·장착 정확도가 보장되지 않아 실측 치수와 검증 사진의 가장자리 오차를 함께 보고한다. 새 허용오차를 정한다면 **초안 제안·실물 미검증·담당자 합의 필요**로 둔다.

## 시뮬 기준
자기 RGB 640×480, 모델 입력 320×240, 어안. 옛 카메라 K/D 수치는 [프로토콜](../../sim2real_measurement_protocol.md)에 있으나 최신 hybrid의 동일 파라미터 여부는 확인 안 됨이다.
