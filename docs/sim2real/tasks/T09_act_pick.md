# T09 ACT 집기·들기 실물 추론

## 목적
`seg5_v1` 전처리와 ACT 추론 지연·명령 출력을 확인하고 집기·들기만 검증한다. 실물 결과는 **확인 안 됨**.

## 준비물
4000스텝 체크포인트와 adapter/설정/해시, 자기 RGB·명령 이력, 실제 추론 장치, 가벼운 시험 상자, 안전 지지와 비상정지. 최신 자산은 main 미포함이며 파일 확보 여부는 확인 안 됨이다.

## 병렬 준비와 물리 통합
모델 로드·저장 입력 추론·출력 범위 검사는 독립. 실물은 T01/02/04/06/07 산출물이 필요하다. T08 접근 완료를 기다리지 않고 안전하게 수동 배치한 시작 자세로 분리 시험 가능하며 수동 초기화를 기록한다.

## 실행절차
1. [모델 자산 절차](../../model_artifacts.md)로 체크포인트·설정·전처리 해시를 확인한다. 다른 모델로 대체하고 같은 결과라고 하지 않는다.
2. 640×480 RGB에서 320×240, `seg5_v1`의 채널 순서·정규화·색 임계·이력 길이를 실제 adapter에서 확인한다. 모르는 채널 의미를 지어내지 않는다.
3. 저장 입력으로 실기 추론 장치에서 모델을 로드하고 출력·지연·명령 범위를 측정한다. 지연 초과 시 행동 큐 처리 정책은 T06과 맞추며 자동 배속하지 않는다.
4. 무부하 관절 시험 후 안전한 수동 배치에서 집기·들기를 실행한다. 끝 전환은 자기 발행 명령 기록 규칙만 쓰고 외부 성공 평가를 전환에 넣지 않는다.
5. 집기·들기·전환 성공을 별도로 채점하고 실패 프레임과 오탐 전환을 남긴다. 교사 강제 보정이나 손코딩 파지로 성공을 대체하지 않는다.

## 수치 통과기준
**초안 제안·실물 미검증·담당자 합의 필요:** 준비 추론 100회에서 NaN·범위 밖 출력 0개, 전처리+추론 P95 ≤0.10 s. 실물 분리 시험 10회 중 8회 이상 집기 후 바닥과 분리된 물체를 3 s 유지, 비의도 낙하 0건. 높이·유지 여부는 독립 평가만 사용하며 명령 완료를 물리 성공으로 세지 않는다. 장치 워밍업 제외 수와 모든 지연을 보고한다.

## 기준의 근거
0.10 s는 10 Hz 주기의 계산 예산 제안이며 chunk 실행이 있으면 실제 스케줄에 맞춰 재합의해야 한다. 100회·8/10·3 s는 추론 안정성과 순간 들림을 구별할 파일럿 설계일 뿐 검증된 실물 기준이 아니다. 실측·사양과 담당자 합의 전 자동 수용 상수로 사용하지 않는다.

## 시뮬 기준
`seg5_v1`, 4000스텝, 집기 정렬 여유 ±1 cm·방향 약 4°, 끝 전환은 자기 명령 기록 규칙. 새 12장면 혼합 6/12와 ACT 단독 0/12는 전체 과제 성적이지 집기만의 성적 아님.

## PR 결과 상대경로와 형식
`experiments/sim2real-<YYYYMMDD>-T09-<run>/`: [공통 template](../04_tasks.md#result-template), `inference.csv`, `pick.csv`, `model_manifest.json`. 추론 CSV: `frame_id,preprocess_ms,inference_ms,total_ms,warmup,invalid_output`. 집기 CSV: `case_id,initialization,pick,lift,hold_s,transition,false_transition,drop,reason`. 모델 manifest에 자산 상대경로·sha256·전처리 버전을 적는다.
