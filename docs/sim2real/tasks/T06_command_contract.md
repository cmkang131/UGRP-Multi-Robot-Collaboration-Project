# T06 10 Hz 명령 계약 구현

## 목적
시뮬 명령을 실물 어댑터에 연결할 때 단위·타이밍·중첩·STOP 의미를 명확히 한다. 실물 결과는 **확인 안 됨**.

## 준비물
시뮬 command port, 가짜 transport, Pi의 실제 SDK/API 명세, monotonic 타임라인, 현장 비상정지. 기존 [구동 CLI](../../../scripts/masterpi_control.py)는 참고 자산이지 10 Hz 호환 보증이 아니다.

## 병렬 준비와 물리 통합
형식 검증·모의 실행은 독립. 실물 서보 연결에 T04 안전 범위가 필요하며 바퀴 물리 환산은 T03 결과로 별도 검증한다. T07과 이벤트 형식은 병렬 협의한다.

## 실행절차
1. [인터페이스](../02_robot_interface.md)의 4바퀴·5서보·주기·단위를 요청 검증기로 표현한다. 허용되지 않은 요청은 원문과 거부 이유를 남긴다.
2. 가짜 transport에서 정상·0길이·최대길이·범위 밖·중복·순서 역전·지연·단절·STOP을 시험한다.
3. **10 Hz/0.15 s 펄스 중첩 정책 미확인**을 해결한다. 시뮬 포트의 실제 타임라인을 읽고 덮어쓰기/큐잉/취소/STOP 동작을 담당자와 명세화한다. 정책 확정 전 연속 실물 구동 금지.
4. 무부하·바퀴 띄움에서 채널 방향과 정지부터 확인한다. 실물 SDK 변환·기구 범위를 확인하고 발행·적용·종료 시각을 기록한다.
5. 연결 끊김·프로세스 종료·오래된 명령 주입 때 로컬 정지와 재연결 후 자동 재개 방지를 확인한다. 정지 지연은 측정하되 근거 없는 안전 시간 한계를 만들지 않는다.

## 수치 통과기준
사용자 계약: 발행 목표 10 Hz, 4바퀴와 ID 1,3,4,5,6의 5서보, 명령 범위 일치. **초안 제안·실물 미검증·담당자 합의 필요:** mock에서 연속 1000틱, 기록 누락·중복 ID 0개, 발행 주기 중앙값 0.100 s ±0.005 s, P95 절대 주기 오차 ≤0.020 s. 부적합 요청의 실제 발행 0건. 실물은 같은 통계와 정지 지연을 별도 보고하며 현장 합의 전 통과를 승계하지 않는다.

## 기준의 근거
1000틱은 재현 가능한 타이밍 smoke 제안이고 5/20 ms는 100 ms 주기의 5%/20% 오차 예산 제안일 뿐이다. 하드웨어 측정 분포·제어 민감도 근거를 확보하기 전 코드 상수로 넣지 않는다. 안전 정지 시간 기준은 실물 위험 평가 전 미정이다.

## 시뮬 기준
10 Hz, 바퀴 0 또는 부호 있는 0.31–0.40, 펄스 0–0.15 s, 서보 PWM 500–2500. PWM 전체 범위는 **실물 스윕 허가 아님**. 중첩 의미와 실물 단위 변환은 확인 안 됨.

## PR 결과 상대경로와 형식
`experiments/sim2real-<YYYYMMDD>-T06-<run>/`: [공통 template](../04_tasks.md#result-template), `contract.md`, `timing.csv`. CSV: `command_id,case,t_issued,t_received,t_applied,t_stopped,requested,issued,rejection_reason`. 모든 시각의 clock domain을 명세에 적고 서로 다른 기기 시각 차이를 지연으로 단정하지 않는다.
