# T10 고정 순서 놓기 재생

## 목적
고정된 놓기 시퀀스의 초기 자세 민감도와 안전한 바닥 놓기를 분리 확인한다. 실물 결과는 **확인 안 됨**.

## 준비물
교사 시연 140개에서 만든 87행 고정 순서 자산·출처·해시, 초기 commanded pose 기록, 안전 지지대와 가벼운 물체, 비상정지. 최신 자산은 main 미포함.

## 병렬 준비와 물리 통합
명령 재생·범위 검사는 독립. 실물은 T04/06/07 필요. T09 성공을 기다리지 않고 현장 담당자가 안전하게 지지한 초기 상태로 분리 시험하되 수동 초기화와 지지 사용을 공개한다.

## 실행절차
1. 원본 87행의 순서·시각·서보/바퀴 값·초기 자세 조건을 확보하고 해시를 고정한다. 140은 시연 수이지 재생 행 수가 아니다.
2. 출력 없는 재생으로 명령과 초기 자세 호환성을 검사한다. 기구 범위 밖이면 즉시 거부하며 clipping한 것을 같은 시퀀스라고 부르지 않는다.
3. 무부하 안전 시험 후 지지된 가벼운 물체로 놓기를 시험한다. 자세 편차는 현장 확인한 범위만 사용한다.
4. 바닥 접촉 후 집게 해제·후퇴가 실제로 일어났는지 별도 평가한다. 중간 정지 시 자동 처음부터 재생하지 않는다.
5. 무부하/지지 사용/자유 놓기를 분리하고 시작 자세별 실패와 비의도 낙하를 기록한다.

## 수치 통과기준
계약 확인: 재생 행 수 87, 원본 순서·값 차이 0개(안전 거부는 실패로 기록). **초안 제안·실물 미검증·담당자 합의 필요:** 승인된 초기 자세에서 자유 놓기 10회 중 8회 이상 바닥에 놓고 집게 분리, 비의도 낙하·충돌 0건. 시각 허용오차는 T06 실제 정책·측정 후 합의하고 현재 임의 기준을 두지 않는다.

## 기준의 근거
87행·140시연은 사용자 제공 구성값이다. 8/10은 파일럿 목표이며 시뮬·실물 성공 근거가 아니다. 초기 자세 허용 분포가 확인되지 않으면 자동 재생 채택을 보류한다. 지지대가 성공을 만들어 준 시행은 자유 놓기 분모와 분리한다.

## 시뮬 기준
놓기는 ACT 자유 추론이 아니라 교사 시연 140개의 고정 순서 87행 재생. 집기 끝은 자기 명령 규칙이며 실제 들림을 보장하지 않는다. 87행을 10 Hz라며 자동으로 8.7 s 균등 시퀀스로 만들지 말고 원본 타임라인을 확인한다.
