# T11 지도 없는 문 통과·구역 도착

## 목적
물건을 들지 않은 로봇이 자기 카메라의 초록 벽·구역 색을 보고 이동하는지 확인한다. 실물 결과는 **확인 안 됨**.

## 준비물
초록 벽·문·색 구역, 무하물 로봇, 자기 RGB·명령 이력, 문 폭/차체 폭 실측 도구, 비상정지. 공용 TOP·정적 지도·AprilTag·실시간 정답 입력은 금지한다.

## 병렬 준비와 물리 통합
저장 영상 문 검출·모의 이동은 독립 준비. 실물은 T01/02/03/06/07 산출물이 필요하며 가동 팬을 쓰면 T05도 필요하다. 집기·놓기는 선행 과제가 아니다.

## 실행절차
1. 미리 만든 지도를 입력하지 않고 자기 카메라의 벽 틈·색 구역만으로 탐색하는지 감사한다. 실제 문 폭·차체/팔 외곽을 수기로 확인해 통과 안전성을 판단한다.
2. 모서리·그림자·가려진 문을 포함해 저장 영상 검출을 확인한다. 구역 색 값은 해당 환경 버전과 실제 사진을 기록하며 임의 새 팔레트를 만들지 않는다.
3. 무부하 정지 시험 후 문 통과와 구역 도착을 별도 실행한다. 목표 소실·벽 접근·충돌 징후는 중단한다.
4. 외부 수기 평가로 차체 전체가 문 반대편으로 넘어갔는지, 목표 구역 안에 멈췄는지 기록한다. 평가 결과를 제어 전환으로 보내지 않는다.
5. 전체 계획·진입·통과·도착 수와 막은 물체/최소 틈을 남긴다. 구역 경계의 평가 정의는 실행 전 고정한다.

## 수치 통과기준
**초안 제안·실물 미검증·담당자 합의 필요:** 미사용 문 배치 12개 중 11개 이상 통과, 구역 도착 6개 중 5개 이상, 충돌 0건. 문/구역 결과는 분리하며 단계 미진입도 전체 분모에서 보인다. 금지된 지도·TOP·GT 입력 0건은 입력 제한이다.

## 기준의 근거
11/12·5/6은 시뮬 수준과 같은 규모의 실물 비교 목표 제안이지 실물 검증치나 일반화 기준이 아니다. 문 여유 폭·정지 위치 허용치는 실제 치수와 정지 오차를 잰 뒤 합의하며 임의 상수로 정하지 않는다.

## 시뮬 기준
지도 없이 초록 벽 색으로 문 통과 11/12, 구역 도착 5/6. 벽 RGBA `.05 .27 .14 1`. 적재 주행·공동 운반으로 확대 해석하지 않는다.
