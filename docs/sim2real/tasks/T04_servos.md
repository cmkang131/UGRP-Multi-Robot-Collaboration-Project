# T04 서보 PWM–각도와 집게 폭

## 목적
관절별 안전 범위·PWM–각도·정착 시간과 집게 열림 폭을 실측한다. 실물 결과는 **확인 안 됨**.

## 준비물
기구/케이블 상태 점검, 안전 지지대, 자·각도기·캘리퍼스, 무부하 로봇, 현장 비상정지 수단. 전원 차단 시 팔 낙하 방지를 먼저 준비한다.

## 병렬 준비와 물리 통합
독립된 벤치 측정이다. T06 전체 구현 없이 기존 안전한 단일 서보 도구를 사용할 수 있다. 다른 과제와 같은 관절을 동시에 제어하지 않는다.

## 실행절차
1. 전원·기구 확인 후 로봇별 허용 자세와 각 관절의 움직일 수 있는 범위를 먼저 기록한다. **PWM 500–2500은 시뮬 계약이지 실물 전범위 스윕 허가가 아니다.**
2. 무부하·바퀴 띄움에서 확인된 안전 자세로 시작해 한 관절씩 작은 승인된 변화만 준다. 옛 문서의 500/2500 끝값이나 중앙 1500을 무조건 보내지 않는다.
3. 같은 PWM의 접근 방향을 바꿔 각도·히스테리시스·정착 시간을 측정한다. 떨림·과열·간섭이 있으면 즉시 중단하고 실패 범위를 남긴다.
4. 집게는 승인된 범위 안에서 안쪽 폭·외곽 폭을 재고, 가벼운 시험 물체는 별도 하중 조건으로만 확인한다. 강제로 끝까지 닫지 않는다.
5. [기존 측정 양식](../../../configs/real_measurements_template.json)에 반복값·단위·안전 범위·출처를 기록한다.

## 수치 통과기준
**초안 제안·실물 미검증·담당자 합의 필요:** ID 1,3,4,5,6의 5/5 채널 식별 및 안전 범위 기록, 관절별 승인된 표본 위치 3개 이상에 양방향 각 3회 측정. 집게 폭도 승인된 3개 위치에서 각 3회 측정. 안전 범위 밖 명령 발행 0건. 범위가 좁아 표본 확보가 안 되면 억지로 확장하지 않고 `blocked`로 기록한다.

## 기준의 근거
3개 위치는 기울기와 비선형 징후를 비교하는 최소 초안, 3회 반복은 기존 프로토콜의 반복 원칙을 따른다. 옛 서보 끝점 MAE 3° 기준은 [실측 절차](../../sim2real_measurement_protocol.md)의 역사적 기준이며 최신 파지 안전·정확도 보장이 아니다. 채택 오차는 실측 분포와 기구 사양으로 합의한다.

## 시뮬 기준
서보 5개 ID 1,3,4,5,6, PWM 500–2500. 실물 PWM–각도와 집게 폭은 확인 안 됨. 발행값을 실제 각도로 간주하지 않는다.

## PR 결과 상대경로와 형식
