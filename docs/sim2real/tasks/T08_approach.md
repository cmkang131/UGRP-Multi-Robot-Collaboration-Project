# T08 색 추종 접근만 실물 검증

## 목적
집기를 끈 상태에서 상자 정면까지 접근·정지하는 능력과 실패 원인을 분리한다. 실물 결과는 **확인 안 됨**.

## 준비물
hybrid 접근 코드(현재 main 미포함), 빨강·파랑 상자, 자기 RGB, 자기 명령 이력, 자·각도기, 비상정지와 감시자. 초기 지정상자 방위·거리의 획득 방법을 기록한다.

## 병렬 준비와 물리 통합
저장 영상·시뮬 접근 시험과 실패 분석은 독립 준비 가능. 실물에는 T01 색, T02 카메라, T03 펄스, T06 명령, T07 기록 산출물이 필요하다. 팬을 움직이는 구성에서만 T05가 추가로 필요하다. T09 집기를 기다리지 않는다.

## 실행절차
1. 초기 방위·거리 제공자를 정하고 시작 시 **1회만** 전달한다. 자동 GT 공급·반복 갱신으로 확대하지 않는다. 정보 제공 방법이 미정이면 실물 실행을 보류한다.
2. 집기 출력을 차단한 채 색 검출·추종·자기 명령 기반 이동 추정 로그를 저장 영상에서 검증한다.
3. 안전 거리와 기구 상태를 현장에서 확인하고 무부하 단일 접근을 실행한다. 목표 소실·정지 실패는 중단하고 실패 이유를 남긴다.
4. 접근 종료 후 자·각도기로 거리·횡방향·방향 오차를 잰다. 측정값을 제어에 되먹이지 않는다.
5. 조정 장면과 미사용 장면을 분리해 평가하고 접근 진입·정지·정렬 관문별 n/N을 낸다.

## 수치 통과기준
목표는 상자 정면 0.20 m, 집기 정렬 여유는 ±1 cm·방향 약 4°다. **초안 제안·실물 미검증·담당자 합의 필요:** 미사용 12배치 중 10개 이상에서 정지 거리 오차와 횡방향 오차 각각 ≤0.01 m, 방향 오차 ≤4°. 평가 기준점(차체/집게 중 어디인지)을 실행 전 고정하고 충돌 0건을 별도 보고한다. '약 4°'를 정확한 ≤4° 판정으로 쓰는 부분도 초안 해석이다.

## 기준의 근거
오차 예산은 집기 여유에서 가져왔지만 실물에 적용 가능한지 미검증이다. 12배치는 기존 시뮬 비교 규모, 10/12는 검토용 목표일 뿐 통계적 보장이 아니다. 거리 기준점과 오차 전파·실물 분포 합의 전 코드 수용 상수로 사용하지 않는다.

## 시뮬 기준
조정하며 본 12장면 11/12, 새 12장면 혼합 전체 과제 6/12, ACT 단독 0/12. 실패 6개 모두 접근. 이 전체 과제 수치를 접근 전용 성공률로 바꾸지 않는다. 현재 상자 위치를 계속 추정·추적하는 구조로 변경 중이며 main 미포함.
