# T03 바퀴 펄스·불감대 보정

## 목적
전진·후진·옆걸음·회전의 펄스당 실제 변위와 정지 지연을 잰다. 실물 결과는 **확인 안 됨**.

## 준비물
실제 바닥, 로봇, 안전한 단일 펄스 구동 도구, 자·각도기, 전압 기록, 현장 감시자·비상정지. 외부 측정은 오프라인 평가용이고 공용 TOP·지도·AprilTag는 쓰지 않는다.

## 병렬 준비와 물리 통합
측정표·단일 펄스 벤치는 독립 가능. T06의 중첩 정책이 확정되기 전에는 10 Hz 연속 펄스 시험을 하지 않는다.

## 실행절차
1. 바퀴를 안전하게 띄우고 채널·방향·STOP을 무부하 확인한다. 바닥 시험 전 공간·기구 상태를 점검한다.
2. [기존 주행 측정법](../../sim2real_measurement_protocol.md) 중 수기 시작/끝 측정을 쓴다. 현재 계약과 다른 옛 장시간 펄스 표를 그대로 실행하지 않는다.
3. 실물 허용 범위 안에서 전후·좌우·양 회전을 따로 측정한다. 0.10 s 기준 펄스와 안전하게 승인한 길이들을 비교하고 매 회 시작 기준으로 되돌린다.
4. 명령 크기별 움직임 시작 여부를 기록해 불감대를 찾고, 정지 후 추가 이동·횡편차·회전 오차를 잰다. 전압·바닥·하중을 분리한다.
5. 적합에 쓰지 않은 반복을 남겨 예측 잔차를 보고한다. SDK 속도와 정규화 명령의 대응은 실측 후에만 고정한다.

## 수치 통과기준
**초안 제안·실물 미검증·담당자 합의 필요:** 전후/좌우/양회전 6방향 각각 0.10 s 펄스 5회 이상을 기록하고 그중 2회 이상은 적합에서 제외해 검증한다. 각 방향의 변위·회전·정지 거리·불감대 측정 커버리지 100%, 누락 이유 없는 행 0개. 정확도 허용치는 먼저 잰 분포로 제안하며 현재는 계측 준비 통과이지 동역학 채택 판정이 아니다.

## 기준의 근거
5회/2회는 방향별 반복성과 최소한의 독립 확인을 분리하려는 초안 설계로 통계적 보장 없음. 6방향은 전후·좌우·양회전의 열거다. 실물 변위를 시뮬 값과 같게 맞추는 것은 합격 조건이 아니다.

## 시뮬 기준
바퀴 4개, 0 또는 부호 있는 0.31–0.40, 펄스 0–0.15 s. 0.10 s 전진 약 11–12 mm, 회전 약 0.09 rad(장면별 0.06–0.095 rad). 옆걸음 실측 기준은 미제공. 10 Hz/0.15 s 중첩 정책은 미확인.

## PR 결과 상대경로와 형식
`experiments/sim2real-<YYYYMMDD>-T03-<run>/`: [공통 template](../04_tasks.md#result-template), `pulses.csv`, `wheel_fit.json`. CSV: `trial,split,direction,wheel_values,pulse_s,dx_mm,dy_mm,dyaw_rad,stop_mm,voltage_v,floor,load_kg,reason`. 기존 fitter 입력은 [보정 JSONL](../../../calibration/masterpi/README.md)로 별도 변환하고 원본을 보존한다.
