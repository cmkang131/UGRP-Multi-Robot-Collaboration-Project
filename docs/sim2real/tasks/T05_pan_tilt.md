# T05 팬·기울기 환산

## 목적
서보 명령 변화가 자기 카메라 광축과 픽셀을 어느 방향으로 움직이는지 확인한다. 실물 결과는 **확인 안 됨**.

## 준비물
고정된 자기 카메라, 안전한 서보 도구, 각도기, 고정 물체 사진, T02 내부/장착 보정값과 T04 안전 범위. 공용 TOP·지도·AprilTag는 사용하지 않는다.

## 병렬 준비와 물리 통합
저장 영상 분석·환산 함수는 병렬 준비 가능. 실물 구동은 T04 안전 범위, 영상에서 각도로 적합하는 부분은 T02 보정값이 필요하다. 둘 다 전체 과제 종료가 아니라 필요한 산출물만 받는다.

## 실행절차
1. 팬/틸트 축 정의와 부호를 적는다. ID6 팬과 ID3/4/5가 기울기에 미치는 결합을 독립 측정하며 단일 고정 이득을 가정하지 않는다.
2. 무부하·비상정지 준비 후 허용된 자세에서 한 서보씩 변화시키고 발행값·프레임·외부 측정 각도를 연결한다.
3. 양방향 이동·돌아오기에서 잔차를 재고, 카메라 왜곡과 원근 때문에 위치별 픽셀/PWM이 달라지는지 확인한다.
4. 적합에 쓰지 않은 자세에서 예측 광축과 측정을 비교한다. 보정 보드를 썼다면 offline 측정 후 제거한다.

## 수치 통과기준
**초안 제안·실물 미검증·담당자 합의 필요:** 승인된 자세 3개 이상에서 각 양방향 3회, 부호 판정 일치 100%, 미사용 자세 광축 각도 MAE ≤2°. 불가능한 자세는 제외 사유와 전체 계획 분모에 남긴다.

## 기준의 근거
2°는 사용자 제공 집기 방향 여유 약 4°의 일부만 시선 환산 오차에 쓰자는 검토용 예산이다. 실제 오차 전파·팔 길이·카메라 자세 검증 전에는 유효한 안전 한계가 아니다. 3개/3회는 자세 의존성과 되돌림을 드러내는 초안 표본 수다.

## 시뮬 기준
입력 640×480 어안, 모델 320×240, 서보 ID 1,3,4,5,6의 PWM 500–2500 계약. 최신 hybrid의 실물 팬/틸트 계수는 미제공이며 과거 픽셀/PWM 값을 그대로 채택하지 않는다.

## PR 결과 상대경로와 형식
