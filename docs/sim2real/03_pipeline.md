# 03 혼합 방식과 실물 위험

[안내](README.md) · [인터페이스](02_robot_interface.md) · [과제 목록](04_tasks.md)

## Solo 단계

2026-11-14 구성이다. 코드는 [`solo_pipeline/`](../../solo_pipeline/README.md)에 있고 실물은 전부 **확인 안 됨**이다. 과거 [ACT 실행 결정](../act_execution_decisions.md)은 설계 이력으로 참조하고, 아래 혼합 구성과 같은 버전이라고 하지 않는다.

| 단계 | 현재 시뮬 구성 | 실물 위험 | 독립 과제 |
|---|---|---|---|
| 둘러보기 | 제자리에서 카메라를 돌려 본 상자의 방위·거리를 추정해 관측 목록을 만드는 코드. 과제는 목록의 번호만 준다 | 카메라 자세 오차에 따른 방위·거리 오차, 뒤쪽 상자를 못 봄 | [T02](tasks/T02_camera.md), [T08](tasks/T08_approach.md) |
| 접근 | 관측 목록의 지정 상자로 다가가 0.20 m 앞에 서는 코드. 자기 카메라의 색 덩어리 추적 | 펄스 이동량·회전량 오차 누적, 색 소실·유사색 오인 | [T08](tasks/T08_approach.md) |
| 정면 맞추기 | 상자 아래 윤곽으로 면의 기울기를 읽어 넓은 면 정면에 서는 코드. 상자가 잘렸으면 다시 보이게 한 뒤 맞춤 | 옆걸음 펄스의 실제 이동량, 미끄러짐, 조명에 따른 윤곽 오차 | [T08](tasks/T08_approach.md) |
| 집기·들기 | ACT, 색 구분 입력 `seg5_v1`, 4000스텝 | 접근 종료 정렬 여유 ±1 cm·방향 약 4°가 작음. 전처리·카메라·서보 편차로 파지 실패 가능 | [T09](tasks/T09_act_pick.md) |
| 집기 끝 전환 | 자기 발행 명령 기록 규칙 | 명령을 보냈다는 사실을 실제 들림으로 오인할 위험. 접촉·GT 성공으로 전환 보정 금지 | T09 |
| 놓기 | 교사 시연 140개의 고정 순서 87행 재생 | 시작 팔 자세·상자 위치·하중이 다르면 고정 궤적 충돌·낙하 가능 | [T10](tasks/T10_release.md) |

시작 정보는 로봇이 둘러보고 만든 관측 목록에서 나온다. 2026-11-13 까지의 접근 코드(`c7232b9`)는 시작할 때 지정 상자의 방위·거리를 장면 정의의 실제 위치에서 계산해 받았고, 그 조건의 결과는 지금 구조의 결과와 섞지 않는다. 구조 전체는 [Solo 구조와 모델](../solo_architecture.md)에 있다.

0.20 m는 접근 목표이고, ±1 cm·약 4°는 집기 정렬 여유다. 이 값이 실물 안전 허용오차로 검증됐다는 뜻은 아니다. 바퀴 0.10 s 펄스가 시뮬에서 약 11–12 mm 움직여 1 cm 여유와 비슷한 크기인 만큼, 실물 펄스 보정과 정지 오차 분포가 중요하다. 임의로 이득·허용오차를 늘려 통과시키지 않는다.

## 무하물 이동과 로봇 간 통신

[T11](tasks/T11_navigation.md)은 자기 카메라 초록 벽 색으로 문을 찾는 별도 무하물 과제다. Solo 집기 모델이 구역 운반까지 학습했다거나 적재 이동이 검증됐다는 뜻이 아니다.

로봇 간 통신은 [연구 설계](../research_design.md)의 팀 구조 실험에 쓴다. [T12](tasks/T12_robot_messaging.md)의 메시지 왕복 검증은 협업 과제 성공과 별개다. 메시지에는 각 로봇이 본 것과 한 일만 담고, 정답 좌표·GT·단계 라벨을 전달하지 않는다. 두 로봇이 한 물체를 맞잡아 옮기는 과제는 연구 범위에서 뺐다.

## 코드 이관 전에 확인할 목록

참조 식별자 `hybrid-v2` / `c7232b9`이다. 아래는 **이관 대상 역할과 저장소 내 목적지 제안**이며 실제 파일 대응·가중치 배포 상태는 확인 안 됨이다.

| 필요한 자산 | 이관 목적지 제안 | 이관 완료 증거 |
|---|---|---|
| 접근·색 추적·명령 기반 전환 | `harness/` | 원본 상대경로/SHA와 차이, GT 입력 감사, 같은 장면 재실행 |
| `seg5_v1` 전처리·ACT adapter | `harness/` | 채널 순서·resize·정규화 명세, 고정 입력 비교 |
| 4000스텝 모델 및 설정 | 기존 [모델 배포 경로](../model_artifacts.md) | 체크포인트·설정 해시, 로딩·추론 검증, 임의 구모델 대체 금지 |
| 140시연 출처·87행 놓기 자산 | `configs/`의 버전 자산과 `experiments/`의 출처 기록 | 순서·시각·명령 해시, 초기 자세 조건 |
| 최신 벽·상자 색과 물리 프로필 | `sim/`, `configs/` | 장면·카메라·접촉 프로필 해시와 실제 렌더 |
| hybrid 실행 진입점 | `scripts/`, 기존 `configs/simulation_workflows.json` 등록 | [표준 관리](../simulation_management.md)에서 경로 해소 및 전체 재실행 |
| 개발/미사용 12장면 목록·채점·감사 | `experiments/`, 작은 fixture는 `tests/` | 분할·전체 분모·실패 원장·평가 분리 |

이관 이후에도 실물 전용 계약·안전 확인은 별도로 수행한다. 이관 목적지는 이번 문서 작성의 수정 범위가 아니다.
