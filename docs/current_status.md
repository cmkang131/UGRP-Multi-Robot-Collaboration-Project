# 지금 하는 일

2026-11-14 기준. 이 문서는 방향이 바뀔 때만 고친다. 실험 수치와 날마다의 진행은 팀 Linear(UGRP 팀)에 적는다.

## 목표

부분 관측에서 LLM 이 짠 작업 계획이 팀 구조에 따라 얼마나 달라지는지 비교한다. 전문은 [연구 설계](research_design.md).

## 갈래별 상태

| 갈래 | 상태 | 문서 |
|---|---|---|
| 팀 구조 비교 실험 (계획 전용 환경) | 환경을 만드는 중. 실험 결과는 아직 없다 | [연구 설계 6절](research_design.md) |
| 로봇 한 대가 상자를 집고 놓기 (시뮬레이션) | 자기 카메라만으로 상자를 찾아 다가가 집고 내려놓는 데까지 됨. 상자를 든 채 옮기는 것은 아직. 코드는 `solo_pipeline/` | [Solo 구조와 모델](solo_architecture.md) |
| 실물로 옮기기 | 과제 카드 13개를 준비했다. 실물 시험은 아직 한 것이 없다 | [Sim2Real 안내](sim2real/README.md) |
| 두 로봇이 한 물체를 맞잡아 옮기기 | 연구 범위에서 뺐다 | [연구 설계 0절](research_design.md) |
