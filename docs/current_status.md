# 지금 하는 일

2026-11-17 기준(로봇 3대 본 실험 동결 뒤). 이 문서는 방향이 바뀔 때만 고친다. 실험 수치와 날마다의 진행은 팀 Linear(UGRP 팀)에 적는다.

## 목표

부분 관측에서 LLM 이 짠 작업 계획이 팀 구조(통신 없음, 모두 동등, 팀장 있음)에 따라 얼마나 달라지는지 비교한다. 전체 설계는 [연구 설계](research_design.md), 이번 제출의 지표와 검정은 [연구 설계 11절](research_design.md#11-이번-제출의-동결-설계-2026-11-16)에 있다.

## 갈래별 상태

R: T0 38.3%, T1 84.4%, T2 75.0%. 2차는 T1 동등(RoCo·DMAS 식 차례 대화)과 T2 팀장(HMAS-2 식 제안·검토, 로봇들이 뽑은 팀장)을 메시지 제한 없이, 기본·메시지 30% 손실·60초 팀장 고장에서 비교한다(장면 9, 126회). 지금은 3회씩 시험하며 고치는 단계다. 주 지표는 R 과 감점 없는 R0. [전체 구조](architecture.md) | [작업 계획](plan.md), [연구 설계 11절](research_design.md#11-이번-제출의-동결-설계-2026-11-16) |
| 메시지 규칙과 내려놓기 | 메시지는 행동에 덧붙여 보내고(차례를 쓰지 않음), 새 메시지를 받으면 이동 중에도 답장할 기회가 한 번 온다. 로봇당 8개까지이고 LLM 에게 상한과 감점을 알린다. 든 상자를 내려놓고 끝내는 행동이 모든 구조에 있다. 이번 실험에서 로봇은 상자를 한 번만 나른다 | [계획기와 메시지 규칙](planning_messages.md) |

| 로봇 3대 | 모든 실험이 3대다. 4대·8대는 2차 뒤의 후속 설계로만 있다 | [작업 계획 3절](plan.md#3-순서와-일정) |
