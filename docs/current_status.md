# 지금 하는 일

2026-11-14 기준. 이 문서는 방향이 바뀔 때만 고친다. 실험 수치와 날마다의 진행은 팀 Linear(UGRP 팀)에 적는다.

## 목표

부분 관측에서 LLM 이 짠 작업 계획이 팀 구조에 따라 얼마나 달라지는지 비교한다. 전문은 [연구 설계](research_design.md).

## 갈래별 상태

| 갈래 | 상태 | 문서 |
|---|---|---|
| 팀 구조 비교 실험 | LLM 이 고른 대로 MuJoCo 에서 로봇이 실제로 움직이는 실험으로 한다. 로봇 2대 동시 실행과 LLM 연결을 만드는 중. 계획 전용 환경의 실험은 접었다 | [작업 계획](plan.md), [전체 구조](architecture.md) |
| 로봇 한 대의 동작 (시뮬레이션) | 자기 카메라만으로 상자를 찾아 집고, 든 채 문을 지나, 지정한 바닥 색 구역에 놓는 데까지 된다. 문과 구역은 본 것을 기억하고, 모르면 직접 찾거나 들은 위치를 쓴다. 장면에 상자만 있을 때다. 문이 안 보이거나 길이 막히면 멈춘다 | [Solo 구조와 모델](solo_architecture.md) |
| 계획과 동작 잇기 | 아직 없다. 계획기의 선택을 시뮬레이션 동작으로 넘기는 것, 여러 로봇이 동시에 움직이는 것 모두 아직 | [전체 구조 5절](architecture.md) |
| 실물로 옮기기 | 과제 카드 13개를 준비했다. 실물 시험은 아직 한 것이 없다 | [Sim2Real 안내](sim2real/README.md) |
| 두 로봇이 한 물체를 맞잡아 옮기기 | 연구 범위에서 뺐다. 그 과제에 쓰던 긴 막대와 그 밖의 물건도 장면에서 뺐다 | [연구 설계 0절](research_design.md) |
