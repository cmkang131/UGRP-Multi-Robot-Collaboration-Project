# 표 해석

`scaling.json`·`timing-table.md`·`rejection-table.json`은 gcp2에서 원본으로 생성하고 세 데이터 파일의 SHA를 회수 뒤 확인했다. setup은 제외하고 프로파일 구간은 중첩되므로 합산하지 않는다. 0.3SIM 행의 환산은 짧은 고정 작업의 평균이다. HOST_ERROR 행은 미완료 구간이며 첫30 중앙값이 아니다. 세 번째는11.4SIM까지 완료하고 다음11.5 export에서 실패하여 그 마지막 부분 비용은 progress 표에 없다. 접촉 평가 출력의 의미적 정확성 결함 때문에 임무 자격을 주장하지 않는다.
