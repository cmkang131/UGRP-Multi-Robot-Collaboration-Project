## 가설과 검증 범위

자기 손목 영상에서 이동하는 어두운 바닥의 밝기 무늬가 보이면, 자기 명령 시작 때의
영상 변화에 비해 이후 변화가 작아지는 것으로 정체를 검출할 수 있다.
주 가설은 아래 전체 수용 기준을 주 설정 `(0.4, 2)`가 새 자료에서 만족한다는 것이다.
보조 설정 `(0.5, 3)`은 별도로 보고하며 주 설정의 실패를 구제하지 않는다.
기존 탐색의 18/18 로봇 구간 검출·0/90 오경보는 새 가설의 근거이지 확증 결과가 아니다.

## 입력 경계

검출 함수에는 **해당 로봇의 자기 손목 RGB, 그 영상의 시각, 자기 발행 명령 구간**만 전달한다.
공용 top RGB, 상대 로봇 영상/STATUS/좌표, PF 위치·공분산, 초음파, 관절 측정,
접촉·물체 ID·성공 여부·시뮬레이터 상태·GT 라벨을 받지 않는다.
SIM 시각은 영상/명령에 붙은 시각 메타데이터로만 사용한다.
팔/운반 자세의 대상 여부도 자기 발행 명령 이력에서 정하고 실제 파지 판정으로 고르지 않는다.
교사 staging과 평가자는 별도 경로에서 GT를 쓸 수 있다. GT 파일은 검출기의 입력 스키마에 없다.

## D1 정의와 동결할 수치

아래는 추천 D1의 블록 차이와 잡음 바닥 보정을 명시한 것이다.
`d1_detector.py`는 이 정의를 NumPy만으로 계산하고 파일을 읽거나 행동을 실행하지 않는다.

| 항목 | 동결 후보 |
|---|---|
| 영상 | 640×480, RGB 순서, 0–255. 회색값은 `round(0.299 R + 0.587 G + 0.114 B)`; 회색 배열은 산술 재생용으로 허용 |
| 어두운 가운데 ROI | 1초 쌍 모두에서 `3 < gray < 60`; 열 `[200:440]`의 어두운 비율이 **>0.9**인 행 ≥40. 첫 행+10부터 마지막 행−10까지(끝 제외), 높이 ≥32. 실제 점수 열은 `[100:540]` |
| 블록 | **16×16 픽셀**, 우측/하단 잔여 픽셀 버림. 16×16개 격자로 리사이즈하는 뜻이 아님 |
| 시각 | 긴 차이 1.0 s, 짧은 차이 0.1 s, 검사 주기 0.2 s. 시각은 SIM초; 실제 카메라 검증은 별도 |
| 프레임 선택 | 각 예정 시각 이하의 가장 최근 프레임. 목표와 차이 ≤0.11 s(±1 프레임 지터 허용). 미래 프레임·보간 금지. 긴 쌍의 실제 간격도 1.0±0.11 s; 짧은 쌍은 현재 프레임 시각−0.1 s에서 선택 |
| 명령 구간 | 자기 이력의 일정한 방향·속도의 **비영 병진** 연속 구간 `[t_on,t_off)`, ≥5 s. 중지·만료·속도/방향 변경 때 분리. 회전/팔 동작만 있는 구간은 별도. 탐색의 ≥0.03 m/s 제한을 적용하지 않아 느린 대조도 포함 |
| 기준 | 예정 시각이 시작 **1–3 s**(양끝 포함)인 유효 `f`의 **중앙값**. 11회 중 ≥5회 필요. 그동안 경보 없음 |
| 판정 | 시작 3 s **이후**, `f < ratio × f_ref`가 **k회 연속**이면 `STALL_SUSPECT`. 이후 같은 조건이면 계속 경보. 정상/결측/ROI 무효 검사에서 연속 횟수 초기화 |
| 주/보조 | 주 **(ratio=0.4, k=2)**, 보조 **(0.5, 3)**. k는 0.2 s 간격의 검사 횟수이며 k초가 아님 |
| 부족한 자료 | <5 s는 `UNSUPPORTED_SHORT_COMMAND`; 기준 유효 <5회는 `INSUFFICIENT_REFERENCE`; 기준 ≤1e−12는 `INSUFFICIENT_SIGNAL`. 경보 없음과 구분해 보존하고 아래 실패 분모에 포함 |

ROI 안에서 두 회색 프레임의 **부호 있는 차이** `I_b−I_a`를 각 블록에서 평균해 `b_j`를 만든다.
`F(I_a,I_b) = mean_j(abs(b_j − mean_j(b_j)))`.
즉 전체 블록 평균을 뺀 **뒤** 절댓값을 취한다. 픽셀 절댓값을 먼저 평균하는 MAD와 다르다.
짧은 쌍에도 같은 긴 쌍 ROI를 쓰고, 모든 조건에서
`f(t) = sqrt(max(F_1s(t)^2 − F_0.1s(t)^2, 0))`로 잡음 바닥을 뺀다.
이는 잡음 모델의 근사이며 0.1초 실제 이동도 일부 빼 버린다. 순수 렌더의 `F_1s`도 진단 열로 보존하되
확증 중 잡음 유무에 따라 판별량을 바꾸지 않는다. 전역 평균 제거는 균일한 밝기 **덧셈**을 지우며,
노출 **배율**·공간 조명 변화를 완전히 지운다는 주장은 하지 않는다.

## 평가 라벨·분모·수용 기준

GT는 검출 완료 뒤 분리된 평가에서만 결합한다. 1초 창의 자기 발행 병진 적분 크기 `m>0`에 대해,
GT 차체 이동 크기 `d ≤0.3m`이면 STALL, `d ≥0.6m`이면 MOVING, 사이는 OTHER로 기록한다.
탐색의 `m≥25 mm` 제한은 기어감 대조를 없애므로 적용하지 않으며 이 차이를 별도 보고한다.
첫 STALL 창의 시작(창 끝−1 s)을 정체 시작으로 고정한다. 시작 이전 경보는 오경보로 기록하고
정체 검출로 세지 않는다. 영향을 받을 로봇과 조작 시작 시각은 staging manifest에 미리 고정하고,
GT로 실제 조작 성립 여부를 확인한다. 조작 불성립/가드 선중단은 목록에 남기고 봉인한 예비 셀로 대체한다.
실제 STALL인 케이스의 무경보·기준 부족·ROI 없음은 **누락**, MOVING인데 출력 불능은 **관측 실패**다.
MOVING 60건에 유효 평가를 못 하면 0건 경보만으로 통과시키지 않는다. 각 구간이 `EVALUATED`이고
기준 이후 예정 검사의 ≥95%에 유효 점수가 있어야 한다(이 초안의 관측 실패 처리 추가 기준).

| 항목 | 주 설정의 수용 기준(연구 §3.2 계승) |
|---|---|
| 표본 | 실제 정체 ≥24 독립 케이스·≥4기전; 계획은 30개/5종. 실제 이동 ≥60 독립 구간, 여러 바닥·조명·leg·속도 |
| 감도 | 전체 ≥90%, **양측 Wilson 95% 하한 ≥70%**, 기전별 ≥75%. 예: 24건이면 ≥22건, 30건이면 ≥27건 필요 |
| 오경보 | 이동 구간 **0/60**, 단측 95% 상한 ≤5%; 이동 검사 창 경보율 ≤1%. 정체 전 이동 창의 경보도 따로 보고 |
| 지연 | 검출한 정체의 중앙값 ≤3 s, p90 ≤6 s(NumPy linear quantile). 누락 수를 함께 보고; 두 로봇 케이스 지연은 필요한 경보 중 늦은 시각. 추가 발행 거리와 GT 밀림도 별도 보고 |
| 잡음·노출·시각 | 저장 렌더에 읽기 잡음 σ={0,1,2} 밝기 단계, 프레임별 노출 배율 jitter σ={0,0.01}, 시각 지터 {없음,±0.1 s}의 **12조합** 모두에서 감도·오경보 유지. 지연도 같은 문턱으로 보고 |
| 동결 | 코드 SHA·전체 파라미터·ROI·색 변환·라벨·시드·배치·예비 셀·환경/지도/카메라/접촉/렌더 해시·분석식을 첫 확증 프레임 생성 **전** 고정 |
| 기각 | 하나라도 실패하면 전체 가설 기각 또는 사전에 적힌 제한된 잡음 범위만 보고. 보조/사후 재조정 통과로 주 실패를 대체하지 않음 |

Wilson 하한은 `p=x/n`, `z=1.959963984540054`일 때
`(p + z²/(2n) − z sqrt(p(1−p)/n + z²/(4n²))) / (1+z²/n)`이다
([NIST 공식](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm), 2026-09-30 확인).
독립 이동 구간에서 경보 0건일 때 **rule of three**의 근사 단측 95% 상한은 `3/n`:
**3/60=5%**. 정확한 단측 이항 상한 `1−0.05^(1/60)≈4.87%`도 병기한다.
양측 95% 상한이나 "위험 0%"로 표현하지 않는다
([Hanley·Lippman-Hand 원 논문](https://jhanley.biostat.mcgill.ca/Reprints/If_Nothing_Goes_1983.pdf), 1983).
로봇별 창과 같은 case의 잡음 변형은 독립 표본 수를 늘리지 않는다.

합성 잡음은 RGB를 회색으로 바꾼 뒤 `clip(round(gray×(1+N(0,jitter))+N(0,σ)),0,255)`로 만든다.
프레임마다 한 번만 변형하고 여러 검사에서 같은 프레임을 재사용한다(탐색의 쌍별 재잡음과 구분).
시각 지터는 프레임마다 {-0.1,+0.1} s를 적용한 뒤 시각순 정렬하고 동시 시각은 원래 index가 작은 것을
남긴다. 명령 시각은 바꾸지 않는다. 고정 RNG 시드 93001/93002/93003을 각 조합에 모두 적용하며
각 시드에서 문턱을 만족해야 한다. 더 많은 창을 만들거나 결측을 보간하지 않는다.

## 실패 유형과 threats to validity

- **탐색 파라미터 선택**: ratio 0.4/0.5, k 2/3은 기존 자료를 본 뒤 골랐다. 같은 영상·배치 재생은
  독립 확증이 아니다. 기존 9건은 벽 접촉 한 종류이고 유효 독립 표본은 약 2–3개, 이동도 약 10곳이다.
- **몸 정지·팔 흔들림 → 누락**: 카메라가 움직이면 밝기 무늬가 변해 정체 신호가 사라진다.
  합성 프레임 변화만으로 팔 흔들림의 물리적 크기/빈도를 검증한 것으로 보고하지 않는다.
- **시작부터 막힘/짧은 명령 → 기준 없음**: 1–3 s 자기 기준은 정상 초기 이동을 가정한다.
  시작 정체 6개를 모두 놓치면 최대 24/30=80%로 전체 90% 기준에 못 미친다. 정의를 몰래 바꿔 구제하지 않는다.
- **균일한 바닥/ROI 소실 → 오경보 또는 관측 실패**: dark ROI는 조명 프로필·짐/팔 자세에 의존한다.
  밝은 바닥에서 dark ROI가 없어지는 것을 "정상 무경보"로 세지 않는다.
- **옆으로 미끄럼/50% 느려짐 → 누락 가능**: D1은 위치·방향을 재지 않는다. 이동 크기가 큰 방향 오류는
  기존 norm 기반 STALL 라벨 밖의 진단 실패로 별도 표기하고, 안전 통과로 표현하지 않는다.
- **잡음 근사**: 짧은 차이에는 실제 이동이 섞이고 독립 읽기 잡음·노출 배율만으로 모션 블러,
  롤링 셔터·자동 게인·50/60 Hz 깜빡임·반사·JPEG 변화를 대표할 수 없다. 수정 회색 변환과 인과적
  프레임 선택은 탐색 OpenCV/미래쪽 선택과 바이트 동일하지 않으며 새 버전으로 재검증한다.
- **상관/선택 편향**: 겹치는 1초 창, 두 로봇, 반복 PF seed, 소수 지도·바닥은 Wilson/3/n의 독립성
  가정을 약하게 한다. 새 배치/물리 조건 단위로 세고, 독립성을 못 만들면 구간을 명목값으로 표시해 채택을 보류한다.
- **교사 staging**: 임무 시작·파지 실패를 건너뛰므로 E2E, 통신 효과, 실제 카메라 일반화가 아니다.
  GT 정체 라벨과 창 시작 라벨은 정확한 물리 접촉 순간과 다를 수 있어 접촉 시각도 별도 열로 보고한다.

## SIM 시간·디스크·보존 예산

이 task의 물리/SIM/렌더 시간과 모델 호출 예산은 **0**이다. 아래는 후속 실행의 동결 후보다.
본 30정체×최대60 s + 60이동×최대90 s + 선택18진단×최대60 s = **8,280 SIM s=2.30 SIM-h**
(배치·안정화 포함), 예비/호스트 재시도 포함 **총 3 SIM-h 상한**. 시간 연장은 새 등록 결정이다.
처음에는 worker 1, OMP/BLAS 1; 물리 잠금을 잡은 별도 작업만 실행한다. wall 예산은 30 h 상한이며
완료 속도 측정으로 주장하지 않는다. 등록 후보 실행기·지원 구현·확증 승인과 잠금 확보가 선행 조건이다.

손목 2대×10 fps×8,280 s = 최대165,600장. JPEG당 평균50 KiB 가정이면 약7.90 GiB이며
실제 인코딩 크기를 확인해야 한다. 로그·예비/재시도 포함 raw **12 GiB**, 파생 표 **200 MiB** 상한.
실행 전 여유 **≥24 GiB**, 항상 ≥10 GiB 유지. 측정치는 `scripts/disk_report.py`로 확인한다.
예산 도달/ENOSPC는 **HOST_ERROR**로 중단하고 미완료·재시도·전체 실패를 기록한다.
유효 프레임이 이미 있는 케이스를 결과 실패 때문에 재시도하지 않는다. raw를 지워 예산을 맞추지 않는다.
raw는 `/Users/changmin/projects/ugrp/outputs/stall-detector-d1-<freeze-sha8>-<cohort>/`에 새로 저장하고
시각/자기 명령/모든 프레임·평가·환경·해시를 보존한다. Git에는 작은 표·manifest·해시만 보존한다.
기존 raw/snapshot은 덮어쓰지 않고 Drive는 쓰지 않는다. 새 실험 결과를 보고할 때는 `docs/tensorboard.md`에
따라 공용 TensorBoard의 새 snapshot과 실패·대조를 함께 로딩/검증한다. 이번 단위 테스트는 새 코호트 결과가 아니다.

## 주장과 봉인 전 미결정

통과해도 **등록한 SIM stage probe의 영상 정체 신호**만 주장할 수 있다. 안전 보장·접촉 예방·물리 성공·
학생 E2E·실물 성공·통신 효과·새 제어기 성능은 주장하지 않는다.
`STALL_SUSPECT`를 제어기에 넣는 일과 정지·후진·재계획 행동은 **후속 별도 사전 등록 변경**이다.
이 모듈을 harness에서 import하지 않는다. 새 실행 번들/workflow 번호를 예약하지 않는다.

봉인 전 결정: 시작 정체를 포함한 전체 가설의 범위(현 초안은 포함), 실제 가능한 빔 끝/한쪽/마찰 조작,
느린 60구간과 바닥/조명 교차 manifest·예비 셀, 단일 case 독립성, 새 probe 지원의 별도 구현/검토,
동결 SHA와 환경·해시, 독립 사전 등록 검토와 후속 실행 승인. 미해결이면 **DRAFT 유지, 확증 실행 금지**.
