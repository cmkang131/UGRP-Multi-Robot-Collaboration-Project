# egomap51 — 지나온 경로로 자기 B 귀환 (2026-10-09)

## 실행 전 사전등록

사용자 결정: egomap50 문 검출(P0.42%, 확인0)은 동결한다. egomap49 여섯 녹화(seed49001–49006)를 개발 자료로 한 번씩 읽어 실제 이동 이력의 위상 그래프를 검증한다. 새 확증 자료가 아니다. 물리 관문 통과 전 물리0, 모델0. 입력은 자기 RGB/검출·명령·추정 자세뿐이며 GT 접촉/좌표는 그래프와 경로를 봉인한 **뒤** 평가에만 읽는다. 초기 세계 자세 GT는 평가 좌표 변환에만 쓴다.

- `return_policy=traversal_graph_v1` 기본 off. off 객체/출력 바이트 동일. 기존 검출기·RBPF·모션·egomap47/48 설정 및 egomap43 도착 판정 유지.
- 탐색 prefix만 저장(360초 손실 전, 손실 프레임 제외). 자기 odom 프레임에 0.30m 이동 또는 20° heading 변화마다 노드, 최초 자기 B 확인 시와 prefix 종료 시 추가 노드. 원시 RGB 경로/SHA와 16×12 밝기 요약, 최근 15초/12관측의 자기 벽 선분 지역 조각, 관측 ID/시각/자세/공분산 보존. 최신 전역 최적화로 과거 노드를 GT처럼 덮어쓰지 않는다.
- 엣지는 시간상 연속한 노드 사이의 **모든 중간 추정 자세/관측 ID**를 보존한다(끝점 직선 shortcut 금지). recovery/backup/clear, 자체 no-progress/abort 구간은 끊고 다른 성분을 거리만으로 잇지 않는다. sensor_sweep 자체는 탐색 관측이며 이동 엣지로 길이를 부풀리지 않는다. 명령은 성공 증거가 아니므로 RGB/추정 이동 근거와 GT 사후 감사의 한계를 구별한다. 제어에 GT 접촉 신호를 넣지 않는다.
- 귀환은 가까운 노드를 기존 CSM(±0.5m, ±20°, overlap≥.60, residual≤.15m 및 원래 모드/경계/관측성 검사)으로 확인한 뒤, 이미 저장된 엣지만 Dijkstra로 B 관측 노드까지 따라간다. 노드마다 지역 관측 정합; 실패 때만 제한된 360° 재관측(기존 30초 상한). B 임무는 blacklist하지 않는다. 역방향 엣지는 회전 후 전진하며 측면/후진 펄스는 금지한다. B 관측 노드에서 자기 B 방향의 현재 free 관측을 따라 접근하고 기존 .20m/5프레임 선언 판정을 쓴다.

### 오프라인 관문 (결과 뒤 변경 금지)

1. 6/6 prefix 생성·인과성 검증, 노드/엣지/제외 구간/시야·RGB 출처 수 보고.
2. B를 prefix에서 실제 확인한 모든 회차에서 B 노드 존재 및 prefix 마지막 노드→B 노드 연결 경로 존재. 미관측 회차는 제외 실행으로 지우지 않고 별도 분모(전체6)로 남긴다.
3. 선택 경로의 **저장된 중간 추정 좌표를 시작 GT 변환만 적용**했을 때 벽 중심선 교차 0, 기존 footprint(0.28×0.24m) 벽 겹침 0. 같은 관측 시각의 실제 지나간 GT 궤적도 별도 감사한다. 실제 궤적이 안전해도 추정 경로가 벽을 가르면 통과로 승계하지 않는다.
4. B 관측/귀환 기록이 있는 모든 회차에서 첫 return 프레임으로 가까운 노드의 지역 CSM 정합 성공 및 B까지 연결. 이 suffix는 prefix 지도/노드 생성에 절대 삽입하지 않는다. 고정 자세 재생은 새 정책의 폐루프 귀환 성공을 뜻하지 않는다.

전부 통과할 때만 같은 seed6개를 각각360초 탐색+270초 suffix로 1회, dev_light/agent_lock/ugrp_session으로 순차 실행한다. 기존 도착/거짓 선언 판정 유지. 도착/6·거짓 선언·벽 접촉·회전 명령 시간 비율·귀환 소요·노드 정합 성공률을 egomap49와 병기. ENOSPC는 HOST_ERROR, 모든 시도/제외 포함. 실패하면 재튜닝·물리 없이 원인과 선택지3개를 기록하고 종료한다. 실제 성공 영상은 실제 성공이 있을 때만 생성; 오프라인 실패는 기존 녹화에 그래프를 얹은 진단 영상으로 명시한다.

## 참고 자료 및 필요한 변경

- [Kuipers 2000, Artificial Intelligence 119:191–233, §2.5·§4.1–4.2·§7.3](https://www.cs.cmu.edu/~motionplanning/papers/sbp_papers/k/Kuipers-aij-00-elsevier.pdf): 원문 확인. 장소/관측/이동의 연결과 지역 metric 지도에서의 재위치, 방향 반전 후 같은 경로 귀환. 전역 metric 일관성을 경로 존재와 혼동하지 않는다.
- [Furgale & Barfoot 2010, JFR27:534–560, DOI10.1002/rob.20342 — 저자 프로젝트](https://asrl.utias.utoronto.ca/~ptf/JFR_VTnR/): 저자 설명의 topologically-connected submaps + repeat local localization 확인. 출판 PDF는 저자 sbib 링크 HTTP401이어서 **전체 원문/수치 미확인**. 해당 논문 stereo visual estimator를 그대로 이식했다고 주장하지 않는다.
- [저자 연구실 VT&R3 설명](https://utiasasrl.github.io/), [공개 구현/Apache-2.0](https://github.com/utiasASRL/vtr3): local submap으로 taught network를 반복하는 구조. 코드 복사·새 라이브러리 설치0. 우리 센서는 단안 저해상도 벽 접점이므로 stereo 대신 이미 동결된 own-wall CSM 지역 정합을 사용한다. 이는 센서 어댑터 변경이며 역방향의 시야 겹침을 보장하지 않는다.
- 0.30m는 사용자 예시,20°는 기존 wide CSM 각도 범위,15초/12관측·정합 거부 조건은 기존 `self_map_csm.py`. B는 자기 최초 확인 provenance만, 제어에 static map/GT/다른 로봇 지도0. 충돌 센서 없는 기록에서 모든 충돌을 사전 식별했다고 주장하지 않는다.
