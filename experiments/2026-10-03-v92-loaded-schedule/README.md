최초 1초 뒤의 팔 과도응답을 피하려고 측정 설계에 **8초 준비 구간**을 사전에 명시했다.

1초 이후 표본을 계속 고르므로, **hold 연장만으로 동결 조립기의 거부가 사라진다고 주장하지 않는다.**
새 구간의 해석은 아래 결정 항목이다.

기존 `.006/.015/.025/.04`의 양·음 **10초 계단+1초 정지(coast)**를 세 축 모두 보존했다.
전진·옆 이동에 `.001/.002/.004` 양·음 계단을 더해 낮은 명령의 운동을 구분한다.
추가 구간은 `low_command_diagnostic`이며 정지로 미리 분류하지 않는다.
각 축의 별도 PRBS31은 기존 다항식 `x^5+x^2+1`, 0.5초 chip, 크기 .015,
이후 2.5초 정지다. PRBS는 검증 구간이며 적합·튜닝에 쓰지 않는다.
기존 288개 명령 수준 조합(로봇×축×부호×크기×horizon)을 모두 보존했다.
이는 **명령 수준 지지** 검사이며 실제 접촉 선별 뒤 288개가 남는다는 보장은 아니다.

180° 마주 보는 두 로봇은 전진·옆 명령의 부호를 뒤집으면 같은 세계 방향으로 이동하지만,
회전 부호는 뒤집히지 않는다. 공동 회전은 두 로봇 모두 `turn=u`, `left=−0.4732u`다.
0.4732 m는 빔 반길이 0.27+정적 파지 반경 0.2032이며, 양 끝의 반대 세계 접선 방향을 만든다.
이 계수는 **자기 명령으로 고정한 기하 설계**이며 실측 gain이나 정확한 속도 관계가 아니다.
세계 위치·측정 관절·접촉으로 명령을 보정하지 않는다. 전진 단독, 옆 단독, 옆+회전 입력의
전체 입력 행렬은 계수(rank) 3이다. 동결 축별 분석기가 혼합 입력을 해석하는 문제는 별도다.

쌍 가장자리 모형은 공통 회전 자체를 볼 수 없으므로 높은 자세에서 작은 상대 회전을
별도 여기(excitation)한다. 이때의 반대 회전 명령을 공동 운동 모형 적합에 섞지 않는다.
기존 네 크기의 양·음 계단과 별도 PRBS로 8초 이상의 창·3초 정착·참조 2장·평활 3장을
담는다. 실제 상대 회전 에너지·RGB 검출·접촉 부족이면 그대로 미측정으로 남긴다.

370초에서 늘어난 이유는 낮은 전진/옆 계단 132초, 두 운반 자세의 용도를 나눈 쌍 측정,
정착·작은 팬·복귀 측정 때문이다. 기존 장계단이나 3.2초 완전 창을 줄여 맞추지 않았다.

원본·해시는 기본 체크아웃의 `outputs/v92-loaded-offline-20261003/`에 로컬 보존한다.

두 짧은 검사를 공용 TensorBoard의 `1003-v92-loaded-design-r2/{posture,motion}`에 추가했다.
이벤트·실행 중 서버의 수치 읽기와 Chrome `강`의 카드 값을 대조했고, 명령 수·SIM초·모델 호출·
기존/후보 관측 열·공동 회전 카드 6개를 고정했다. HParams 기본 네 열도 적용했다.
새 HParams 행의 개별 화면 확인은 남아 있으며, 마지막 화면 복귀는 Chrome 창 연결 실패로
완료하지 못했다. 새 영상은 0개이며, wall 시간·모델 응답 시간·운반 성공 수치는 만들지 않았다.
대시보드 링크와 세부 확인 범위는 [TensorBoard 기록](tensorboard_verification.json)의 `url`,
공용 `outputs/tensorboard-view.json`의 `v92_loaded_design_20261003`에 저장했다.

전체 수집은 조정자가 아래 명령으로 실행한다. PR 최종 인계의 **40자리 소스 SHA**를
`V92_SOURCE_SHA`에 먼저 지정한다. [collect.sh](collect.sh)는 HEAD·브랜치·clean tree·새 출력,
디스크·잠금을 확인하고, 소유 SIM 슬롯을 획득해 표준 실행 경로를 시작한 뒤 자식 종료까지 기다린다.
예상 90분은 잠금 메타데이터이며 실행시간 측정값이 아니다.

```bash
V92_SOURCE_SHA=<PR에 적힌 최종 40자리 SHA> \
  bash experiments/2026-10-03-v92-loaded-schedule/collect.sh
```

실제 수집 호출은 다음과 같으며 단독으로 잠금 절차를 생략해 실행하지 않는다.

```bash
"$PY" scripts/ugrp_session.py run final-pair-v92-loaded -- \
  "$PY" -m scripts.sim_cli workflow run zone-final-pair-loaded-v92 -- \
  --check calibration-loaded --map-id zone_wide_two_doors_final_v3 --seed 911 \
  --expected-source-sha "$FINAL_SHA" --lock-owner codex --sim-slot sim-codex-v92-loaded \
  --output "$RUN_ROOT" --execute
```

동시에 다른 SIM 슬롯을 쓰려면 같은 owner·같은 조정자 PID여야 한다. 별도 조정자의 잠금,
시간 측정 잠금은 거부한다. 종료 중에도 자식이 끝나기 전에 잠금을 지우지 않는다.
회수할 파일은 plan/bundle, 일정·측정 설계, 모든 명령·own JPEG, 0.05초 평가 위치/관절/접촉,
카메라 변환, 적용 설정, result, 전체 파일 해시다. 실제 전체 수집 뒤에는 새 TensorBoard
스냅샷과 기존 관련 기준을 함께 표시하고, 렌더·모형·완주 검증을 별도로 보고한다.
