# 성공1 시드 재생 검토

시드8317104, controller f0db6b1a, postprocessor e0c5eab97. gcp2에서 개요(저장 상태 재구성, 평가 전용)+실제 r1 RGB+r2 N/A(혼자 하는 임무)를 합성했다. 자기 카메라는 변경하지 않았다. 3배속 영상77,433bytes, ffprobe960×240/6fps/14.833333초. Mac 앱은 열지 않고 전체2Hz89프레임(SIM0–44)과 종료10Hz100프레임(SIM34.1–44)을 모두 파일로 직접 읽었다. 회수13파일 SHA 일치, 생성 코드 SHA 일치.

| SIM 시간 | 시간순 관측 |
|---|---|
| 0–8.5 | 로봇이 청록 상자로 접근하고 자기 영상의 대상이 커진다. |
| 9–11.5 | 대상이 화면 하단 가장자리를 드나든다. |
| 12–33.5 | 자기 영상 대부분이 파란 구역이다. 원장/개요는 집기·들기·내려놓기 동작을 보이지만 자기 RGB에서 보유 자체를 확인했다고 하지 않는다. 물리 성공은 별도 평가 원장으로 검증했다. |
| 34–36.1 | 물러난 뒤 빨강 상자와 벽·바닥 경계가 자기 영상에 들어온다. |
| 36.2–38.9 | 몸과 시야가 돌아 벽 모서리와 회색 바닥/파란 구역 경계를 본다. 빠른 전환 뒤 정지 구간과 복귀가 있다. |
| 39.7–41.6 | 다른 쪽으로 다시 시야가 바뀌고 한동안 파란 바닥만 보인 뒤 되돌아온다. |
| 42–44 | 시야가 정착하고 종료한다. |

2Hz만 보면 큰 시야 점프로 보이지만10Hz에서는 빠른 전환→정지→복귀 순서를 구분할 수 있다. 종료34.1–44에서 지속적인 작은 왕복 진동은 보이지 않았다. 그 이전 구간의 빠른 진동을 배제한 것은 아니다. 실제 RGB view6개를 기록했고 `self_pose_source=none`, `localization_verified=false`다. 둘러보기를 했다는 관측과 위치 추정 성공은 구분한다.

첫 묶음 원본 재계수7/7, manifest1455파일 불일치0, invisible_measurements=0/held_world_reads=0. 전체40회 관문은 진행 중이고 현재 완료된 실패는0이어서 실패 영상은 아직 없다. 본 영상으로 실패 원인을 주장하거나 제어기를 고치지 않았다. [회수/검토 영수증](success-playback-review.json), [둘러보기 몽타주](success-lookaround-g0w0.jpg).
