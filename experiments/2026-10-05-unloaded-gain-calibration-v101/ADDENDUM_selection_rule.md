# 선택 규칙 개정 (재생 진행 중 규칙 충돌 해소, 2026-10-05)

이 문서는 수집·적합·평가 결과를 본 뒤, **재생 진행 중 PREREGISTRATION.md §7의 (ii)와 (iii) 충돌을 해소한 규칙 개정**이다.
최초 규칙 커밋 `341ce3b9`는 2026-10-05 03:12:36 KST이고, r1·seed 0의 base/B/C/C2 재생 결과는 03:26:29–03:28:43에 이미 생성됐으며,
이 개정 커밋 `169f5578`는 03:30:06이다(모두 KST). **개정 전 재생 결과를 보지 않았다는 것은 작성자의 진술이며, 커밋·파일 시각만으로 증명할 수 없다.**
(적합 결과: 보정 C는 VALIDATED_DEV, C2는 잡음 포함 비율 0.788로 §6 조건 0.90 미달. 개정 당시 재생 앙상블 40개 중 앞쪽 일부의 결과는 이미 생성된 상태였다.)

1. **C2는 선택 후보에서 제외한다.** §6이 "포함 비율 0.90 미만이면 C2는 재생 후보에서 제외"라고 정했다. 재생은 이미 대기열에 넣었으므로
   그대로 돌려 참고 열로만 보고하고 선택에는 쓰지 않는다(사전 등록과 다른 점으로 README에 적는다). 선택 후보는 B와 C 둘이다.
2. **§7의 (ii)와 (iii)이 문장으로는 서로 부딪힌다.** (ii) S 차이가 10 % 이내이면 C > C2 > B 순, (iii) "C 또는 C2가 B보다 S가 10 % 이상 좋지 않으면 B 유지".
   (iii)을 "B보다 10 % 이상 **나쁘면** B 유지"로 개정했다. 이는 (ii)와의 충돌을 해소하기 위한 판정 규칙 변경이다. 순서는 (i) → (ii) → (iii)이고 코드(`sel_summary.py`)가 같은 순서로 판정한다.
3. **점수와 오차의 계산.** 시드·로봇별 창(30–40, 40–50, 50–60 s)의 NEES(위치 2자유도) 중앙값을 만들고, 시드 사이 중앙값을 그 로봇·창의 값으로 쓴다.
   S = Σ_{r1,r2} Σ_{3창} |log10(그 값/1.386)|. 중앙 |오차|는 시드·로봇별 30–60 s 중앙값(mm)의 시드 사이 중앙값을 로봇별로 구한 뒤
   두 로봇 값의 중앙값(=평균)이다. 60 s 근처(58 s 미만)에서 끝난 재생은 세지 않는다(앙상블 요약 도구와 같다).
4. 기준선 `base`(HEAD 그대로)는 선택 대상이 아니라 참고다. 전부 #363 HEAD 94d083ba에서 같은 재생 도구(`--cal-path/--cal-sha` 추가)로 만든다.

이번 결과는 C S=2.880198, B S=5.245331이며 C의 위치 오차도 더 작아, **원규칙과 개정 규칙 모두 C를 선택한다.** 결과 수치와 선택은 바뀌지 않는다.
향후 확증 수집에서는 충돌 없는 선택 규칙과 요약 코드를 첫 결과 생성 전에 함께 동결한다.
