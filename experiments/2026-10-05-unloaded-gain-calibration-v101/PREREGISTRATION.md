측정해 모델에서 고친다)을 따른다." 이 문서는 수집 설계, 적합·수락 규칙, diff C와 재생 선택 규칙, 회복(R1·R2) 적층 규칙을

## 0. 범위와 정직한 한계

- 대상: 무하중 로봇 r1의 전진·측면·회전 정상 상태 이득과 시간상수(접근에서 쓰는 명령 범위). 하중(적재)·지형·다른 로봇은 아니다.
- 지상 진실(ground truth, SIM 정답 변위)은 **평가 기록·오프라인 적합/채점과 물리 실행기의 중단 전용 안전 검사**에 쓴다
  (`guard()`, `sim/final_environment_measurement_v2.py:91`, `sim/final_environment_gain_calibration_v101.py:94`).
  명령 생성·경로 보정·단계 전환·학생 성공 통보에는 쓰지 않는다. 명령은 모두 미리 쓴 표이고 물리 소유자는 중단(abort)만 할 수 있다.
- 결과는 `DEV_PILOT`(탐색용)이다. `MEASURED_SIM`이 아니고 확증 표본이 아니다. v89·v92 자료와 live probe는 이미 본 자료이므로
  이 보정이 그 자료로 정해진 규칙이 아님을 아래에 분리해 적는다(§1 분리, §9 사후 선택 표시).
- PF의 `motion` 구획은 선형 이득 + 1차 지연이 기본이다. 실제 바퀴 평면은 비선형(작은 명령에서 이득이 낮음, v89 실측)이다.
  그래서 단일 선형 이득은 "사용 분포로 가중한 유효 이득"이고, 데드밴드(deadband) 형태는 §3의 규칙으로만 채택한다.

## 2. 운영·안전 (고정)

- 표준 경로: `scripts/sim_cli workflow run zone-final-environment-gaincal-v101 -- ...`를 `ugrp_session.py run`으로, 조정 스크립트
  `collect.sh`가 `agent_sim_slots`로 SIM 슬롯을 획득(비타이밍, 같은 coordinator PID)한다. 한 번에 최대 2개, 부하가 높으면 1개.
- 매 실행 결과에 loadavg 시작·끝, 동시 보유자(`host_start`/`host_end`)를 기록한다. wall 시간·속도 결론은 쓰지 않는다.
- 시작 전 여유 공간 ≥ 10 GiB(runner와 `ugrp_session`이 확인). 디스크 부족(ENOSPC)은 `HOST_ERROR`로 분류한다.
- 원본은 기본 체크아웃 `outputs/`의 절대 경로에 새 이름으로 쓴다. 덮어쓰기 없음. 커밋된 SHA에서만 실행하고 소스는 수집 중 고정한다.
- 인터록이 중단하면(`HOST_ERROR`) 그 run은 완료로 세지 않는다. 같은 설계로 **한 번만** 다시 실행하고, 다시 중단하면 멈추고 보고한다
  (설계를 결과에 맞춰 바꾸지 않는다). 재실행은 새 출력 이름, 이전 출력 보존.
- 학생·모델 호출·접촉 보조 고정(weld)은 없다.

## 3. 모델과 적합 규칙 (고정)

모델은 PF의 `predict_to`와 같다: 명령이 있으면 축별 1차 지연(`tau_axis_s`), 모든 축이 0이면 공통 정지 지연(`tau_stop_s`, 스칼라 하나),
0.05 s 단계, 갱신한 속도로 위치 적분, `deadband`(있으면) `u·clip((|u|−c0)/(u1−c0), 0, 1)`. 정지 지연은 **세 축 공통 하나**로 적합한다
(축별 정지 지연 평균 금지 — v92 dev pilot이 빈 항목으로 남긴 이유).

- 적합 대상: 블록 창(계단 4 s + 정지 1.5 s)에서 시작 자세 좌표계의 (x, y, 0.35·yaw) 궤적 전체. 초기 속도 0. 정답 시작 자세는
  오프라인 초기조건으로만 쓴다.
- 가중: 창 가중 = (0.8·그 수준의 사용 에너지 비율 + 0.2/4)/그 수준의 창 개수. 접근에서 많이 쓰는 진폭을 더 맞추되, 거의 안 쓰는 수준도
  데드밴드 모양을 식별하도록 유지한다. 가중 평균 1로 재규격화.
- 형태 세 가지(모두 적합, 수락 규칙으로만 하나 채택):
  `linear_diag`(대각 이득 3 + 축 지연 3 + 정지 지연 1), `deadband_diag`(+ c0 3, u1 3, c0는 0–0.015, u1 0.012–0.2),
  `linear_full`(3×3 이득 전체 + 지연).
- 최적화: scipy `least_squares`(trf, 경계: 이득 0.05–4, 축 지연 0.03–3 s, 정지 지연 0.01–0.5 s), 시작점 3개(지연 0.2/0.8/1.5 s), 최소 비용 채택.
  경계에 붙은 매개변수와 야코비안 랭크는 숨기지 않고 기록한다.
- 모델 비의존 교차 확인: 블록 끝 1.5 s의 실측 평균 속도로 사용 가중 최소제곱 기울기(`direct_usage_weighted_gain`).
- 반복 측정 퍼짐: 같은 (축, 수준, 부호) 블록이 fitA1·fitA2에 하나씩 있다. 두 값의 상대 표준편차를 `scale_std` 후보로 쓴다.
  `use_scale` = (`scale_std` > 0.01). `scale_walk` = 0 (한 run 안 반복 이득 표류는 이 설계로 측정하지 않는다).
- `rest_noise`: 명령 0이 정지 지연 5배 이상 지속된 구간의 1 s 변위 RMS ≥ 1 mm이면 true, 아니면 false.
- `tau_s`(스칼라) = 전진 축 지연(`tau_axis_s`가 있으면 PF가 쓰지 않는 값, 로더 요구용).

## 4. 형태 선택 (heldA3·heldM1에서만, 고정)

기준 형태 `linear_diag`. 선택용 지표 = heldA3 계단 창 15개(전진 3 + 측면 6 + 회전 6) + heldM1 혼합 창 8개의 창 끝 오차
(x, y, 0.35·yaw)의 RMS.
1. `deadband_diag`의 RMS ≤ 0.9 × `linear_diag`이면 deadband 채택.
2. `linear_full`의 RMS ≤ 0.75 × (1 단계 결과 형태)이면 full 채택.
3. 아니면 `linear_diag`.
heldP1·heldP2는 이 선택에 쓰지 않는다(§5 수락 전용).

## 5. 수락 규칙 (heldP1·heldP2·heldA3·heldM1, 고정, 모두 만족해야 `VALIDATED_DEV`)

- (a) probe 재생 구간 끝 위치 오차 / 실측 경로 길이 ≤ 0.06, 두 구간 모두.
- (b) 재생 구간 중 위치 오차 최댓값 ≤ 0.12 m, 두 구간 모두.
- (c) 재생 구간 위치 오차 RMS ≤ 0.5 × DEV 기본 채움(이득 1.15/0.94/1.40, 지연 0.12)의 RMS.
- (d) 선택용 창 끝 오차 RMS ≤ 0.6 × DEV 기본 채움, ≤ 0.8 × r4/r5 후보(이득 1.237/0.851/1.0725, 지연 0.798/0.788/0.168, 정지 0.0890).
- 실패하면 `FAILED_HELDOUT`. 등록 산출물은 만들지 않고 실패 그대로 보고한다. 규칙을 바꿔 다시 통과시키지 않는다.

## 6. 잡음 규칙 (변형 C2용, 고정)

diff C의 잡음은 **등록된 r4/r5 측정 잡음**(B)이다. 변형 C2는 이 보정에서 직접 잰 잔차 잡음을 쓴다.
- 평균 모델(`linear_diag`) 확정 뒤 적합 run의 안정 구간(계단 시작 후 지연 3배 이상, 정지 후 정지 지연 5배 이상)에서 지평선
  H = 0.5/1/2 s의 변위 잔차 RMS를 백색 속도 잡음 표준편차 `s = ρ/√(0.05·H)`로 환산하고, 축별 `s ≈ rel·|v̄| + abs`를 비음수 최소제곱으로 적합한다.
  (그룹: 그 축이 구동 중 / 다른 축이 구동 중 / 정지.) 가중은 그룹 표본 수의 제곱근. `noise_abs`는 0.002(m/s, rad/s) 아래로 내려가지 않게 바닥을 둔다
  (잡음이 0이 되면 입자 결핍 위험, MRPT 잡음 바닥·Gustafsson 디더링 근거). 2σ 판정에는 자세 기록 해상도 1 µm 바닥을 둔다.
- C2 채택 조건: heldA3·heldM1 창에서 H = 1/2/4 s의 2σ 포함 비율 ≥ 0.90. 아니면 C2는 재생 후보에서 제외.

## 7. diff C와 재생 선택 규칙 (최초 규칙, 재생 진행 중 개정은 아래 별도 표시)

- diff C = #363 현재 HEAD에 대한 최소 diff: 새 보정 파일(§8)의 sha를 `dev_pilot.admitted_calibration_sha256`에 추가하고 그 출처를 등록한다.
  숫자는 코드에 타이핑하지 않는다(등록 파일에서만 읽음). 잡음은 등록 r4/r5(C) 또는 이 보정의 측정값(C2).
- 후보: base(HEAD 그대로) / B(등록 잡음·척도 0 overlay, 이전 분석) / C / C2. base는 선택 대상이 아니라 기준선이다.
- 재생: v98 DEV probe의 기록된 입력(`outputs/v98-dev-probe-raise_high-1f7fb800`)을 PF에 열린 루프로 재생. 같은 5 시드(s0, 101–104),
  r1·r2, 60 s까지, 동시 재생 ≤ 2. 지표는 이전 앙상블과 같다: 시드 중앙값의 창(30–40, 40–50, 50–60 s) 중앙 NEES(χ²(2) 99.9% 한계 13.8).
- 점수 S = Σ_{r1,r2} Σ_{3 창} |log10(중앙 NEES / 1.386)| (1.386은 χ²(2)의 중앙값; 과신과 과소신뢰를 모두 벌점).
  선택: 후보 {B, C, C2} 중 S가 최소인 것. 단 (i) 선택 후보의 중앙 |오차|(30–60 s)가 세 후보 중 최소 ×1.25 이하여야 하고, 아니면 오차 최소 후보가
  S가 최소의 +30% 이내일 때 그것을 선택. (ii) S 차이가 10% 이내이면 C > C2 > B 순(측정 추적 가능성). (iii) C 또는 C2가 B보다 S가 10% 이상
  좋지 않으면 B 유지.
- 이 규칙으로 고른 것을 diff C로 보고한다. 표 전체(모든 후보·시드)를 함께 낸다. 파라미터를 probe 통과에 맞추지 않는다.

**재생 진행 중 규칙 개정:** 위 최초 문구의 (ii)와 (iii) 충돌을 해소하기 위해 [ADDENDUM](ADDENDUM_selection_rule.md)에서
(iii)을 "B보다 10 % 이상 나쁘면 B 유지"로 개정했다. 최초 규칙 `341ce3b9`는 2026-10-05 03:12:36 KST,
r1·seed 0의 base/B/C/C2 재생 결과 생성은 03:26:29–03:28:43, 개정 `169f5578`는 03:30:06이다(모두 KST).

## 9. 회복 R1·R2 적층 (고정)

- 조정자 결정: R1(믿음 둘레 국소 증강 MCL)과 R2(도착 거절 경로에서만 `expand_belief`)는 둘 다 채택 방향이다. 매개변수는 이전 분석 그대로
  (R1: alpha_slow 0.001, alpha_fast 0.1, local_std [0.1, 0.1, 0.2] — Thrun 2005 augmented MCL, Nav2 문서 값; R2: 확장 반경 (0.1 m, 0.1 m, 0.2 rad) —
  Ueda 2004, emcl2 기본). 이 probe에서 다시 조정하지 않는다. R1 국소 주입은 균일 주입이 다 m 규모 일시 오차를 만들어 정한 **사후 안전 선택**이다(공개).
- 통합 diff = C 위에 R1, R2를 차례로 얹은 것. R2는 #363 HEAD의 도착 확인 코드 거절 경로에 호출 위치를 맞춘 실제 diff.
- 오탐 검사(유지): 보류 도크·정상 주행 재생에서 주입 0건. 하나라도 주입되면 그 사실을 보고하고 통합 diff를 제안하지 않는다.
