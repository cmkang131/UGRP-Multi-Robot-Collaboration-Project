# 지도 코드 → 빔 짝 ACT 학생 인수 분포 명세

**명세만.** 지도/교사/장면 코드를 이번에 바꾸거나 배치를 제출하지 않는다. 온라인 위치 정답 가드를 넣는 제안이 아니다. 인수는 허용 영상·자기 발행 명령·정적 지도로 추정하며 아래 truth는 오프라인 평가/표적에만 쓴다. ACT 관측에는 인수 거리/각도/불확실도도 새로 넣지 않는다.

## 분포 근거와 좌표 정의

beamdiag의 실제 TRAIN166시드 local_skill_sample 60,023행 중 접근26,499행 기준이다. [원문 수치/해시](beamdiag-reference.json)의 `train_geometry.approach`를 사용한다. 행 가중 백분위이며 초기 상태만의 분포나 독립 시드 백분위는 아니다.

|값|TRAIN 값|용도|
|---|---:|---|
|배정 끝까지 평면 거리 최솟값|0.1414823425721142m|관측된 지원 범위의 하한, 목표 정지거리가 아님|
|같은 거리 p25 / p50 / p75|0.15683129 / 0.30707896 / 0.52954564m|후속 표집 층, 균등 원판 시작으로 대체하지 않음|
|같은 거리 p95 / p99|0.73874975 / **0.7816726268189497m**|기본 근거리 인수 외곽의 근거|
|같은 거리 전체 최댓값|0.8485531701038711m|드문 꼬리의 존재이며 시작 허용치로 쓰지 않음|
|최종 파지 방향 대비 yaw 절대오차 p99|**2.936715138172937rad** (약168.26°)|접근 단계의 방향 범위|
|정렬 단계 거리 p99 / yaw 오차 p99|0.26758890787274625m / 0.8120270585607118rad|더 좁은 정렬 전용 인수를 주장할 때 별도 층으로 확인|

`d`는 로봇 기준점과 **배정된** teal/blue 끝의 평면 거리다. `ψ`는 빔의 최종 파지 방향(blue는 π 반대) 대비 로봇 yaw 오차의 wrap 절댓값이다. 카메라 광축 대비 끝의 bearing와 다르다. beamdiag에는 bearing p99가 없으므로 yaw 표로 카메라 시야 범위를 만들어내지 않는다. 실제 카메라/FOV·발행 pan을 유지하며 그 bearing 분포는 후속 gcp2 원본 요약에서 확보한다.

## 오차 예산을 뺀 인수

같은 머신/지도/장면/추정기 버전의 별도 오프라인 평가에서 `E_d = p99(|d_est−d_eval|)`, `E_ψ = p99(|wrap(ψ_est−ψ_eval)|)`를 잰다. 상대 끝 위치 추정 오차를 포함해야 하며 자기 위치의 내부 σ나 발행 이동량을 실제 오차로 대체하지 않는다. 각 오차의 N·시드·SHA·단위·재현 명령을 기록하고 evaluator 값을 제어 경로에 반환하지 않는다. 로봇/끝의 별도 p99를 단순히 더한 값은 상대 오차의 공동99% 보장이 아니다.

후속 `beamact4_handoff_v1`의 **추정치** 범위는 다음과 같다.

```text
0.1414823425721142 + E_d ≤ d_est ≤ 0.7816726268189497 − E_d   [m]
0 ≤ |ψ_est| ≤ 2.936715138172937 − E_ψ                       [rad]
```

이는 `d_est ± E_d`, `ψ_est ± E_ψ`를 TRAIN 지원 범위 안에 두려는 오차 예산 설계이며 성능 보장이 아니다. 거리/각도의 주변 p99 두 개만으로 결합99%가 성립하지 않는다. 후속 인수 로그에서 결합 분포와 실패율을 따로 검증한다. **현재 E_d/E_ψ가 없으므로 숫자를 임의로 채우지 않으며 실행 NOT_READY다.** 예산을 뺀 구간이 비면 ACT 인수 대상0으로 기록하고, 원거리 교사 범위 확장 또는 추정기 개선을 조정자에게 배정한다.

## 평가 시작 분포와 기록

1. 근거리 평가와 원거리 cold start는 별도 코호트다. 기존 시작은 A/B 각각30/40이0.8m 밖이고 최대1.68780170m라 근거리 분모로 재사용하지 않는다. 코드로 정답 위치에 스냅하거나 학생 행동 중 truth로 인수 여부를 보정하지 않는다.
2. 후속 지도→ACT 경계에서 관측 가능한 추정치·오차 예산으로 인수/거부를 남긴다. 거부 뒤 지도 주행/재관측은 기존 지도 기술의 소관이며 이 PR에 수제 접근·정렬·파지 경로를 만들지 않는다. 평가 전용 truth는 별도 원장에서 거리·각도 지원 범위/잘못된 끝을 판정한다.
3. TRAIN 접근의 실제 거리/각도/가시성/역할/pan 결합을 보존한 시작 목록을 등록한다. p25/p50/p75/p95/p99 층과 실제 두 로봇 역할을 함께 기록하고 각 층의 분모를 공개한다. 수치 상자 안에 있다는 이유로 임의 독립 표집이나 정렬 완료 start를 섞지 않는다. 프레임 통계만으로 episode-start 적합도를 주장하지 않고 시드별 첫 유효 인수 행도 후속 집계한다.
4. 자기 RGB4장(5.2/1.5/0.5/0초), 자기 발행 명령16개·10Hz의 원래 시각/해시를 지도 주행부터 이어받는다. beamact3 최근5개 history 변환도 기록한다. 교사 이력을 복사하거나 로봇을 GT로 이동한 뒤 정상 handoff라고 이름 붙이지 않는다. 필요한 지도→ACT 연결 시연은 별도 교사 관문 뒤 확보한다.
5. 배정 색 띠의 자기 RGB 관측, camera bearing/pan, 직전 명령/PWM 분포를 평가로 확인한다. 기존 TRAIN 접근 색 띠 후보 가시율99.81%는 참고 대리지표다. 색분할9px 같은 분석 상수를 온라인 수용 상수로 옮기거나 새 근거리 인식 가드를 덧붙이지 않는다. 입구 거부는 예측 불확실/미관측/지원 범위 밖/데이터 부족으로 이유를 남긴다.
6. 각 관문의 후보/프레임/이벤트 누적 통과와 거부를 남기고 `reason_category`, `blocked_object`, `min_gap_m`, 원본/sha256·재현 명령을 보존한다. 계측 없는 막힘은 UNKNOWN/null+측정 불가 이유다. `cap_end`, HOST_ERROR, 감독 중단도 보존하고 통과 수를 채우려고 누락하지 않는다.

지도 인수/새 교사 성공/데이터 적합도/오프라인 head/폐루프 성공은 별도 관문이다. warp8 종료와 후속 배정 전에는 이 명세가 실행 승인이 되지 않는다.
