# warp8 이후 배정할 빔 교사·표적 명세

소유: 교사는 `codex/warp6`의 warp8이다. **이번에는 교사 코드를 수정하지 않는다.** warp8 관문 종료 뒤 조정자가 별도 배정한다. 새 관문·데이터·학습·호스트 사용도 이번에는 승인하지 않는다. 아래는 학생 후보가 요구하는 데이터 계약이다.

## 단계 출력과 표적 경계

새 `ugrp.beamact4.stage-target.v1`은 기존 14차원 행동 표적과 별도인 `stage_target[chunk=8]` int64다. 순서는 학생 코드와 동일하게 `approach, alignment, ready, execute, recover, complete`다. 표적의 `sample_id/t/robot_id/실제 role/episode/교사 SHA/판정 출처`와 기존 action padding을 맞추고 청크가 로봇·역할·에피소드를 넘지 않게 한다. 패딩을 READY 음성 표본으로 세지 않는다. stage 표적은 학습 loss에서만 읽고 ACT encoder/worker 요청/자기 history에 넣지 않는다. 정답은 표적/평가에만 쓴다.

|표적|의미와 필요한 자료|
|---|---|
|approach|실제 배정 끝으로 접근. 반대 끝 접근/미관측과 구별할 own RGB·역할·발행 pan/팔 명령 문맥 보존|
|alignment|배정 끝 자리와 방향을 맞추는 중. PWM이 작아졌다는 이유로 READY로 라벨하지 않음|
|ready|현재 배정 끝의 정렬이 끝나 GO를 기다리는 단계. 기존 교사/평가 station0.203m, XY≤0.03m, yaw≤0.06rad의 **출처가 있는 기존 정의**로 오프라인 표적을 점검하고 자기 끝 가시/명령 문맥을 보존. 작은 PWM 감소/GO 발행 시각/접촉만으로 양성을 만들지 않음|
|execute|GO/ACK 뒤 자기 파지 명령 시퀀스를 실행 중. 파지 직전 띠 소실과 팔/집게가 커지는 정상 장면을 실패 영상으로 자동 재라벨하지 않음|
|recover|끝 교환·장기 미정렬·시야 이탈·한쪽 조기 완료 뒤 실제로 다시 보며 회복하는 궤적. 허가를 철회하고 자기 관측으로 READY를 다시 낼 수 있어야 함|
|complete|자기 스킬의 명령 시퀀스 완료 요청. 공동 물리 성공/실제 들기와 별개. 완료 뒤에도 자기 RGB/발행 명령을 관측하고 완료 철회·복구로 이어지는 자료 필요|

표적 우선순위는 정상 명령 완료/실행, 유효 READY 대기, 의도적인 복구, 정렬, 접근의 교사 실행 상태에서 하나로 정하고 중복/불명확은 unknown으로 거부해 별도 계수한다. 교사의 내부 phase 명칭을 그대로 복사하기 전에 위 의미·시각·물리 평가를 대조한다. 특히 완료 요청을 전역 들기 성공 라벨로 바꾸지 않는다. 정렬 전 READY는 음성, READY 중 형제 로봇이 늦는 대기와 PWM 잡음도 음성/양성의 실제 단계에 따라 남긴다. 학습 클래스별 unique TRAIN 행·청크 노출·padding/unknown 거부 수와 validation 혼동 행렬을 보고한다.

head는 기존 ACT의 같은 decoder/CVAE forward로 학습한다. 따라서 학습 때 미래 행동을 본 posterior 특징의 분류 손실만으로 READY 정확도를 판단하지 않는다. 오프라인 혼동 행렬은 실제 배포와 같은 `predict_staged`(행동/단계 표적 없는 prior 추론)로 만들고, 학습 posterior 점수와 구분한다. 이 확인도 이번에는 수행하지 않았다.

교사 행동은 현재 자기 카메라에 보이는 대상만 사용한다. invisible measurement0, held world read0을 감사하고, 보이지 않는/잡고 있는 빔의 세계 좌표를 행동·단계 전환에 넣지 않는다. 고정 카메라 배치/FOV·외관·장면과 weld OFF를 유지한다. 접촉/관절/정답 높이는 평가 및 오프라인 표적과 학생 관측 사이에서 격리한다. 행동이 정답으로 구제된 시연은 이 가시 교사 관문 성공으로 세지 않는다.

## 실제로 반대 역할을 수행한 시연

동일한 배치 계열에서 r1→teal/r2→blue와 r1→blue/r2→teal을 **각각 실제로 실행**한다. 시작 카메라/차체/팔 상태·own RGB·issued history·정렬/파지 행동·접촉 평가·교사 성공이 실제 배정과 함께 달라져야 한다. 각 로봇이 자기 배정 색 끝을 실제로 방문/파지했는지 평가 전용 원장으로 감사한다. 반대 끝으로 가는 쪽이 물리적으로 막히거나 관측할 수 없으면 그 거부를 보존하며 원래 역할 행동을 새 역할 정답으로 쓰지 않는다.

번호표만 바꾸고 원 명령을 유지하는 증강은 금지한다. 한 샘플의 사후 번호표 교환 출력은 진단일 뿐 실제 반대 역할 시연이 아니다. paired 시드의 모든 역할 변형과 두 로봇은 같은 TRAIN/validation 그룹에 둔다. 실제 반대 역할 대비 행동·경로가 다른 사례를 양쪽 클래스에 포함하고 색/로봇 ID/배치와 역할의 일대일 지름길을 감사한다. 균형 수나 학습 가중치는 새 분포를 계수한 뒤 등록하며 임의의 최소 표본 상수를 넣지 않는다.

## 원거리와 학생 방문 복구 범위

근거리 입구는 [handoff-spec.md](handoff-spec.md)를 따른다. 원거리 cold start까지 ACT가 맡는 별도 조건이라면 기존 0.84855m 최대 시연으로 충분하다고 주장하지 않는다. 현재 학생 초기 관측 거리 범위 0.20286237–1.68780170m, p99 1.67991834m와 실제 초기 방향/가시성/자기 명령 이력을 포함한 시연을 먼저 확보해야 한다. 필요한 외곽은 적어도 `현재 초기 최대1.6878017037889643m + 측정된 상대거리 오차 예산 E_d`까지 점검한다. 이것은 원거리 범위 요구이며 근거리 인수 범위를 넓히는 온라인 가드가 아니다. 초기 각도/bearing와 오차 예산은 미측정이므로 후속 원본 집계 전에는 원거리 실행 NOT_READY다.

원거리 자료에는 배정 끝 미가시→실제 둘러보기→올바른 끝 획득, 반대 끝/같은 끝 자리에서 자기 배정 끝으로 돌아가기, 화면 가장자리 장기 정렬, 몸통 시야 뒤 재관측, 한쪽 완료/상대 미정렬 뒤 완료 철회, 대기 중 단계 유지와 새 GO/ACK 후 복구를 포함한다. beamdiag에서는 TRAIN 파지 전 몸통+양끝 미검출의 최장 연속이0.1초인 반면 학생 A0 r2는52.6초였다. 짧은 정상 파지의 몸통 영상을 늘리는 것만으로 이 복구 분포를 덮었다고 하지 않는다. 로봇 충돌은 원본에 접촉 원장이 없어 UNKNOWN이며 새 원장 없이 충돌 시연이라고 단정하지 않는다.

실패 학생 방문 상태에서 전문가 자료를 얻는 DAgger 계열 제안을 따른다([Ross 2011](https://proceedings.mlr.press/v15/ross11a.html)). 원 상태·교사 반응·그 뒤 전체 궤적·완료/실패·원본 해시를 연결하고 가시성/held-world 제약을 동일하게 적용한다. 기록/재현은 후속 승인된 gcp2 작업에서 수행한다. 모델 키·에이전트 자격증명은 VM에 두지 않는다.

## 후속 관문과 전달

변경 교사/역할·범위의 성공 ≥95%, 최소40회를 같은 머신 종류에서 먼저 측정한다. 이때 학습용 카메라 기록은 끄고 검토 영상·명령·원장만 남긴다. 실패 원인을 확인하면 같은 결함의 자기 실행을 즉시 정지하고 고친 코드로 처음부터 다시 잰다. 성공을 확인한 뒤 실제 학생 해상도·주기·FOV로 시연을 기록하고, 실패/HOST_ERROR/cap_end와 거부 이유·막은 물체·최소 틈·순서 퍼널을 보존한다.

새 데이터/표적/역할 출처 SHA, 고정 분할, 원본 해시, head 학습/재로딩, TRAIN/validation READY 오탐/단계별 통과, 완료 뒤 실제 재추론/회복, 학생 배정 끝 들기 성공을 따로 전달한다. 저장 명령 재생이 물리 성공을 뜻하지 않는다. 기록·학습·폐루프 실행은 현재 계획의 남은 관문이며 이번에 수행한 결과로 표시하지 않는다.
