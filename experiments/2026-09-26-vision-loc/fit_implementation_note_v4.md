# VIS4 적합 구현 확인 (PF 비교 전)

첫 `outputs/vision-loc-v4/motion_fit.json`은 짐 상태 yaw의 유효 자극이 0개인데
이를 큰 상수 손실로 더했다. 계수는 원래 값으로 유지했지만, 불필요한 큰 상수가
다른 축 손실의 정밀도를 떨어뜨린다. 해당 축을 점수에서 제외하고 원래 계수를
유지하도록 수정해 `motion_fit_final.json`에 다시 적합한다. 첫 파일도 보존한다.
후보·분할·격자·선택 규칙은 바꾸지 않는다. yaw 학습 성공을 주장하지 않는다.

현재까지 dev 영상·라벨·평가 시각/위치 불일치는 0이다. 시각을 이동하는 후보는
추가하지 않는다. `delay_s`는 명령에 대한 물리 응답 지연이며 영상 timestamp
수정이 아니다. 새 test를 열거나 평가하지 않았다.
