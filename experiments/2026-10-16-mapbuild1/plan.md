# mapbuild1 사전 기록

2026-10-16 사용자 "지도 그리는 것도 같이 진행 ㄱ". #366 본문 1–4 확인: 가능성/척도/독립 번들/자원. 첫 E2E 이후 시점과 Mac GPU 제외 사유를 이번 결정으로 대체한다. 단계별 관문 실패는 후속 단계 성공으로 넘기지 않는다. 같은 결함 3라운드면 중단한다.

## 조건과 실행 예산

- 토글 `mapbuild1_v1` 기본 OFF, 독립 번들 `mapbuild1-feasibility-v1`; 공통 실행 번들 번호·warp7 제어기·기본값을 수정하지 않는다.
- 장면 `walls_floor_contrast_v5_indigo110_s80` + v1 바닥 + `no_mip_v1`. MJWarp 렌더는 warp5 `3c598b816b823ef93d064b2f30ffd07cf5493816`의 `warp5_native_visual_v2`; 원 GPU 설치·셰이더 소스는 수정하지 않는다. 렌더 자체의 미통과 색 관문은 공개한다.
- 1차 가능성은 실제 주행 전, MJWarp 렌더의 통제된 카메라 변위 영상이다. FOLDED/HIGH × 전진/횡이동/회전 6조건, 각 4 SIM초·10Hz(41장), 시작 원점. 변위 0.2m 또는 15도는 시험 범위이고 수용 오차가 아니다. 기록기는 fixture 상태를 설정할 수 있지만 추정기는 RGB·고정 카메라 보정만 받는다. 실제 명령으로 주행했다고 보고하지 않는다. wheel command prior는 0이며 변위 정답으로 예측을 만들지 않는다.
- 렌더 gcp2 L4 공유 임대 1개 작업, nworld6; 분석 gcp2 n4-64 1개 프로세스. 최대246 JPEG와 요약·평가 출력 약50MB, Mac 회수 ≤8MB. 호스트 watchdog 15분은 프로세스 장애 정리 전용이며 행동 선택에 쓰지 않는다. 모든 계획·RANSAC은 프레임·반복 수 한도. 상한 종료 `cap_end`, 호스트 중단 `HOST_ERROR`.
- L4 기존 warp3/beamact3/warp7 임대와 프로세스를 보존하고 concurrency 합계≤40. gcp3 사용하지 않는다. 첫 프로젝트 접근0, 새 VM/모델 키/자격 증명0, 비용·유휴·상한 변경0. 자기 임대만 제거하고 타 임대가 있으면 VM을 정지하지 않는다.

## 단계 관문

1. 조사: 고전·학습형 원문/입력/척도/계산·라이선스·선택 이유를 references.md에 기록. 설치·실행 성능과 구분.
2. 가능성: 6조건을 모두 보고하고 프레임→유효 RGB→특징→기하 추적의 순차 funnel, 유지 n/N, 연속 추적 길이, 구간별 이동량 오차·척도 비율, ATE/RPE를 기록한다. 평가 정렬은 첫 자세 SE(2)만(척도 최적화 없음). 통제 변위는 렌더/광학 가능성 관문이고 실제 MJWarp 주행·지도 성공 관문이 아니다. 실제 주행에서 명령 척도와 초음파 ON/OFF를 별도로 잰 뒤 단계3을 연다.
3. 지도: 자기 RGB 추정 pose→색 기반 벽 바닥 접점→기존 OdomGrid의 inverse sensor 누적. 미관측은 unknown, 보인 벽면 뒤를 free로 채우지 않는다. 목적지 색 영역은 관측 기하와 의미를 분리, 문은 양쪽 벽·관측된 빈 통로 근거가 있어야 하며 미관측을 문으로 추정하지 않는다. 지도별 벽/문/장애물/목적지의 대칭 거리·누락·거짓, 전체/관측영역 커버리지를 전용 scorer로 잰다. 표본·픽셀뿐인 탐침을 전 지도 완성으로 보고하지 않는다.
4. 지도 소비: 각 로봇의 지도 원점·해시를 유지한 채 위치 추정→경로 선택→빈 차 통과→운반→도착/place를 분리. warp7와 같은 시드·장면·호스트·백엔드·모델 조건, 결과 합산 금지. 정답 정렬 변환을 제어기에 주지 않는다.

탐색 경로는 코드가 자기 지도 frontier와 관측 이득으로 생성한다. 단계2·순수 지도 품질 진단에는 LLM을 쓰지 않는다(고정 탐색 과제). 과업 통합 단계4에서는 LLM이 목적지·화물·순서·경로 후보를 판단하며, 코드가 새 지도에서 후보와 안전을 계산한다. 로봇별 지도 공유 옆길은 없고 파트너 정보는 통신 조건의 허용 채널만 사용한다.

실패 원장은 category/reason/blocked_object/minimum_gap_m/gap_status를 항상 남긴다. 영상 검토는 원격 ffmpeg, 전체2Hz·마지막10 SIM초10Hz 프레임 띠, Mac GUI0. 실행이 4 SIM초면 전체가10Hz 보존 범위다. 물리 성공 예제가 아직 없으면 렌더 추적 성공 예제와 명확히 구분한다.
