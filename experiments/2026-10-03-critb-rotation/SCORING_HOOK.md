# 회전 부록을 읽고 채점하는 후속 연결 설계

**설계만 기록한다. #356 브랜치와 검증기는 수정하지 않는다.** #356 병합 뒤 별도 PR에서
다음 연결을 구현하고 합성 자료로 검사한 다음, 코디네이터의 공개 해시 고정을 확인해야 한다.

1. 원래 B 경로는 그대로 실행한다. #356의 `verify_commitment`는 B/r4/기존 검증기와
   v91 수집 전 공개 기록을 확인한다. 이 경로의 회전 후보와 회전 판정은 계속 null이다.
   r4 자리에 r5 파일을 넣거나 과거 공개 기록의 해시를 바꾸지 않는다.
2. 별도 명시적 인자(예: `--rotation-addendum`)로 이 부록을 선택한다. 부록·r5의 실제
   SHA-256을 코디네이터가 올린 공개 기록의 두 값과 대조한다. 공개 기록의 서버 생성 시각,
   수정 여부, 본문과 본문 해시, 실제 파일 해시를 보존한다. 누락·변조·조회 실패는
   회전 `INELIGIBLE`, `pass=null`이다. 파일 mtime·Git 날짜로 공개 기록을 대신하지 않는다.
3. **이번 공개 고정은 채점 전(pre-scoring)이다.** v91은 이미 수집됐다. r5의 공개 시각을
   v91 수집 시각보다 앞섰다고 요구하거나 보고하지 않는다. #356의 기존 수집 전 검사를
   느슨하게 만들지 않고, 회전에만 2026-10-03 위임 결정과 별도 채점 전 기록을 적용한다.
   첫 v91 원자료 접근 전에 두 해시가 공개됐다는 작업 기록도 연결한다. 이 선언은 서명된
   원자료나 모든 참여자의 과거 미열람을 암호학적으로 입증하지 않는다.
4. #356의 v91 입력 감사를 재사용한다. 두 지도 모두 `zone-final-pair-v91`, source
   `04043e274af7351f3d35cb6be77d948cac1b8c6a`, 무하중, 지정된 bundle·schedule·완료 기록·
   명령·pose·artifact 해시를 확인한다. 두 지도 중 하나라도 빠지면 전체 회전 검증 완료를
   주장하지 않는다. 새 훈련 명세의 pose 해시도 이전에 본 목록에 합쳐 중복을 거부한다.
5. r5의 `candidate_axes.rotate.consumer_fields`만 새 회전 프로필로 읽는다. B/부록의
   해시·상태, r4 전진/측면 필드 동일성, null인 `axis_validation`/`params.motion`,
   명령 축 `turn`, 단독 축 gain, 양의 스칼라 tau, M1 이상 잡음, 0.05초 간격,
   `rest_noise=true`, `use_scale=false`, `scale_std=scale_walk=0`을 검사한다.
   회전 후보가 null이거나 ±계단·±PRBS·전체 예측 시간 지원이 없으면 판정은 null이다.
6. 수치 계산은 기존 `evaluate_axis(case, 2, profile, B)`를 그대로 호출한다.
   예측 시간은 0.2/0.5/1/2/3/3.2초, 성분은 전진 m·측면 m·yaw rad다.
   각 지도·사례·계단/PRBS·시간·성분에서 `p95(abs(error)/sigma) <= 2`와
   `coverage_2sigma >= 0.90`을 모두 요구한다. 모든 0.05초 시작점과 coast를 포함하고,
   창을 구간 밖으로 잇거나 잔차를 중심화·솎기·재적합하지 않는다.
7. 기존 B 결과와 별도의 `rotation_addendum` 결과를 나란히 저장한다. 부록 결과에는
   두 파일 해시, 공개 기록, 채점 소스, 입력 해시, 두 지도별 수치, null 사유를 남긴다.
   부록을 포함한 전체 요약이 필요하면 새로운 이름으로 만들고 B의 `combine` 규칙
   (실패 하나면 false, 실패 없이 미검증이면 null, 모두 통과해야 true)을 그대로 쓴다.
   원래 r4의 회전 null이나 기존 보고서를 덮어쓰지 않는다. 읽은 입력은 채점 후 다시 해시한다.

필수 후속 검사는 정상 합성 yaw, 두 지도 중 실패/누락, 기준값 직전·직후,
후보/부록/공개 기록 변조, 훈련 pose 재사용, ±명령·PRBS 누락, 명령 lease/시계 오류다.
동일 합성 사례를 frozen `evaluate_axis`에 직접 넣은 수치와 완전히 같아야 한다.

이 연결은 오프라인 채점에만 쓴다. `MEASURED_SIM` 승격, 학생 제어기·P03·pair 로더 적용,
회전과 병진의 혼합 명령은 별도 작업이다. frame을 읽는 후속 기능이 생기면 실제 키
`sim_time`을 사용한다(#358). pose·commands의 시각 키는 `t`다.
