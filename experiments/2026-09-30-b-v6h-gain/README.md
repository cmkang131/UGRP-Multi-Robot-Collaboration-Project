# b-v6h 앞으로-이득(전진 gain) 보정 + 진행 감시 규칙 p2f: 연쇄(L0→내려놓기/재파지→L1) 탐색 실험 (2026-09-30, Claude)

Refs #216. 브랜치 `claude/b-v6h-gain`(초안 PR). **탐색용 실험이다. 사전 등록도 아니고 E2E 성공도 아니다.**

## 한 줄 요약 (쉬운 말)

- 든 채로 앞으로 갈 때 위치 추정기(PF)가 "앞으로 1.4004배 간다"고 믿는 값이 실제보다 약 5.2 % 크다는 진단(PR #284)을, 실행 코드는 그대로 두고 **실행 중에만 0.9483배로 고치는 패치**로 넣었다. 이 패치를 넣으면 L1 끝의 앞뒤(x) 오차가 +61 mm에서 -3 mm로 줄고, 앞뒤 방향 "±2σ 안에 들어오는 비율"이 71 %에서 100 %가 된다. 세 축(x, y, yaw) 모두 정직하다(표본 안의 100 %).
- **하지만 이 보정만으로는 충돌 여유(σ 배수) 완화와 넓힌 yaw 관문이 필요 없어지지 않는다.** 등록된 값(σ 배수 2/2, yaw 관문 3.0/2.5도)에서는 문 통과에서 여전히 막힌다(L0→L1 연쇄 1/24, 그 앞의 L0 단계도 22/24). σ 배수 1 + 등록 관문에서는 L1이 5/24다(yaw σ가 3도 관문에 닿는다).
- 완화(k1g: σ 배수 1, yaw 관문 5.0/4.0도) + 보정(p2f 진행 감시)만 있으면 연쇄가 통과한다. 보정 패치를 더하면 위치 σ가 정직해진다.
- 통과율은 **놓는 위치(배치)에 크게 좌우된다**: 고정 문 축 시트 위의 12개 배치는 24/24(12/12 배치)지만, 실제 기록된 hR2 시작 10곳은 14/20(7/10 배치)이고, 지시서(시트)를 빔 위치에서 반올림한 시나리오의 12개 배치는 보정 없이 10/12, 보정 있으면 11/12다. **남는 실패는 gain과 무관하다**: L1 끝 오차가 (빔 x − 반올림 시트 x)와 상관 0.95–0.97로 붙어 있고, 100 mm 관문을 넘는다.
- **진행 감시(p2f)는 고쳐진 규칙 그대로 208건 중 0건에서 무장(arm)하지 않았다.** 즉 이 연쇄에서 든 쌍에는 **정지(stall) 감지가 사실상 없다.** 문 구역만이 아니라 든 구간 전체에서 그렇다(이유는 아래 4절). 사전 등록 초안에 그대로 적었다.

## 범위와 한계

- teacher가 시작 상태를 만들어 주는 stage probe(연쇄, `--chain-stop-leg 1`)이며 SIM 시간, weld OFF, 모델 호출 0. **제어기 입력에는 정답 좌표가 없다**(제어기는 자기 영상·자기 명령 이력·정적 지도만 쓴다). 정답(GT)은 평가 출력에만 쓴다.
- 단위. PF 시드(911, 913)는 PF 난수만 바꾸고, 물리는 결정적이라 결과가 거의 같다. 그래서 **독립 단위는 배치**다. 케이스 수준 신뢰구간은 낙관적이고, 표에는 배치 수준을 함께 적는다.
- 배치 12개(N01–N11 + F_hR2_04)는 이 실험 안에서 새로 뽑은 것이지만, PF 사전분포(prior)는 기존 hR2 표본 10개를 돌려 썼다. 사전분포의 다양성은 10개다.
- 모든 코호트에서 접촉(벽 트래커) 0건, 하드 한계(기울기>15도, 관통>5 mm) 위반 0건. 트래커는 벽만 본다.
- 여러 코호트가 서로 다른 소스 SHA에서 돌았다(아래 원본 표). 세 SHA 사이에서 `harness/`는 바뀌지 않았고, `scripts/run_pair_stage_probes.py`는 배치 목록의 `sheet` 옵션(케이스 계획 생성)만 추가됐다(`git diff 69c2a99a b95d2016 -- harness scripts`로 확인). 실행·제어 코드는 같다.

## 정직성(정직한 σ)을 축별로

leg 끝의 PF 추정 오차(추정−정답)와 자기 공분산으로 z² = (오차/σ)²을 축마다 본다(정직하면 z² ≈ 1, 과신이면 > 1, 보수적이면 < 1). "±2σ 포함 비율"은 z² ≤ 4인 표본 비율이다. 표본은 로봇 r1·r2의 leg 끝 값이다.

| 코호트 | L1 x 평균오차 | L1 x / y / yaw 평균 z² | L1 ±2σ 포함 x / y / yaw | L1 NEES3 (참고) |
|---|---|---|---|---|
| cA (gain 없음) | **+61.5 mm** | **3.85** / 0.07 / 0.02 | **0.71** / 1.00 / 1.00 | 4.16 |
| cB (gain) | -3.3 mm | 0.03 / 0.19 / 0.04 | 1.00 / 1.00 / 1.00 | 0.27 |
| rA (gain 없음) | +66.4 mm | **4.28** / 0.06 / 0.13 | **0.53** / 1.00 / 1.00 | 4.47 |
| rB (gain) | +0.3 mm | 0.04 / 0.04 / 0.08 | 1.00 / 1.00 / 1.00 | 0.21 |
| sA (gain 없음) | +60.0 mm | **3.59** / 0.08 / 0.02 | **0.81** / 1.00 / 1.00 | 3.93 |
| sB (gain) | -5.5 mm | 0.06 / 0.21 / 0.03 | 1.00 / 1.00 / 1.00 | 0.33 |

- **gain 보정이 앞뒤(x) 편향을 없애고 x σ의 정직성을 고쳤다**(z² 3.6–4.3 → 0.03–0.06). 다만 **이제 x는 매우 보수적이다**(z² 0.03이면 σ가 실제 오차의 약 6배). y·yaw는 gain 유무와 상관없이 보수적이다. 이 보수성은 충돌 여유(σ 배수)와 yaw 관문을 더 세게 막는 방향으로 작용하므로, 정직성 기준은 "포함 비율 ≥ 90 %와 z² ≤ 1.3", 보수성은 정보로만 보고한다.
- y 평균 오차가 코호트마다 -8 ~ +15 mm로 일정하지 않다(cB·sB +15 mm, cA·sA +7 mm, rA -8 mm, rB 0 mm). 포함 비율은 100 %지만 원인은 이 실험에서 진단하지 않았다.
- L0 끝의 x는 보정 전 z² 1.4–1.5(경계), 보정 후 0.03: 보정이 L0에서도 같은 방향으로 작동한다(L0 통과는 cA/cB 모두 24/24).

## 남는 실패는 gain과 무관하다: L1 끝 오차는 시트 반올림 오프셋에 비례한다

rA/rB의 실패 6건은 모두 `MOTION_ERROR`(L1 끝 오차 103–112 mm, 100 mm 관문 초과)이고 gain 유무와 무관하다(오히려 111–112 mm로 약간 더 크다). sA/sB의 실패도 같은 코드다. sA/sB의 배치별 L1 끝 오차를 (빔 x − 반올림 시트 x = dx)에 대해 적합하면:

- sA: `끝 오차 = 64 mm + 1.08·dx`, 상관 0.97
- sB: `끝 오차 = 65 mm + 1.09·dx`, 상관 0.95

(`analysis/end_error_vs_sheet_offset.py`, 출력 `results/{sA,sB}_end_error_vs_dx.txt`.) 즉 dx = 0에서도 이미 64 mm이고, 빔이 반올림 시트보다 약 +33 mm 이상 앞이면 100 mm 관문을 넘는다. 시트 격자가 0.1 m라 dx는 ±50 mm에서 나오므로, 균등 분포 가정이면 통과율은 대략 (33+50)/100 ≈ 83 %다(관측 sA 10/12 = 83 %, sB 11/12 = 92 %와 일관). **이것은 다음 등록에서 기대 통과율이 80 % 문턱에 걸쳐 있다는 뜻이다.** 원인은 (a) 경로 시작점이 시트를 따라가고 빔은 dx만큼 떨어져 있는 것, (b) dx=0에서도 L1의 축 방향 이동이 계획보다 길다(예: 이동 0.893 m, 계획 0.85 m; 이번 실험에서 원인을 파고들지는 않았다). gain 패치는 PF 추정만 고치고 실제 이동은 바꾸지 않으므로 이 실패를 못 고친다.

## 진행 감시 p2f: 실제로는 무장하지 않았다 (fail-open)

- 모든 코호트에서 p2f가 기준선을 세운 횟수는 **0건**이다. 무시한 시도 1176건은 전부 `move_t0 = None`이었다(구간 시작 직후에 한 번씩만 fix를 시험함). 이동 명령이 나간 뒤에는 든 쌍에 신선한 fix(나이 ≤ 0.3 s, σ_xy ≤ 하한)가 다시 들어오지 않아 `trusted()`가 불리지 않는다.
- 따라서 **든 쌍(문 구역만이 아니라 든 구간 전체)에는 정지 감지가 사실상 없다**. "문 구역에서 fix가 없어 감지가 실패한다"는 독립 검토 지적(fail-open)은 이 연쇄에서 더 넓게 참이다. 사전 등록 초안에 사실로 적고 성공 판정의 근거로 삼지 않는다: 이 코호트의 통과는 "정지 감시가 잡아 주어서"가 아니라 "물리적으로 안 멈추고 도착해서"다.
- 등록 규칙(p2 이전)에서는 구간 시작 직후의 0.3 s 이내 fix가 기준선을 세우고, 0.4 m를 명령한 뒤 신선한 fix가 없으면 `POSE_UNCERTAIN_PROGRESS`로 멈춘다. p2f는 이 정지를 물리 코호트에서는 사실상 없앤 것이다. 기록된 hR2 시작에서 k1g+p2f는 14/20으로 PR #283의 k1g+p2와 같은 통과 수다(p2는 정지 상태의 최근 fix로도 무장하던 결함이 있었지만, 이 연쇄에서는 결과 차이로 드러나지 않았다).
- 이동 시작 시각 이후의 fix가 실제로 도착하는 상황(예: 내려놓기 재관측 뒤)에서 규칙이 어떻게 작동하는지는 단위 테스트(`test_p2f_*`)로만 확인했고, 물리 코호트에서는 관측되지 않았다.

## 지시서 질문에 대한 답

1. **(i) k1g+p2f (cA, rA, sA)**: 고정 시트 24/24, 기록된 hR2 14/20, 시트-반올림 20/24. x σ는 과신(z² 3.6–4.3, 포함 53–81 %).
2. **(ii) k1g+p2f+gain (cB, rB, sB)**: 통과율은 cA/rA/sA와 같거나 조금 낫다(sB 22/24 대 sA 20/24: 같은 배치의 S07·S12 중 S12가 통과로 바뀌었다). **σ 정직성은 세 축 모두 100 % 포함으로 고쳐졌다.**
3. **(iii) 보정만으로 완화가 필요 없는가**: **아니다**(cD, cC, cF). 보정은 등록 값 아래에서 L0의 충돌 차단을 줄이는 효과가 있다(L0: 등록 값 14/24 → 보정 후 22/24). 그러나 L1은 여전히 막힌다(충돌 가드 21건, yaw 관문 2건).
4. 성공한 배치에서도 남는 위험: 통과율의 배치 분산이 크다(고정 시트 100 %, 기록된 hR2 70 %). 다음 등록은 시트-반올림 분포로 정하는 것이 실제 조건에 가깝다.

## 남은 문제

- L1 끝 오차의 dx 의존과 dx=0에서의 64 mm 절편(축 방향 이동이 계획보다 길다)은 미진단이다. 등록 제어기 수정이 아니라 배치/판정 기준 문제일 수 있다. 다음 등록의 기대 통과율이 80 % 문턱에 걸린다.
- y 방향 평균 오차(-8 ~ +15 mm)의 일정하지 않은 편향 원인 미진단.
- p2f는 무장하지 않으므로, 정지 감지 자체를 어떻게 복원할지(문 구역의 fix 부재) 미해결. 등록은 fail-open을 수용하는 전제다.
- 시드 911/913은 독립이 아니고, PF 사전분포 다양성이 10개다.

## 참고 자료 (조사 요약)
