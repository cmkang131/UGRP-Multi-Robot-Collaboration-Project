2026-10-09 사용자 지시. GT는 이 문서의 저장 기록 채점에만 사용한다. 현재 제어기에 GT 입력·파라미터 적합0. egomap58의 큰 `own_tracked_path_m`은 **명령 DR 적분이 아니라 매 RGB 프레임의 RBPF posterior 위치 차이의 길이 합**이다(`goal-route-continuous/code/report.py:24–37`). 정합 보정·입자 선택 변경도 이동으로 합산되므로 실제 이동량의 추정치로 해석하면 안 된다. 원본 egomap58 표는 보존하고 여기서 세 열로 분리한다.

## 오프라인 진단 — 시동 손실 가설은 기각, 회전 횡축·posterior 점프는 남음

자기 발행 이력 `robots/r3/commands.jsonl`만 `RotationPulseOdometry`에 순서대로 재생했다. RGB는 같은 시각의 명령 발행 **전**이며, 실제 GT가 있는 시각까지만 비교한다. HOST 직전 제안은 backend에서 거부돼 발행 이력에 없으므로 적분하지 않는다. 마지막 발행 뒤 GT가 없으면 해당 펄스는 이동 비교에서 빼고 수를 JSON에 기록한다. 55002/4/5의 마지막 미발행 RGB도 GT 비교에서는 제외한다. 55003은 두 구간 전체이고 다른 실행과 합산 성공률을 만들지 않는다.
