# egomap69: 오차 예산·설계 진단 (실행 전 방법 고정)
- egomap68 기준선 63001–63006 전체 6개를 사후 분석한다. 새 물리·모델 호출·제어기 변경·문턱 적합 0; 기존 DEV이며 확증/E2E 성공 아님.
- 원본 명령을 동결 rotL 주행 모델로 적분; 회전/전진/정지별 실제 증분과 비교한다. 추정 posterior 경로 길이를 명령 DR로 오인하지 않는다.
- GT는 평가만: 원래 시작 변환, checkpoint에서 한 번 GT로 초기화한 DR, 매 시점 GT yaw를 넣은 진단 상한을 구분한다. posterior-prior는 입자 선택·Manhattan·CSM·경로 보정의 합으로, 순수 시각 보정/인과 기여율이라 부르지 않는다.
- B 판정은 기존 .20m·5프레임 그대로: 실제 경계 거리, 자기 근접, 현재 패치·확인·하단색·hold·timeout을 실행별 집계한다.
- RGB는 기준선 매25관측(5초) 고정 표본과 직전 프레임, egomap68 ORB/보정/차체 마스크 그대로; 특징·상단특징·연속 대응·E RANSAC 수. 실제 경기장 사진이 없어 sim/real 질감 차이는 미측정.
- 원본 x86/ARM 보존, Mac은 간결 JSON·그림만 fetch-lite. 결과·sha256·참고 자료·주 설계/대안은 summary.json에 기록한다.
