## 구현

- Nav2 RPP의 곡률 반경 규제와 **경로 잔여 길이 .6m 안에서만 목표 감속**을 보정 펄스 발행률에 적용했다. 직선 최대0.2초, 굽은/가까운 구간0.4초. PWM·0.1초 명령 길이·보정 응답은 그대로다. 연속 곡률 조향을 새로 보정한 구현은 아니다.
- 한 영상 사이 추가 전진은 최대1개. 첫 제안과 **실제 발행** 일치가 있어야 무장되고, 자기 발행 보정량으로 전진한 예측 자세에서 충돌 투영을 다시 검사한다. 영상0.4초 초과, 카메라/다른 명령·정지·파지·단계 변경은 취소한다. 이후 몸 스킬의 자기 RGB·초음파·지도 필터를 통과해야 실행된다. DEV 로그 전용 충돌을 빠른 펄스에 우회 적용하지 않는다.
- 경로는1초마다 재계획하고, 목표5cm 변경 또는 현재 자기 지도에서 경로가 막히면 즉시 다시 계산한다. 프레임별 추적·충돌 확인은 유지한다.
- 주행 카메라 팬에12° deadband를 둔다. 최종 시각 서보의 정렬 허용 오차·파지 조건은 바꾸지 않는다. 큰 팬 조정의 기존80 pulse/settle 절차는 유지한다.
- 마지막 자기 관측 방위부터 시작하고 그때 정한 좌/우 탐색 방향·시도 섹터를 이동 창 뒤에도 기억한다. 스캔은 **명령 자세가 발행되고 대기가 끝난 새 영상**을 받은 뒤 다음 시점으로 간다. 일반 탐색 창8초·무진척5초 뒤 기억한 다음 방위를 본다. 이 시간·섹터 폭은 로봇에 맞춘 DEV 설정이며 논문 성능 수치를 승계하지 않는다.
- `search_own_beam` 피드백 스킬을 공통 후보·안전 필터에 연결해, 코드 몸 게이트가 실행 층의 기억된 방향을 다시 고정 스캔으로 덮어쓰지 않게 했다.

## 저장 입력 재생과 예상 단축량

`approach-v351-own-inputs.json.zst`는 선택한 자기 RGB 판독·자기 추정·발행 명령·transport 사건만 보존한다. 실제 이미지 원본·평가·관절/접촉은 결정 입력으로 넣지 않았다. 원격 원본 파일 해시와 압축 해제 해시는 `approach-v351-summary.json`에 있다. 재생 명령:

```sh
python3 scripts/probe_e2e_approach_efficiency.py \
  --input experiments/2026-10-13-e2e18-body/approach-v351-own-inputs.json.zst \
  --log outputs/e2e18-body/r69-logs/e2e18-v324-s61006-r69-log.txt \
  --output outputs/e2e18-body/approach-v351-replay-new.json.zst
```

합계 입력 평가 **537/537 주행·114/114 팬**, 빠른 주기 대상215/537·팬 생략59/114. 이는 기능 적용 수이며 정답 스킬 정확도나 실제 주행 성공률이 아니다. 곡선 전체 polyline과 과거 costmap이 없으므로 .6m 밖이고 기존 projected_clear가 true인 제안만 주기 추정에 넣었다. 두 번째 펄스의 미래 충돌/신선도·몸 게이트 승인과 경로 재사용 효과는 추정하지 않았다.

**주행 약20–23초, 팬 대기 약22–26초, 탐색 이동 창 약34–36초/로봇의 감소 여지**가 있다. 항목은 겹칠 수 있고 새 경로에서 관측·재획득 횟수가 달라지므로 합산하거나435초에서 빼서 공동 파지 도달 시간을 예언하지 않는다. 스캔의 더 빠른 뷰 전환과 방향 기억은 성공 영상이 달라져 시간 점수를 붙이지 않았다. 통합 부모v350도 r69와 몸 선택기가 다르므로 실제 효과는 감독의 v350/v351 같은seed 비교가 필요하다.

## 검증·남은 일

- 관련3파일39/39 통과(`approach-v351-pytest.txt`). 실제 carrier advance의 발행 확인·1회 추가 펄스, 차단7종, 경로 주기/장애물/목표 변경, 카메라 발행/대기 장벽, 방향 기억, 몸 게이트 안전 우선, default off·부모 등록·변조 거부를 검사했다. 초기1회 실패는 시험의 근거리 fixture를 먼 구간으로 바로잡았고 sparse 누락 기존 JPEG를 HEAD 바이트로 복원한 뒤 해소했다. 초기 실패 및 중간 통과는 최종 분모에 합산하지 않는다.
- 물리/모델 실호출0. 첫30SIM 원본 점검·정렬→공동 파지 SIM 시간·재획득/좌우 진동 감소·E2E 도착은 **미확인**이다. VM 직접 제출 없이 감독자에게 요청한다.
- 기본off를 유지하며 v350을 아직 퇴역하지 않는다. 새 후보 실제 채택 전 비교 기준선이다.
