# E2E18 몸 결정과 대화 분리 (DEV, 기본 OFF)

Refs #461. `claude/e2e18-jevmotion`, 인계 기준 `495b606fe99e6ced0fa1659a9db89324f51e4c4e`.
미커밋 5개 파일을 이어받아 수정했다. 기본 체크아웃과 다른 작업 파일은 변경하지 않는다.

## 구조와 입력

`--body-controller jev_v1`에서 Gemma는 경로 제안·승인, claim, GO/ACK과 자연어 메시지만 결정한다.
몸·집게·카메라 움직임은 Jev `jev-1.13.0`이 코드가 만든 안전 후보에서 선택한다.
탐색/경로 추종, 정렬/접근, 파지 닫기, 합의 후 들기, 합의된 운반 구간, 내려놓기, relook/다음 구간에 연결한다.
고정 초기 카메라 SEARCH 설정은 첫 관측을 위한 초기화다. 런타임 선택은 첫 관측 이후부터 시작한다.
`continue`는 대화 행위 없음이며 몸의 정지가 아니다. 네 통신 조건의 메시지 본문·수신 경로는 그대로다.

- v335: v321 + Jev 몸 결정(기본 선택). v336: 동일 인터페이스의 유료 d1 교체 비교용, 기본 채택 아님.
- v337: v335 + `--body-visual-check d1_v1`; 잘림/보 안 보임에서 10 SIM초 간격 이하로 자기 RGB 범주를 교차 확인. d1 결과는 참고 범주이며 정답·새 좌표·파지 성공을 만들지 않는다.
- `--body-controller off`는 기존 경로. `d1:free` 재시도는 없다. 실패·늦은 답·후보 밖 응답은 정지 후 같은 백엔드에 재질의한다.
- VM에는 키가 없고 `127.0.0.1:18433` → 기존 유한 SSH 역방향 터널 → Mac `18434` 릴레이만 사용한다. 키는 Mac Keychain에서 메모리로 읽는다.

매 질의는 역할/카메라/동작 효과/우선순위 규칙, 현재 자기 RGB 범주·지도 목표/정렬 오차·나이/불확실성·자기 초음파·화면의 상대 외관·수신 대화 합의를 담는다.
최근 10개 결정과 새 영상의 결과, 단계 SIM 시간/60초 예산, 최근 20초 거리 진척, 재획득/진동 수, 마지막 목격 방향/나이, 시도한 복구를 유지한다.
모델에는 음수 방향 대신 `35 degrees to the RIGHT`처럼 명시한 단어를 보내고, 후보 효과는 기존 명령 보정에서 계산한다.
코드는 전방 근접·자기 지도 예상 충돌·좌우 반복 후보를 제거한다. 탐색 회전은 마지막 목격 방향으로 제한한다. 닫힌 그립과 실제 파지는 구분한다.
화면의 주황색 외관은 보수적인 상대 후보이며 정확한 로봇 식별/거리 측정은 아니다. 새 영상의 파지 서명 변화도 가설이지 접촉 정답이 아니다.

정체 시 후진 넓은 시야 → 자기 지도 standoff 복귀 → 카메라 팬을 순서대로 제시하고 이미 시도한 것을 제외한다.
복구 뒤 20 SIM초 동안 효과를 관찰한 다음 다음 전략을 판단한다. standoff 복귀는 최대 10 SIM초의 자체 지도 추종 동작이다.
GO/ACK 전에 들기를 허용하지 않기 위해 파지 닫기와 들기를 분리했다. 운반 중 중단된 보정 구간은 완료로 세거나 처음부터 자동 재생하지 않는다.
응답 대기 시간을 SIM 정지 구간으로 반영한다. 원래 코드의 수치 실행·제한 포트·실행기 승인 검사와 평가 전용 정답 출력은 유지한다.

## 검증 범위

관련 검사 63통과/1환경 skip. 원본·회차별 결과는 `summary.json`에서 확인한다.
VM3 v321 seed61006 r65 원본에서 16장면을 골라 자기 RGB·발행 서보/바퀴 명령·ownmap만 추출했다. frames의 `actuator_state`는 제외했다.
실행 가능한 제안이 없는 2장면은 분리해 기록했고, 14장면 ×3회가 모델 선택 비교 분모다.
첫 Jev 비교 30/42(정렬24/24), 탐색 맥락 수정과 합의 전 들기 라벨 수정 후 42/42; 같은 장면을 튜닝에 재사용했으므로 확증·물리 성공률이 아니다.
유료 d1 비교는 24/42, 응답36/42(단일 후보 파지 대기6건 거절), 중앙0.463초. Jev 해당 비교 중앙0.239초.
부호 방향의 단어화·후보 결과 예측 후 비교는 Jev 39/42(중앙0.234초), 정렬21/24다. 새 물리 실행은 별도로 기록한다. 조정자 비교 수치를 우리 분모에 합산하지 않는다.

기준 원본: `azure3:~/ugrp-sim/runs/e2e18-v321-s61006-r65/raw`.
기준 align76 → grasp_lift511 = 435 SIM초, carry544. 파지 시작 단계와 평가상 실제 공동 파지 시각은 구분한다.
기존 단계 탐침은 벽/팔 fixture용이며 76초의 전체 지도·대화·제어기 상태를 복원하지 않는다. 따라서 전체 E2E 1쌍으로 대체한다.
새 실행/속도 게이트/전체 CI가 아직 끝나지 않았으며 접근 시간 개선은 미확인이다. PR 병합은 조정자 독립 검토 후에만 한다.
