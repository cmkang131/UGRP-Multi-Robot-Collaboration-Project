# 시간순 검토 — gcp2 저장 상태와 원본 자기 RGB

검토 영상은 gcp2에서 개요+r1+r2를 나란히 만들고 3배속 H.264로 인코딩했다. `ffprobe`로 실제 stream/길이/크기를 확인했다. Mac에서는 화면 앱을 열지 않고 아래의 **전체 2Hz와 끝10초 10Hz 프레임띠를 모두 파일로 읽어 직접 검토**했다. [생성·회수 해시](runtime/playback-verification.json)에 gcp2 원본·Mac 위치와 검증한24개 파일이 있다. R1 영상28,378B, R2 영상204,443B, R3 영상13,816B, 각각8MB 미만이다.

|실행/본 범위(절대 SIM초)|시간순으로 보인 동작|원장과의 관계/한계|
|---|---|---|
|R1 감독 중단,1.3–4.6 전체2Hz·동일 범위10Hz|1.3–1.7 초기 카메라 회전.1.8–2.7 r1은 빔을 보지만 r2 화면에는 큰 벽 면이 차지한다.2.8–4.6 r2 화면은 대부분 파란 바닥이며 r1은 먼 빔을 본다.개요에서는 두 로봇이 접근을 시작하고 빔은 그대로 있다.|중단 시점까지 pick/들기 장면은 없다.멈춤은 모델 차이 검토를 위한 감독 중단이며 물리 실패/진동 때문이라고 주장하지 않는다.실제 원본10Hz 자기 RGB58장 사용, 그 밖은 저장 상태 재구성.3.3초밖에 실행되지 않아 이전10초가 존재하지 않는다.|
|R2 성공,1.3–29.4 전체2Hz,19.4–29.4 끝10초10Hz|1.3–8.8 둘러보기·접근 동안 자기 화면에서 빔이 여러 번 빠졌다 돌아온다.9.3–15.8 서로 다른 파랑/청록 끝이 점점 커지고 가까워진다.16.3–21.7 각자 자기 끝을 향해 계속 접근한다.22–24.8 끝 띠가 화면 아래로 내려가고,25.3–29.4 화면 대부분이 빔으로 채워진다.마지막10초10Hz에서는 빠르게 좌우를 왕복하는 제한 주기나 같은 끝에 두 로봇이 몰리는 모습은 보이지 않았다.|최종1/1은 원본 GPU 접촉·높이·양쪽 유지 평가식 결과다.위에서 내려다본 영상만으로 파지/높이 성공을 재판정하지 않았다.저장 상태 C3.12 재렌더는 원본GPU RGB가 아니다.|

R3 N64 감독 중단 실행도1.3–1.9 SIM초 전체2Hz/10Hz 두 프레임띠를 직접 봤다. 초기 pan 동작 뒤 원본1.8–1.9초 화면은 대부분 바닥이며 다른 로봇 일부가 보인다. 파지 전에 끝났으므로 물리 실패 원인이나 성공을 추론하지 않았다. 원본 ring은4장뿐이고 그 전은 저장 상태 재구성이다.

R2의 원본 자기 카메라는 성공 시1Hz 저장이므로 **원본10Hz라고 부르지 않는다**. 저장 qpos/qvel의10Hz를 C3.12에서 `mj_kinematics`/`mj_camlight`로 재구성하고, 기록한 실제 카메라 pos/quat/intrinsic/resolution을 적용했다. `mj_step`은 호출하지 않았다. RGB 차이를 숨기지 않도록 프레임마다 `saved-state C312 render`를 표시했다. R1의 존재하는 원본 실패/중단 ring은 `original10Hz`로 표시했다.

추가로 R2 원본1Hz에서12시점의 자기 RGB를 직접 대조했다(`original-gpu-own-1hz.jpg`, 원본 elapsed0/2/5/7/10/12/15/17/20/22/25/27초). 빔 끝으로 접근하는 흐름은 재구성과 맞지만, **GPU 원본 바닥은 단색 파랑이고 C 재구성은 회색 체크 무늬**다. 형상·카메라 수치를 유지했어도 렌더가 동등하다는 근거는 없다. 이 차이의 원인을 parent의 알려진 partial-alpha 문제와 같다고 단정하지 않는다. ACT 학습/시각 위치 추정/LLM E2E로 이 RGB를 승계하려면 원본 RGB 차이를 별도로 해결·검증해야 한다. 이번 visible-only 정답 교사의 물리 성공을 학생/위치 추정 성공으로 해석하지 않는다.

2Hz만 보면 접근이 순조롭게 이어지는 것처럼 보이지만 초기 자기 화면에는 바닥·벽만 보이는 구간이 반복된다.10Hz 확인은 끝10초의 급격한 왕복 유무를 제한된 범위에서 확인해 준다. 실제 제어에 입력된 모든 시점의 원본 RGB를10Hz로 검토했다는 주장은 하지 않는다.
