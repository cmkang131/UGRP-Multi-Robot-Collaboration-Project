- 단계 변경은 시험용 과제 전환이며 강제 위치 초기화가 아니다. B 미도착 후 귀환도 따로 표기하고, 전체 임무 성공은 **B와 귀환 모두 GT 평가 유효**인 경우만 센다.

## 실행·사전 판정

로컬 바뀐 모듈 시험 → 커밋/push → oracle-x86에서 동일 체크포인트 ≤10초 복원 smoke 1회(필요시) → **12개 전체 목록 한 묶음** 제출. 동시 실행 상한은 직전 승인 10개이므로 10 실행+2 대기, 여유 RAM 6GiB 미만이면 대기. Mac 물리/녹화 재생 0. 결과 후 설정 변경/재튜닝 없음.

- 조건별 B 도착 n/6, 귀환 n/6(선언 시 GT 시작점 거리 ≤0.20m), 둘 다 n/6, 거짓 선언 수, 벽/로봇 접촉 event 및 실행 n/6.
- >3σ는 원래 정의(XY 실제 오차 / sqrt(공분산 최대 고유값)) >3인 프레임 n/N 및 종료 n/6. NEES라고 부르지 않는다. 종료 오차 중앙/최대, 접근/귀환별 분모도 기록한다.
- B 선언은 GT 차체 중심이 실제 B 사각형 안인지 평가만. 실행별 접근 시작/최근접 B 경계 거리(안이면 0), 접근/귀환 SIM초·GT 시작점 종료 거리.
- 명령 비율: 자기 발행 명령 전체(hold 포함) 중 회전/전진/측면/hold, 이동 명령만의 회전 비율도 병기. 회전 부호 반전은 연속된 회전 펄스들(hold 제외) 기준, 전진 사이 회전 묶음별 반복 횟수/최댓값과 shared heading 행의 정렬 이유 집계. 원인 기록만, 수정하지 않는다.
- 차단·HOST_ERROR·호스트 중단도 각각 등록 12분모에 남기고 측정 없는 값을 0성능으로 꾸미지 않는다. 유효 raw의 n/N을 따로 병기. ENOSPC는 HOST_ERROR. 원격 중단은 감독의 기존 동일 SHA/명령 재제출 규칙에 따른다.
- 이번은 DEV 6쌍의 예산 진단이며 새 확증/품질 관문 통과로 표현하지 않는다. 결과는 60초 egomap63과 조건 구분하여 비교하고 합산하지 않는다.
