# 봉 파지 감사와 정답 교사 → ACT 학생

Refs PR #461, #475, #480, #483. 작업 PR #484. **40회 교사 관문 진행 중이며 학습 데이터·학생 물리 평가·학습 모델은 아직 없다.**

판단 LLM은 허용 관측으로 스킬을 고른다. 시연 전용 교사는 전체 정답을 알고, ACT 학생은 자기 RGB 이력·자기 발행 명령·스킬 번호표만 받는다. 주행·운반은 지도 코드다. weld OFF와 현행 카메라·외관·물리를 유지한다.

- 감사: 집게 한쪽 여유 **10.5 mm**, 끝 추정 오차 중앙 **69.5 mm(6.6배)**. 가까운 0.3 m 미만도 중앙 **10.7 mm**, p95 **254 mm**다. 원본 72실행을 재집계했고 r69/r76/r80 독립 재집계는 미완료다.
- 중단 펄스 교사: 조정자 요청에 따라 16개 모두 interrupted, 관문 **0/0**. 60 ms 회전 중앙 **3.41°** 대 허용 **±1°**, 최대 **134회** 부호 역전을 확인했다.
- 연속 교사: 기존 zone_teacher의 비례 주행과 IK를 재사용했다. 가까운/먼 시작 진단 **2/2**, 완료 **29.6/20.6 SIM초**. 다음 관문 후보는 접근에서 31–38 mm에 멈춰 **11/11 완료·5중단·24미시작**으로 종료했으며 관문 통과가 아니다.
- 수정 `078cbb45`: 정렬 인계를 8 cm로 옮기고 최종 3 cm+IK 기준은 유지했다. 이전 정지 상태 재진단 **2/2**, 완료 **21.7/16.8 SIM초**, wall/SIM **2.531/2.713**. 각 실행 0/6/12/18/24/29초를 직접 봤다. 같은 소스로 16속도→40회 관문(≥38/40)을 시작했다.
- 측정 중 학생 RGB는 **0**이며 저해상도 검토 영상과 명령·평가만 보존한다. 실제 학생 규격의 학습 기록은 관문 이후다. ACT 실제 CPU forward/backward·저장/재로딩·구 계약 거부 **3/3**, 관련 오프라인 검사 **27/27** 통과는 물리 성공과 별도다.
