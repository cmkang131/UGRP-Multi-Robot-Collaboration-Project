# 봉 파지 감사와 정답 교사 → ACT 학생

Refs PR #461, #475, #480, #483. **개발 중이며 새 교사·학생 성공은 아직 측정하지 않았다.**

2026-10-14 사용자 결정에 따라 감사·설계에서 교사 구현, 데이터 생성, ACT 학습·평가까지 범위를 넓혔다. 판단 LLM은 정답 위치를 모른다. 시연 전용 교사 코드는 전체 정답을 알고, ACT 학생은 자기 영상 이력과 자기 발행 명령으로 LLM이 선택한 스킬을 실행한다. weld OFF와 기존 카메라·로봇·봉 형상을 유지한다.

- [설계와 검증 순서](design.md): 교사 성공, 데이터 적합도, 재생, 새 시작 상태 학생 성공을 분리한다.
- [참고 자료](references.md): 고정 LeRobot ACT 재사용, privileged teacher, DART, DAgger.
- [기계 판독 상태](summary.json): 감사·교사·데이터·학습·평가의 완료 범위를 구분한다.
- [재개 기록](progress.md): 다음 작업과 VM 사용 조건.

승인 구독의 Korea Central GPU 계열 할당량은 조회 시 모두 0이었다. GPU 자원 생성·크기 변경·IAM 변경은 하지 않았다. VM3는 다른 작업이 사용 중이다. PR #483의 **“VM3 비움”** 코멘트 또는 조정자 확인 전에는 사용하지 않는다.
