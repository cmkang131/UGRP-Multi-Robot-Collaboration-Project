## 바꾼 것

기본 OFF인 `--approach-coordination prioritized_approach_v1`은 정확한 기준 프로필
(`align_relook_v1`, `search_body_scan_v2`, `approach_goal_set_v1`,
`nominal_blocked_handoff_v1`, `approach_progress_v1`, `approach_recovery=off`)에서만 허용한다.
파랑이 관측 빔 좌표계의 y=-0.65m 대기점으로 이동 → 청록 접근·정렬 → 파랑 접근·정렬 → 공동 집기다.
대기점 x는 파랑의 첫 관측 시 자기 명령 좌표계로 결정하며, 상대 실제 위치나 경로를 전송하지 않는다.
각 전환은 기존 boolean READY→GO→ACK 장벽을 새로 열어 정한다. 최종 집기 지연은 기존 값을 유지한다.
청록은 파랑 접근 중 READY가 취소되어도 다시 병진하지 않는다. 마지막 두 로봇 READY와 GO/ACK가 없으면 집지 않는다.

계획·발행 펄스는 보이는 대상/유효 기억과 자기 발행 명령으로 만든 좌표계에서 검사한다.
양 끝 예약 영역·서로 반대쪽 통로를 더하고 기존 물리 여유를 줄이지 않는다.
대기점 허용 오차25mm, 예약 끝 여유380mm, 청록 이동 경로와 파랑 대기 영역 간 최소 설계 분리375mm다.
기존 A*를 재사용하되 정확한 시작/끝점과 모든 연결 선분을 다시 검사한다.

이력 만료/표적 없음은 표본을 채택하지 않으며, 최종 짧은 blind 구간은 유효 기억 범위에서 유지한다.
