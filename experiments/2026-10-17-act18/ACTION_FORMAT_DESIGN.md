# act18 행동 형식 표준화 design note (실행 없음, 다음 승인 카드)

2026-10-18, Phase A 감사 후속(Lead 자율 트랙 항목 4). **코드·실행 없음.** 근거: RECIPE_AUDIT.md, contract `encode_action`/`decode_action`, act-plus-plus `imitate_episodes.py`/`utils.py`.

## 현재 우리 행동(14차원, 고정 계약)

| 차원 | 의미 | 인코딩(학습 표적) | 디코딩(실행) |
|---|---|---|---|
| 0..3 | 바퀴 4개 속도 | 원값 full-scale(교사 ±.35, 0) | `|w|<.155→0`, `|w|→.31–.40` 스냅, done이면 0 |
| 4..7 | 각 바퀴 펄스 지속 | `dt/0.15` (0..1) | `dt=.15*v`, ≤.15s, wheel=0이면 0 |
| 8..12 | 서보 5개 PWM (`SERVOS` = servo 1 gripper, 3 wrist, 4 elbow, 5 shoulder, 6 yaw) | `(pwm-1500)/1000` | `1500+1000*v` → 500–2500 clamp |
| 13 | 완료 | 0/1 (balanced BCE) | `>=.65` |

- 표준 ALOHA/ACT: 행동 16차원 = 양팔 **절대 관절 목표 14**(6관절×2+그리퍼2) + **base 속도 2**(v,ω). 목표는 데이터 로드 시 mean/std 정규화, base는 5샘플 이동평균(act-plus-plus `preprocess_base_action`). 실행은 위치 서보 + base twist 명령이고, **done 헤드가 없다**(종료는 환경 성공/시간).
- 차이 핵심: (1) 우리는 관절 목표가 아니라 PWM/펄스 명령을 직접 회귀; (2) base가 2차원 속도가 아니라 바퀴4×펄스2의 8차원; (3) 디코더가 학습 목표 분포와 다른 하드 클램프/데드존을 적용; (4) done은 우리 고유.
- B1·B2에서 관찰된 정지/조기 종료 병리는 (1)(3)의 영향 가능성이 있다: teacher wheel ±.35가 정규화 후 회귀되고 다시 .31–.40로 스냅되며, 작은 wheel 값은 데드존에서 0이 된다. 이는 "회귀 오차→정지 변환"(SURVEY 16행의 가설)과 맞물린다.

## 후보 A (저비용, 방어적 정합) — 권장 1순위

1. **학습 표적 스케일 명시**: wheel 차원을 `w/0.40`로 고정 스케일 정규화(또는 mean/std 유지하되 std floor 적용), duration·PWM은 기존 고정 스케일 유지. decode의 `.155` 데드존·`.31–.40` 스냅은 **추론 전용 후처리로 분리**하고, 학습 목표는 연속값 그대로 둔다(현재는 동일 계약 공유).
2. **base 5샘플 이동평균**: B2에서 이미 default-off 구현(`--base-smooth-window 5`). B3까지 유지.
3. **추론 명령 스무딩**(후보 전용, 기본 off): wheel/duration 출력에 3–5틱 이동평균을 적용해 펄스 지터 감소. 단 이는 정책 행동을 바꾸므로 새 후보·prereg 필요.
4. **비용**: 코드 0.5일, 테스트 3–4개, 물리 TRAIN4 1회(≈15분) + VAL8(통과 시). 기존 결과와 pooling 금지.
5. **위험**: 데드존/스냅을 추론 후처리로 옮기면 실제 명령 분포가 바뀌어 기존 R8/R100과 직접 비교 불가(새 후보로만 해석).

## 후보 B (표준 형식 정렬, 고비용) — Phase D 이후

- 행동을 **7차원** = [v, ω, 팔관절 3(rad), 그리퍼 2(rad/폭), done] 또는 8차원(그리퍼 개별)로 재정의. 
  - 데이터: 교사 `clean_teacher_command`의 PWM을 관절각으로 역매핑(서보 캘리브레이션: 1500 center·1000/rad 가정 검증 필요)하고, wheel 4개를 differential-drive로 (v,ω)로 변환. teacher 라벨에는 관절/IK가 허용되나(교사 학습 예외), **학생 입력에는 측정 관절 금지**를 유지한다.
  - 실행: 예측 관절각을 위치 서보 PD로 추종하고 (v,ω)를 wheel 속도로 믹싱. 시뮬 액추에이터 인터페이스에 위치 제어 래퍼 필요.
- **비용**: 개발·테스트 2–3일, 캘리브레이션/검증 실행 3–5회(2–3h GPU), 새 데이터 없이 재사용 가능성 높음. 평가 계약(decode_action) 변경을 수반하므로 **공식 채점 정의는 사용자 승인 전 변경 금지**, 새 후보 prereg로만 비교.
- **위험**: PWM↔관절각 캘리브레이션 오차, 위치 서보 래퍼의 지연/진동, 기존 레퍼런스와 직접 비교 불가.
