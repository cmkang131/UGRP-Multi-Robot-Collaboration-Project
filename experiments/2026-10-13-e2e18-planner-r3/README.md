`planner_evidence_gate=on_v1`, 기본 off. 30초를 넘은 보고나 더 최신인 자기 관측과 충돌하는 보고는 메시지 ID·나이·자기 관측 시각·원문 해시를 남기고 판단 본문에서 제외한다. 원문은 실제 채널 및 요청 밖 감사 기록에 보존한다. 후보마다 public 비용의 상태 의존성 또는 명시된 물체/통로/파트너 의존성을 기록한다. 근거가 부실한 후보는 확인 대상/낮은 우선순위로 표시한다. 공개 비용식에서는 사전 분포로 계산한 기대 비용을 사용하고, 비용식이 없는 native 경로에서는 신뢰 가중치 0.25를 사용한다. 실행 가능한 act/args 목록은 그대로 두고 Gemma가 선택한다. 최신 메시지 자체가 틀렸고 자기 증거가 없는 경우에는 감지할 수 없다.
