# 후보 근거 신선도 게이트 r3

`planner_evidence_gate=on_v1`, 기본 off. 30초를 넘은 보고나 더 최신인 자기 관측과 충돌하는 보고는 메시지 ID·나이·자기 관측 시각·원문 해시를 남기고 판단 본문에서 제외한다. 원문은 실제 채널 및 요청 밖 감사 기록에 보존한다. 후보마다 public 비용의 상태 의존성 또는 명시된 물체/통로/파트너 의존성을 기록한다. 근거가 부실한 후보는 확인 대상/낮은 우선순위로 표시한다. 공개 비용식에서는 사전 분포로 계산한 기대 비용을 사용하고, 비용식이 없는 native 경로에서는 신뢰 가중치 0.25를 사용한다. 실행 가능한 act/args 목록은 그대로 두고 Gemma가 선택한다. 최신 메시지 자체가 틀렸고 자기 증거가 없는 경우에는 감지할 수 없다.

원래 튜닝 384개(비애매 331·애매 53) × 네 조건 + 단독 24개, 신규 seed 2026101303의 별도 384개 × 네 조건 + 단독 24개. 이전 확증 seed 2026101302 및 문장은 재사용하지 않는다. 새 generator를 모델 호출 전에 고정한다. 신규 자료도 같은 합성 비용식과 상태 순환을 사용하는 문장/비용 일반화 검사이며 독립 현장 자료가 아니다. 정답은 결정 이후 평가에서만 결합한다.

실제 경로 등록: main 및 열린 PR 9개 전체의 RUNNABLE_ID와 E2E workflow를 조사한 최댓값 386 다음 **v387 (Gemma gate), v388 (동일 입력 규칙 gate)**. 기존 v373/v374는 gate off. v373/v374 및 새 버전 모두 VM 실행을 제출하지 않는다. 사용자 순서대로 #475/#476 단계 시험 이후에만 가능하다. 이번 기록에는 실제 장면 실행 결과가 없다.
