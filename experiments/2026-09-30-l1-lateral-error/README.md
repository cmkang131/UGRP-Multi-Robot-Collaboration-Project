# L0·L1 측면 끝점 오차 재검증 — 2026-09-30

Refs #221. **기존 raw의 탐색적 오프라인 분석이다. 확증 결과나 관측 완주율이 아니다.**
물리·렌더·모델 호출·로봇 명령 발행 0회. `outputs/`는 읽기만 했다.

## 판정

**현재 등록 후보의 48/60 관문은 안심할 수 없다.** 측면 오차만 다루는 조건부 모형은
약 **59.14/60(98.56%)**, 계수 불확실성을 반영한 기대 통과 수의 부트스트랩 90% 대역은
**58.32–59.85**다. 그러나 등록 후보 `3afc61b0`의 기존 수용성 기록에서는
주 비교 10건 중 **6건이 L0 뒤 재파지 관측에서 정지**했다. 이 실패는 측면 끝점 모형의 범위 밖이다.
따라서 이 수치를 **b-v6h1 실제 완주율**로 읽거나 확증 실행 승인 근거로 삼으면 안 된다.

기존 99.5% 예측의 측면 모형도 보정이 충분하지 않았다. 34개 배치 조건을 코호트별로 빼고 검증하면
학습 잔차로 만든 명목 95% 구간의 L1 포함률은 **21/34 = 61.8%**다.
배치 방식에 맞춰 모형을 제한하고 시작 사전분포의 방향 오차를 포함하면 보류 예측은 나아지지만,
독립적으로 설계된 코호트가 세 개뿐이고 큰 꼬리를 검증할 표본은 부족하다.

우선 등록 경로의 정지를 해결·재검증한 뒤, 아래 **새 배치/사전분포 조합 6건(예상 357.2 SIM초)**을
추가하는 것을 권한다. 확증 60곳 자체를 미리 시험하지 않는다.

원본은 **로컬 보관**이며 GitHub 백업으로 표현하지 않는다.

무하중 분포나 하중 효과를 이 자료에서 추정할 수 없다. 시작이 loaded라는 표시는 끝까지 파지를 유지했다는 판정이 아니다.
구간·이동축·하중·축/측방 lag·gain별 전체 분포는 [`results/strata.csv`](results/strata.csv),
코호트별 진행축/측면/yaw 분포는 [`cohort_distributions.csv`](results/cohort_distributions.csv)에 있다.

## 4. 모형·보류 검증·독립성

회귀 단위는 한 배치의 두 시드 평균 **L0/L1 쌍**이다. 기존 cB/rB/sB 34곳을 먼저 재검증했고,
업데이트 표는 cB 11 + tR 10 + tS 12 + tX1/tX1b 7 = **40개 배치 조건**이다.
같은 배치의 ON/OFF·시드·수용성 재생을 학습/검증에 나눠 넣지 않았다.
실행 중단으로 나뉜 tX1/tX1b는 같은 X 모집 설계로 묶는다.
holdout 단위는 C/R/S/X **모집 코호트 전체**이며 행 단위 무작위 분할이 아니다.

같은 물리 배치 `cB/F_hR2_04`와 `X/X00_F_hR2_04`는 시트가 다르다. 두 번 세지 않고
목표에 맞는 lag-ON/coarse-sheet X만 남겼다(`duplicate_units.json`). R의 10개도 서로 다른
사전분포/로봇 상태이며 10개의 독립적인 빔 위치는 아니다. R04–06 등 같은 빔 위치를 공유한다.
보류 검증에서는 다른 코호트에 있더라도 거리 ≤0.1 mm·yaw 차 ≤0.01°인 배치를 학습에서 제거한다.
기존 34곳 재검증에도 이 제거를 적용했다(C 보류 시 R의 3행, R 보류 시 C의 1행 제거).

확증의 station 배치 방식(`ENVS`)과 기록된 로봇 자세의 `hR2`는 다르다.
R을 학습에서 뺀 모형으로 R을 예측하면 L1 평균 보류 오차는 약 +40 mm다.
R을 다른 모집단의 대조로 남기고 **C/S/X 30곳**에 제한한 모형을 주 조건부 예측으로 쓴다.
R 포함 40개 배치 조건 예측도 함께 제시한다. 이 분리는 탐색적으로 정한 것이며 확인 실험을 대신하지 않는다.
C는 고정 시트/axial lag OFF이고 S/X는 반올림 시트/ON이라는 남은 차이도 있다.

주 모형(측면 mm): `1 + 배치 yaw(도) + (배치 y−0.05)(mm) + prior yaw 오차(도)`.
마지막 항은 확증 배치 JSON이 고정해 둔 `prior`에 해당하는 hR2 두 로봇의 기록 오차 평균이다.
새 카메라를 읽어서 얻는 값도, 런타임에 GT를 전달하는 장치도 아니다.

```text
L0 = −2.52 + 4.15*yaw + 0.423*(y−0.05)_mm − 12.33*prior_yaw_error
L1 = −11.47 + 6.50*yaw + 0.273*(y−0.05)_mm − 17.36*prior_yaw_error
```

prior y와 dx까지 넣으면 L1 보류 RMSE는 19.09 mm로 개선되지 않고, 작은 X 코호트로 계수를 정할 때
구간 폭이 불안정해져 주 모형으로 선택하지 않았다. 후보 전부를 `models.json`에 남겼다.
시작 yaw 학습 범위는 −4.16…+4.24도라서 C02/C11/C14/C23/C41은 약간 외삽한다.

| 검증 | L0 / L1 보류 RMSE(mm) | 명목 95% 구간의 L0 / L1 포함률 |
|---|---:|---:|
| 기존 34곳 모형, 학습 잔차 분위수 | 14.83 / 36.40 | 79.4% / **61.8%** |
| 40개 배치 조건 풀링, 학습 잔차 분위수 | 14.30 / 31.04 | 85.0% / 77.5% |
| 목표 30곳 + prior, 학습 잔차 분위수 | 12.81 / 19.08 | 73.3% / 90.0% |
| 목표 30곳 + prior, 내부 코호트 holdout으로 구간 보정 | 같은 값 | 100% / 93.3% |

마지막 행은 **외부 보류 코호트를 구간 폭 결정에 쓰지 않은** 중첩 검증이다(시드 평균 기준).
실제 예측에 쓰는 *계수 부트스트랩 + 보류 잔차 + 단일 시드 편차* 분포도 별도로 외부 검증했다.
이때 한 배치의 **두 시드가 모두 포함되어야** 배치 하나가 포함된 것으로 센다:

| 명목 예측 구간 | L0 | L1 | 두 leg 모두 |
|---|---:|---:|---:|
| 50% | 17/30 | 19/30 | 13/30 |
| 80% | 27/30 | 26/30 | 24/30 |
| 90% | 30/30 | 28/30 | 28/30 |
| 95% | 30/30 | 30/30 | 30/30 |

**100% 포함이 정확한 보정의 증명은 아니다.** 외부 코호트를 빼면 학습 모집 설계가 두 개만 남아서,
95% L1 구간의 코호트별 평균 전체 폭은 95–149 mm다. 매우 넓은 구간으로 포함한 면이 있다.
40개 배치 조건 풀링의 실제 부트스트랩 예측 구간은 95%여도 L1 **34/40**만 포함한다.
새 모집단에 대한 명목 95% 보장이나 확증 수준의 검증을 주장하지 않는다.

독립성 감사:

- 같은 배치의 두 시드 L1 상관 **0.994**. 절댓값 차이 중앙 2.12 mm, p95 7.13, 최대 12.78 mm다.
  80케이스를 80독립 배치로 세지 않았다. 예측은 시드 평균을 그대로 단일 시드로 착각하지 않도록
  배치 내 L0/L1 편차를 잔차 분포에 합성한다.
- 목표 모형의 L0/L1 보류 잔차 상관 **0.808**. 두 leg의 잔차를 한 쌍으로 뽑고 통과 확률을 곱하지 않는다.
- 30곳에서도 같은 prior가 2–6번 등장하고 확증 60곳도 그 10개 template을 재사용한다.
  prior별 잔차 ICC는 fit −0.041 / 보류 −0.072으로 추가 양의 효과를 입증하지 못했다.
  그래도 표본이 작고 모든 확증 배치가 PF seed 941을 공유하므로 독립을 증명한 것은 아니다.
- PR #286도 계수와 tick phase는 60곳이 공유하지만 잔차 쌍은 배치마다 독립으로 추첨했다.
  이번에는 같은 구조의 독립 잔차와, **한 번 뽑은 잔차 코호트를 60곳이 공유하며 같은 prior끼리 같은
  잔차 쌍을 공유**하는 민감도를 함께 계산한다. 후자는 자료로 추정된 정확한 공분산이 아니라 의존성 stress다.

## 5. 확증 후보 60곳 조건부 재예측

입력은 PR #286에 보존된 파일(sha256
`bb8044058377d86efc658ce3a7458c8afc141680acfd98542260e0efda018454`)과 동일하다.
진행축은 기존 `plant_model.py`의 **P1b(κ 보정 + axial lag)**, 정지 틱 위상 40개를 그대로 사용했다.
P1b는 등록 후보의 해당 시간 계산을 가정하는 것이며 정상 b-v6h1의 재파지 guard를 재현하는 모형은 아니다.

**예측 사건:** 두 leg에 도달하고 물리/시간 계산이 이 자료처럼 동작할 때,
L0와 L1의 `hypot(axial, lateral) ≤ 100 mm`를 모두 만족한다.
접촉·파지·재관측/팔 가드·sigma 판정·HOST_ERROR·방출·이후 leg·E2E 완주는 포함하지 않는다.

코호트를 복원 추첨하고 그 안에서 배치를 추첨해 2,000번 회귀 계수를 맞췄다(seed 20260930).
학습 잔차 대신 모집 코호트를 뺀 잔차를 사용하고 코호트에 같은 가중치를 주며,
위 단일 시드 편차와 L0/L1 결합을 보존했다. 계수는 한 draw 안의 60곳에 공통이다.
표의 대역은 **조건부 기대 통과 수의 5–95 분위수**이고 실제 횟수의 구간과 다르다.
잔차 분포 자체의 불확실성까지 완전히 포괄하는 신뢰구간도 아니다.

| 모형/측면 전체 배율 | 기대 통과 /60 | 계수 불확실성 90% 대역 | P(≥48), 독립 잔차 | P(≥48), 코호트·prior 공유 |
|---|---:|---:|---:|---:|
| 목표 30곳, ×1 | 59.14 | 58.32–59.85 | 0.997 | 0.997 |
| 목표 30곳, ×1.5 | 54.12 | 50.24–57.22 | 0.977 | 0.929 |
| 목표 30곳, ×2 | 46.06 | 40.49–50.97 | 0.399 | 0.456 |
| R까지 풀링 40조건, ×1 | 58.48 | 56.44–59.72 | 0.992 | 0.990 |
| R까지 풀링 40조건, ×1.5 | 50.09 | 45.05–53.83 | 0.793 | 0.690 |
| R까지 풀링 40조건, ×2 | 40.05 | 34.39–44.21 | 0.030 | 0.215 |

공유 조건의 **횟수** 90% 예측 구간은 목표 모형 ×1에서 57–60, ×1.5에서 **46–59**,
×2에서 34–56이다. MC 표준오차는 P≥48 각각 0.0012/0.0057/0.0111이며 모형 불확실성과 다르다.
×1.5/×2는 기존 민감도와 같이 평균과 잔차를 합친 **서명 측면 오차 전체**에 곱한다.

두꺼운 꼬리의 별도 stress(자유도 3 Student-t, 같은 보류 공분산, prior 공유, 5,000 draw)는
기대 59.05/60, P≥48=0.9984다. 작은 표본으로 t분포의 꼬리를 검증·선택했다는 뜻은 아니다.
이 예에서는 꼬리 모양보다 **측면 오차의 전체 규모와 모집 조건의 이동**이 더 큰 민감도였다.

가장 낮은 배치별 조건부 확률: C12(0.611), C41(0.818), C14(0.908), C23(0.963).
상세 60행은 [`placements.csv`](results/placements.csv)에 있다. 이 배치들을 먼저 돌려 확증 표본을 소모하지 않는다.
현재 자료의 모형 안에서는 48/60에 여유가 있으나, **1.5배 규모 변화만으로 공유 조건 미달 위험은 7.05%**다.
더구나 2절의 정상 등록 경로 정지는 이 확률에 들어 있지 않다. 실제 전체 관문 위험은 수치화하지 못했다.

## 6. 조정자에게 권하는 추가 시험 — 이번 작업에서는 실행하지 않음

**먼저 등록 인수 차단을 해결한다.** 고정한 최종 후보로 S07(0.932, 0.037, −4.16°, hR2_05),
X01(0.940, 0.050, −3.51°, hR2_07)을 각각 seed 911, coarse sheet,
chain-stop-leg 1로 재확인한다. 원본 예상 총 시간은 **2 × 62.8 = 125.6 SIM초**다.
전역 margin override 진단의 통과를 정상 후보의 수용성으로 대체하지 않는다.
이 두 건은 최소 차단 확인이며 별도로 정한 전체 인수 목록을 대체하지 않는다.

이후 측면 모형을 위한 우선 **6건**, 모두 새 탐색 seed **951** 한 번씩:

합계 **357.2 SIM초**, 앞의 최소 인수 확인을 더하면 **482.8 SIM초**(약 8분).
A는 위험한 음의 yaw·측면·반올림 경계, B↔C는 같은 위치에서 yaw 부호,
A↔C는 같은 yaw에서 위치/측면 차이, 각 prior 쌍은 시작 사전분포 효과를 비교한다.
prior_04는 기록 yaw 오차 약 1.1°, prior_07은 약 0.21°이지만 기존 최대 측면 사례 X01의 prior다.
세 위치에서 yaw와 측면 오프셋을 교차 비교하도록 정했다.

여유가 있으면 A/C에 **hR2_10**을 하나씩 더한다(seed 951; **119.7 SIM초**, 측면 시험 8건 총 476.9초).

이 효율은 설계상 판단이며 실제 정보량을 최적화했다는 실험 결과는 아니다.

[`proposed_probes.json`](inputs/proposed_probes.json), [`proposed_probe_extra_priors.json`](inputs/proposed_probe_extra_priors.json)은
`--env-placements` 형식이다. 나머지 조건은 고정 후보 `b-v6h1`, teacher chain, coarse sheet,
`--chain-stop-leg 1 --prior-std e2e --render-profile floor_light_v1 --pf-track --contact-track`, weld OFF다.
정상 등록 경로가 인수 통과한 뒤 coordinator의 표준 실행 어댑터로 실행해야 한다.

**시간은 기존 완료 raw의 시트별 총 SIM시간(준비 포함)으로 산정한 추정치**다.

80초 중단 옵션이 있다고 가정하지 않았다. 새 중단 예산이 필요하면 조정자가 평가용 종료 설정과 소스를 별도로 고정한다.
wall 시간·디스크·로봇 명령 수는 실행 전 확정하지 않는다. 새 모델 호출은 필요 없다.

두 JSON의 위치는 고정 확증 60곳 및 적합에 쓴 40개 배치 조건과 `(거리 <1 cm AND yaw 차 <0.5°)`로 겹치지 않음을 검사했다.
프로브는 탐색 자료로 남기고, 결과를 보고 정책/배치/판정을 바꾸면 확증 사전 등록에 반영한 다음 봉인한다.
